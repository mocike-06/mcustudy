51 单片机教程

51 单片机是绝大多数人接触的第一颗芯片：结构简单、资料最多、每一根引脚都能亲手测到波形， 写完代码到看见灯亮之间只隔一次下载。它没有庞大的库和抽象层，寄存器就摆在数据手册里， 你操作什么、硬件就做什么，这种「所见即所得」正是建立底层直觉最快的方式。 本专题以 STC89C52RC 为核心，从 Keil C51 建工程、最小系统电路，一路讲到定时器、中断、串口、 LCD1602 与 DHT11 综合项目。学完之后你能独立完成按键、数码管、液晶、传感器这类常见题目， 也能顺畅衔接到 STM32 的 HAL 库开发——因为 GPIO、定时器、中断、串口这几个概念，你已经在 51 上手动实现过一遍了。

8 个专题 芯片：STC89C52RC 工具：Keil C51 + Proteus 建议周期：4~6 周

学习顺序建议

这 8 个专题是层层递进的，跳跃着学会在中断和串口处卡很久。建议按下面的节奏走。

1

先把环境和最小系统跑通

装好 Keil C51，在 Proteus 里画出晶振 + 复位 + 电源，能点亮一个 LED 再往下走。

2

再啃定时器与中断

定时器和外部中断是 51 的分水岭，TH/TL 初值一定要自己动手算一遍，不要只抄代码。

3

串口 + LCD1602 + DHT11 串成一个能演示的小系统，简历和课设都能直接拿去用。

Pitfalls

避坑提示

下面这些坑几乎每个 51 新手都会踩一遍，提前看一遍能省下好几个晚上。

晶振旁边那两个 30pF 电容不是装饰

晶振必须配两个 20~30pF 的负载电容接地，它们和晶振一起构成稳定的振荡回路。 省掉电容最常见的现象是「程序偶尔能跑、一碰就死机」，甚至干脆不起振。 电容还要尽量贴近晶振和单片机的 XTAL1 / XTAL2 引脚，走线越短越好。

串口助手一片乱码：先查波特率和晶振

乱码九成以上是波特率对不上。用 12MHz 晶振配 9600bps 无法整除，误差大到必然出错； 换成 11.0592MHz 后，9600 / 19200 等常用波特率都能整除。 另外确认两端的数据位、停止位、校验位一致，并且单片机是 TTL 电平， 接电脑 USB 转串口模块时别把 TX / RX 接反（应当交叉连接）。

LED 不亮：先看限流电阻和接法

51 的 IO 口拉电流能力很弱（约几百微安），灌电流能力才强（约 10~20mA）， 所以标准接法是 LED 阳极经限流电阻接 VCC、阴极接 IO 口，输出低电平点亮。 限流电阻一般取 220Ω~1kΩ：太小会烧 IO 口或 LED，太大亮度几乎看不见。 如果代码没错却不亮，先量一下 LED 有没有装反、电阻有没有虚焊。

中断服务函数里别写延时和 printf

中断服务函数应当尽量短。在里面调用长延时或串口打印，会长时间占用 CPU， 导致主循环卡顿、其他中断被错过，串口打印本身还可能因为重入把数据搅乱。 正确做法是在中断里只置一个标志位或写进缓冲区，真正的处理交回主循环完成。

sbit 必须定义在可位寻址的地址上

sbit 只能作用于位寻址区：字节地址能被 8 整除的特殊功能寄存器 （如 P0~P3、TCON、SCON、IE、TMOD 之外的多数 SFR），或 20H~2FH 的位寻址 RAM。 给不可位寻址的寄存器定义 sbit 会直接编译报错。 典型例子就是 TMOD：它字节地址 0x89 不能被 8 整除，只能整体赋值，不能 sbit 单独操作某一位。

先用 Proteus 仿真验证，再上硬件

烧录进芯片再排查问题，你分不清是电路错了还是代码错了。 先在 Proteus 里把最小系统、LED、LCD、串口都跑通，用虚拟示波器看时序波形， 确认逻辑无误后再上真实硬件，剩下的问题基本就只在焊接和接线上了。

Reference

常用寄存器速查

调程序时最常翻的就是这张表。注意「可位寻址」一列——它决定了你能不能用 sbit。

寄存器 作用 常用位
P0 P0 口数据寄存器（字节地址 0x80，可位寻址）。作为普通 IO 时为漏极开路，需外接上拉电阻；扩展总线时复用为低 8 位地址 / 数据总线。 P0.0 ~ P0.7
P1 P1 口数据寄存器（字节地址 0x90，可位寻址）。纯准双向 IO，内部已有上拉，驱动 LED、按键、LCD 数据线最常用。 P1.0 ~ P1.7
P2 P2 口数据寄存器（字节地址 0xA0，可位寻址）。准双向 IO；扩展外部存储器时输出高 8 位地址。 P2.0 ~ P2.7
P3 P3 口数据寄存器（字节地址 0xB0，可位寻址）。每个引脚都有第二功能。 P3.0/RXD、P3.1/TXD、P3.2/INT0、P3.3/INT1、P3.4/T0、P3.5/T1
TMOD 定时器 / 计数器方式寄存器（字节地址 0x89）。高 4 位控制 T1，低 4 位控制 T0。不可位寻址，只能整体赋值，例如 TMOD = 0x01;。 GATE、C/T、M1、M0
TCON 定时器控制寄存器（字节地址 0x88，可位寻址）。负责启停定时器、设置外部中断触发方式，并保存溢出与中断请求标志。 TF1、TR1、TF0、TR0、IE1、IT1、IE0、IT0
SCON 串行口控制寄存器（字节地址 0x98，可位寻址）。选择工作方式、允许收发、保存收发中断标志与第 9 位数据。 SM0、SM1、SM2、REN、TI、RI
IE 中断允许寄存器（字节地址 0xA8，可位寻址）。总开关 EA 关闭时，任何中断都不会被响应。 EA、ET2、ES、ET1、EX1、ET0、EX0
PCON 电源控制寄存器（字节地址 0x87，不可位寻址）。最高位 SMOD 用于串口波特率加倍，其余位与掉电、空闲等低功耗模式有关。 SMOD、SMOD0、PD、IDL
IP 中断优先级寄存器（字节地址 0xB8，可位寻址）。设置两级中断优先级，处理中断嵌套。 PS、PT1、PX1、PT0、PX0

提示：以上地址以标准 8051 / STC89C52 为准。STC 系列额外增加的 SFR（如 AUXR、P4 口、看门狗 WDT_CONTR） 请以对应型号的官方数据手册为准。

Code

完整代码示例：LED 流水灯

把下面这段代码原样贴进 Keil 新建的 main.c，按 12MHz 晶振编译， 用 STC-ISP 下载到 STC89C52RC，接在 P1 口的 8 个 LED 就会依次点亮。 

#include <reg52.h>          /* 包含 8051 标准寄存器定义，P1、unsigned int 等都在里面 */

/* ---------------------------------------------------------------
 * 硬件连接说明（共阳极接法，最常见）
 *   P1.0 ~ P1.7 各接一个 LED 的阴极
 *   每个 LED 的阳极各串一只 220Ω~1kΩ 限流电阻，再接到 +5V
 *   因此：IO 输出低电平(0) -> LED 点亮；输出高电平(1) -> LED 熄灭
 * --------------------------------------------------------------- */

sbit LED0 = P1^0;         /* sbit 定义单个引脚，P1 字节地址 0x90 可位寻址 */
sbit LED7 = P1^7;         /* 这里演示 sbit 用法，主循环中仍用字节整体赋值 */

/* ---------------------------------------------------------------
 * 函数：Delay_ms
 * 作用：软件延时，晶振 12MHz 时约延时 ms 毫秒
 * 说明：51 的机器周期 = 12 / 晶振频率 = 1us，所以内层空循环次数
 *       按经验取值即可；对时间精度要求高时请改用定时器。
 * --------------------------------------------------------------- */
void Delay_ms(unsigned int ms)
{
    unsigned int i;
    unsigned char j;

    for (i = 0; i < ms; i++)          /* 外层：循环 ms 次，每次约 1 毫秒 */
    {
        for (j = 0; j < 120; j++)     /* 内层：空循环，负责"吃掉"这 1 毫秒 */
        {
            ;                          /* 空语句，什么都不做，只消耗时间 */
        }
    }
}

/* ---------------------------------------------------------------
 * 函数：main
 * 作用：主函数，程序入口。单片机没有操作系统，必须写成死循环，
 *       否则 main 执行完就"跑飞"了。
 * --------------------------------------------------------------- */
void main(void)
{
    unsigned char led;                 /* 保存当前要输出的 LED 状态 */

    P1 = 0xFF;                         /* 上电先把 P1 全部拉高，8 个 LED 全灭 */

    while (1)                          /* 主循环：单片机的程序永远不退出 */
    {
        led = 0xFE;                    /* 0xFE = 1111 1110B，最低位为 0 -> P1.0 点亮 */

        while (1)
        {
            P1 = led;                  /* 把状态输出到 P1 口，驱动 LED */
            Delay_ms(200);             /* 保持 200ms，让肉眼能看清流水效果 */

            led = (led << 1) | 0x01;   /* 左移一位，并把最低位补 1（保持熄灭） */

            if (led == 0xFF)           /* 8 个 LED 都轮流亮过一遍后，低 8 位全变 1 */
            {
                break;                 /* 跳出内层循环，重新从 P1.0 开始 */
            }
        }
    }
}

说明：Delay_ms 是软件延时，实际时长受晶振频率与编译器优化等级影响， 仅适合流水灯、数码管扫描这类对时间不敏感的场景。需要精确定时请参考 定时器原理与定时 一节，用定时器中断替代。
