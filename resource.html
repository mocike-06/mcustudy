报错排查：Cannot open source input file "reg52.h"

这条报错的本质是 C51 编译器找不到头文件，而 reg52.h 本来是 Keil C51 安装目录下 C51\INC 里的标准头文件。常见成因有三种：当前工程其实是用 MDK-ARM 打开的（ARM 编译器根本没有 reg52.h）、TOOLS.INI 里 C51 的 PATH 指向了不存在的目录、或者工程是从别人电脑拷来的、Include Paths 还指着旧路径。文档按这三种情形给出逐步排查方法，并顺带讲清 #include <reg52.h> 与 #include "reg52.h" 的区别——尖括号只搜系统与 Include 目录，引号会先搜当前源文件所在目录。

如何自己替换下载链接

三步就能把上面的占位按钮变成真正的下载入口。整个过程不需要改 JavaScript，也不需要后端。

1

把文件放进 downloads 目录

在项目里新建 assets/downloads/ 目录，把资源文件按卡片上的文件名放进去（例如 stc89c52rc-datasheet.pdf），文件名建议只用小写字母、数字和连字符，避免空格与中文。

2

删掉占位属性

打开 resource.html，找到对应卡片的下载按钮，把 data-demo-download 属性删掉——保留它就会一直弹演示提示，也就是现在点击的效果。

3

换成真正的下载链接

把 <button> 换成带 download 属性的链接，样式类保持不变，外观完全一致：

<a class="btn-outline btn-sm" href="assets/downloads/stc89c52rc-datasheet.pdf" download>下载资源</a>
