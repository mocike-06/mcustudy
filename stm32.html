STM32 HAL 库教程

从 51 的 P1 = 0xFE; 直接写寄存器，切换到 32 位 ARM 的工程化开发方式：用 STM32CubeMX 图形化配置时钟树与引脚，用 HAL 库函数代替手写寄存器，在 STM32F103C8T6（Cortex-M3，主频 72MHz）上跑通 GPIO、串口、定时器 PWM、ADC、I2C 与外部中断。HAL 库的取舍是牺牲一点执行效率与代码体积，换来更短的开发周期、跨型号的可移植性和官方文档与例程支撑——对课设、竞赛和毕设来说，这笔交易非常划算。学完之后你能独立走完“配置 → 写代码 → 编译下载 → 定位问题”的完整闭环，并做出数字电压表这类综合小项目。

8 个专题 芯片：STM32F103C8T6 工具：CubeMX + Keil MDK 建议周期：6~8 周

Mindset Shift

从 51 到 STM32 的思维转变

51 的经验不会白费，但有三件事必须先换个思路，否则第一条编译不过的报错就会把人劝退。

1

从直接写寄存器到调用 HAL 函数

51 里一行 P1 = 0xFE; 就完事；STM32 里一行 HAL_GPIO_WritePin() 背后是“开时钟 → 配模式 → 写 BSRR”三件事。HAL 不是更难，而是把细节收进了初始化结构体，你要做的是看懂 CubeMX 生成的初始化代码，而不是背函数。

2

从 8 位到 32 位：先有时钟，才有外设

51 上电就能用 IO 口，STM32 的每个外设都要先“开时钟”才通电。系统时钟由 HSE 经 PLL 倍频得到 72MHz，串口波特率、定时器周期、ADC 采样时间全部由它推导——时钟树上错一个节点，外设就完全不工作。

3

从裸机 while(1) 到中断与 NVIC 优先级

51 只有几个固定中断号；STM32 有几十条可屏蔽中断，需要理解抢占优先级与响应优先级的分组。通用做法是：中断里只置标志位、存数据，真正的活儿留给主循环处理。

Pitfalls

避坑提示：新手最容易栽的五个地方

下面这几条几乎每个人都要踩一遍，提前看一遍能省下好几个晚上。排查外设问题时的通用顺序是：先看时钟，再看引脚复用，最后才怀疑代码逻辑。

外设完全没反应？先确认时钟使能了没有

STM32 的每个外设（GPIO / USART / TIM / ADC / I2C）在总线上默认都是关着的，时钟不开，寄存器怎么写都不会有反应。CubeMX 会帮你生成 __HAL_RCC_GPIOA_CLK_ENABLE() 这类语句；一旦自己手写初始化，或者临时启用了一个新端口、新外设，就必须补上对应的 __HAL_RCC_xxx_CLK_ENABLE()。典型现象是：程序明明在跑，串口有打印，引脚却一动不动。

串口乱码：先查时钟树，再查波特率

绝大多数乱码不是接线问题，而是波特率算错：HAL 库用系统时钟推导 USARTDIV，如果 SystemClock_Config() 没被调用，或者板子上的晶振是 8MHz 而 CubeMX 里填成了别的值，波特率就会整体偏掉。排查顺序： ① 确认 HSE_VALUE 与板上晶振一致；② 确认时钟树上 USART1 挂在 APB2（72MHz）；③ 确认串口助手也是 115200-8-N-1，并且接了 GND。

HAL 库回调函数里不要做耗时操作

HAL_GPIO_EXTI_Callback() 是在中断上下文里执行的：里面不能调用 HAL_Delay() （SysTick 中断优先级默认被设为最低 0x0F，在优先级更高的 EXTI 里等它等于死等），不能 printf() （串口发送既耗时又不可重入），也不要跑长循环。正确做法是只改一个 volatile 标志位或把数据塞进环形缓冲区，真正的处理放到 main 的 while(1) 里做。

CubeMX 重新生成代码会覆盖 USER CODE 之外的内容

CubeMX 只保留 USER CODE BEGIN xxx 与 USER CODE END xxx 之间的内容，其余部分每次 Generate Code 都会重新生成。自己写的函数、全局变量、额外的 #include 一定要放进对应的 USER CODE 区；否则今天调好的中断回调，明天重新生成一次就凭空消失了。

烧录成功但程序不跑：先看 BOOT 跳线与复位

下载提示成功、灯却不闪，先别怀疑代码：确认 BOOT0 跳线在 0（从 Flash 启动），BOOT0/BOOT1 组合不对会进系统存储器或 SRAM 启动；再按一次复位键，有些 ST-Link 下载完成后不会自动复位； 最后检查是否把 SWD 用的 PA13/PA14 复用成了普通 IO，那样下次就连不上下载器了。

省事小技巧：把 CubeMX 的引脚配置截图存档

在 CubeMX 的 Pinout 视图里，把引脚分配图、时钟树、每个外设的参数页各截一张图，连同工程一起放进文件夹。写实验报告、画原理图、给同学讲接线时直接引用； 过两周回头改代码，也比重新打开 CubeMX 一个个翻参数页快得多。

Cheat Sheet

HAL 库常用函数速查

初学阶段 90% 的代码都是这十几个函数拼出来的，先混个脸熟，写的时候回来查一眼即可。表中 &huart1 这类句柄由 CubeMX 生成，不要自己改名。

函数 作用 典型用法
HAL_GPIO_WritePin 把指定引脚置高或置低，一次只改一个引脚 HAL_GPIO_WritePin(GPIOC, GPIO_PIN_13, GPIO_PIN_RESET); // 低电平点亮板载 LED
HAL_GPIO_ReadPin 读引脚当前电平，返回 GPIO_PIN_SET 或 GPIO_PIN_RESET if (HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_0) == GPIO_PIN_RESET) { /* 按键按下 */ }
HAL_GPIO_TogglePin 翻转引脚电平，做 LED 闪烁最方便 HAL_GPIO_TogglePin(GPIOC, GPIO_PIN_13);
HAL_Delay 基于 SysTick 的毫秒级阻塞延时，中断里不能用 HAL_Delay(500); // 等待 500ms
HAL_UART_Transmit 阻塞方式发送一串字节，发完才返回 HAL_UART_Transmit(&huart1, (uint8_t *)buf, len, 100);
HAL_UART_Receive_IT 开启中断接收，收满指定长度后进接收完成回调 HAL_UART_Receive_IT(&huart1, rx_buf, 1); // 单字节中断接收
HAL_TIM_Base_Start_IT 启动定时器并打开更新中断 HAL_TIM_Base_Start_IT(&htim2); // 每 1ms 进一次中断
__HAL_TIM_SET_COMPARE 运行时动态修改 PWM 比较值，即改占空比 __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, 500);
HAL_ADC_Start 启动 ADC 转换（轮询模式，需再调 PollForConversion 等结果） HAL_ADC_Start(&hadc1);
HAL_ADC_GetValue 读取最近一次的转换结果，12 位量程为 0~4095 uint16_t raw = HAL_ADC_GetValue(&hadc1);
HAL_I2C_Master_Transmit I2C 主机发送数据，OLED 写命令与写数据都靠它 HAL_I2C_Master_Transmit(&hi2c1, 0x78, buf, len, 100);
HAL_NVIC_SetPriority 设置某条中断的抢占优先级与响应优先级 HAL_NVIC_SetPriority(EXTI0_IRQn, 1, 0);
HAL_NVIC_EnableIRQ 使能 NVIC 中对应的中断线，不调用则中断永远不来 HAL_NVIC_EnableIRQ(EXTI0_IRQn);

Code Sample

完整示例：串口重定向 + main 函数骨架

这份代码可以直接贴在 CubeMX 生成的 main.c 里（重定向部分放在 USER CODE 区），编译下载后打开串口助手就能看到打印。 

/**
 * @file    main.c
 * @brief   STM32F103C8T6 + HAL 库：把 printf 重定向到 USART1 的完整示例
 * @note    工程由 STM32CubeMX 生成，本文件只改 USER CODE BEGIN / END 之间的内容
 *          串口参数：115200-8-N-1，引脚 PA9(TX) / PA10(RX)
 */

#include "main.h"
#include "usart.h"
#include "gpio.h"
#include <stdio.h>              /* printf、fputc 的声明都在这里 */

/* ================= 1. 重定向：让 printf 走串口 ================= */
/* Keil MDK(ARMCC) 里的 printf 最终调用 fputc 输出一个字符，覆盖它即可 */
int fputc(int ch, FILE *f)
{
    uint8_t byte = (uint8_t)ch;                     /* 只取低 8 位；中文要按字节流发送 */
    HAL_UART_Transmit(&huart1, &byte, 1, 10);      /* 阻塞发送 1 字节，超时 10ms */
    return ch;                                      /* 必须有返回值，否则 printf 会中途停住 */
}

/* 关闭半主机模式：少了这两句，Keil 下可能一直卡在 _sys_exit 里出不来 */
void _sys_exit(int x) { x = x; }
void _ttywrch(int ch)  { ch = ch; }

/* 如果用 STM32CubeIDE(GCC)，把重定向改成实现 __io_putchar 即可 */
#ifdef __GNUC__
int __io_putchar(int ch)
{
    HAL_UART_Transmit(&huart1, (uint8_t *)&ch, 1, 10);
    return ch;
}
#endif

/* ================= 2. 系统时钟：由 CubeMX 生成 ================= */
/* HSE 8MHz 经 PLL 9 倍频得到 SYSCLK = 72MHz；APB2 = 72MHz，USART1 就挂在这条总线上 */
void SystemClock_Config(void)
{
    /* 函数体由 CubeMX 生成，不要手改：重新生成代码时会被整体覆盖 */
}

/* ================= 3. 主函数 ================= */
int main(void)
{
    uint32_t cnt = 0;             /* 变量声明统一放在最前面，兼容 C90 编译模式 */

    HAL_Init();                   /* 复位所有外设、初始化 Flash 接口与 SysTick(1ms) */
    SystemClock_Config();         /* 必须在 HAL_Init 之后调用，否则波特率、延时全部算错 */
    MX_GPIO_Init();               /* PC13 推挽输出，接板载 LED */
    MX_USART1_UART_Init();        /* 115200-8-N-1，无硬件流控 */

    printf("STM32F103C8T6 启动完成\r\n");                 /* \r\n 是串口助手习惯的换行 */
    printf("SYSCLK = %lu Hz\r\n", HAL_RCC_GetSysClockFreq());

    while (1)
    {
        HAL_GPIO_TogglePin(GPIOC, GPIO_PIN_13);          /* 翻转 LED，观察程序是否在跑 */
        printf("第 %lu 次循环：LED 已翻转\r\n", ++cnt);
        HAL_Delay(500);                                   /* SysTick 提供的毫秒级延时 */
    }
}

注意：fputc 是阻塞发送，在中断里调用会拖慢响应；调通之后建议改成 DMA + 空闲中断的发送方式。
