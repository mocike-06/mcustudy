有源滤波与电压比较器

前一篇你把运放当成了「放大倍数的搬运工」，这一篇要让它干两件更接近真实工程的事：按频率挑信号和按幅度下判决。前者是滤波器——它决定了 STM32 的 ADC 读到的到底是真的传感器信号，还是从高频折叠回来的假信号；后者是比较器——它决定了你的光电门、按键、过压保护是「干净利落地触发一次」，还是「在阈值附近疯狂抖动把中断塞满」。这两件事有个共同特点：软件再怎么写都补救不了，必须在引脚之前的那一小段模拟电路里解决。

第 1 节

为什么需要它

先看两个几乎每个人都会撞上的现场，再回头看它们其实是同一个原因。

先说两个真实场景，你看看是不是自己遇到过：

  • 场景 A：ADC 读数一直在跳。你用 STM32 的 ADC 采一个压力传感器的输出，理论上电压应该稳定在 1.50V 左右，可串口打印出来的值在 1.47 ~ 1.53V 之间乱蹦，最后一位数字根本没停过。你以为是 ADC 不行，于是软件平均 64 次——小数点后第二位稳了，第三位还在跳。你把传感器直接焊到 ADC 引脚上，跳得更厉害。
  • 场景 B：一次按键进了八次中断。你用一个红外对管（或者机械按键、霍尔开关）接到 STM32 的外部中断引脚，想在中断里累加计数。结果手一按，计数一次跳了 7 ~ 8；电机没转的时候，计数器自己也在涨。你加了个 HAL_Delay 在中断里，程序反而卡死了。

这两个场景看起来一个是「采样」一个是「中断」，八竿子打不着，但根因是同一个：从传感器到单片机引脚之间的那一小段模拟电路，你没做。

单片机是一颗纯数字器件：它的 ADC 只会老老实实把「采样瞬间引脚上的电压」量化成一个数字，它的外部中断只会老老实实把「引脚电平跨过门限」记成一次事件。它不会分辨这个电压是真实信号还是搭在信号上的噪声，也不会分辨这次电平变化是真正的动作还是阈值附近的抖动。所有这些判断，必须在信号进引脚之前用硬件做完。

这一篇要装的两种「前置判断」

滤波器管频率——它决定「哪些频率的成分能通过」。传感器信号和噪声的频率往往不在一起，把不想要的频率挡掉，ADC 才能读到真值。

比较器管幅度——它决定「电压越过哪条线算一次事件」。加一点正反馈（滞回）之后，阈值附近的小抖动会被直接无视，中断才会干净。

一句话记住分工：滤波器解决「读得准不准」，比较器解决「触发得稳不稳」。

先建立最重要的一个直觉：信号和噪声的区别不在「大小」，在「频率」

刚学模电时最容易有的误解是：「噪声就是那些很小的电压，信号就是那些很大的电压，把信号放大、把噪声压小就行了。」这个想法在真实电路里几乎一定会翻车，原因很简单：噪声很多时候比信号还大，而且它就长在信号身上，你没法用「大小」把它们分开。

但换个角度看就很清楚了：信号和噪声占据的频率范围通常不一样。这就是滤波器的立足点。先看一张频谱图——横轴是频率，纵轴是各个频率成分的幅度：

看图说话，这张图里其实藏着三个完全不同的任务：

  • 任务一：把 50Hz 工频干扰去掉。不可能。它和你的信号（0 ~ 100Hz）在频率上重叠，滤波器分不开它们。这种情况只能从源头解决：屏蔽线、差分输入、远离变压器、把传感器桥路做成差分。这是「滤波不是万能」的第一课。
  • 任务二：把奈奎斯特频率以上的干扰挡在 ADC 之前。可以，而且必须。这就是抗混叠滤波器要干的事，也是这一篇最实用的部分。注意 10.05kHz 这段干扰的频率明明比信号高得多，但它一旦被 10kHz 采样，就会折叠到 50Hz——采样后的数字世界里，它和一个真实的 50Hz 信号长得一模一样，软件再也分不开了。
  • 任务三：把「电压越过某条线」变成一次干净的事件。这不是滤波器的活，是比较器的活。下文会看到，比较器对付的不是频率，而是幅度上的「判决」。

四种滤波器，其实就是四种「频率门卫」

按放行哪一段频率，滤波器只有四种基本类型。名字和形状对应起来记，一辈子不会忘：

类型放行挡住典型用途
低通（LPF）低频高频ADC 抗混叠、传感器信号平滑、电源纹波
高通（HPF）高频低频去掉直流偏置与温漂、交流耦合、隔直电容
带通（BPF）中间一段两侧只关心某个频段，如心电、超声、谐振检测
带阻（陷波 BSF）除中间外中间一段专门干掉 50Hz 工频（陷波器）

你会发现，低通是所有类型里最重要的一种，因为几乎每一次「模拟量进单片机」都伴随着采样，而只要采样，就必然需要抗混叠。所以这一篇讲滤波时，主线是低通，高通和带通只做必要的延伸。

比较器管的是另一件事：把连续量变成事件

再来看比较器。如果说滤波器是「把信号收拾干净」，比较器就是「替单片机下判决」：电压比参考值高，输出一个电平；比参考值低，输出另一个电平。它输出的是纯数字量，可以直接进 GPIO、进中断、进计数器。

但判决这件事有个陷阱，用空调打个比方最容易懂：

【错误的温控，等价于「单限比较器」】
   室温高于 27 度 → 开压缩机
   室温低于 27 度 → 关压缩机
   结果：温度在 27 度附近微动，压缩机一秒开、一秒关，很快就会坏。

【正确的温控，等价于「滞回比较器」】
   室温升到 27 度 → 开压缩机
   室温降到 25 度 → 关压缩机
   中间 25 ~ 27 度这一段的动作保持不变，这叫「滞回窗口」。

比较器完全一样。你的信号上永远搭着噪声，如果判决线只有一条（单限），那么当信号缓慢经过这条线时，噪声会让电压反复穿越它，输出就在高/低之间疯狂抖动。这不是「偶尔多触发一次」，而是在穿越期间以噪声的速率持续翻转——如果它接在 STM32 的外部中断上，主程序会被中断淹没，看起来就像死机。

给它加两条判决线（够高才置位、够低才复位），中间那段就是「死区」，噪声幅度只要小于死区宽度，就被彻底无视。这也是本篇第 3 节要手算的核心内容之一。

先把信号和噪声的频谱分开：滤波器到底在做什么取舍

第 1 节已经说了，滤波器的立足点是信号和噪声占据不同的频段。现在把这个想法变成可以画在纸上的东西。

教科书里画的「理想滤波器」是一个直角矩形：低于截止频率 fc 的成分原封不动通过（增益 1，即 0dB），高于 fc 的成分被彻底抹掉（增益 0）。而真实的滤波器，形状是一条斜着滑下去的曲线：

这三个区间的名字要记住，后面所有指标都围绕它们：

  • 通带：你希望原样通过的频段（传感器信号在哪儿，通带就该在哪儿）。
  • 阻带：你希望彻底压掉的频段（噪声、混叠隐患在哪儿，阻带就该盖住哪儿）。
  • 过渡带：通带和阻带之间那段「斜着下来」的区域。它越窄，滤波器越「接近理想」，代价也越大。

于是，滤波器设计的所有矛盾都可以归纳成一句话：你想让过渡带多窄，就要付出多少代价。这个代价可以是更多的阶数（更多 RC、更多运放）、更高的 Q（元件更敏感、阶跃响应更振铃）、或者更高的采样率（把 fs/2 推得更远，给过渡带留出空间，这条是数字时代的「捷径」）。

无源滤波 vs 有源滤波：为什么非要用运放

只用电阻电容（有时加电感）的滤波器叫无源滤波器；带运放、需要供电的叫有源滤波器。你可能会想：RC 已经能滤波了，为什么还要花钱加运放？看这张对比表就明白了：

对比项无源 RC / LC有源（运放 + RC）
通带增益最大 1（0dB），实际还略低（插入损耗）可以大于 1，可以小于 1，随你设计
输出阻抗高（等于 R 的量级），一接负载 fc 就跑掉极低（运放输出闭环阻抗通常远小于 1Ω）
级与级之间后级输入阻抗会「加载」前级，fc 和高低通特性互相影响几乎不互相影响，可以放心级联

代价元件少、便宜、可靠、高频也能用要供电、要运放；受运放带宽（GBW）与压摆率限制
适用频率从直流到射频都可以常见于音频、传感器、几十 kHz 到几百 kHz 的场合

最关键的一行是「级与级之间」。你可以自己算一下：如果一级 RC 低通（R = 10kΩ，C = 100nF，fc ≈ 159Hz）后面直接再接一级一样的 RC，第二级的输入电阻 10kΩ 会和第一级的 R 并联，第一级实际看到的负载变成 5kΩ，fc 直接翻倍。这就是无源滤波器「级联就变样」的本质。而运放的输入端是虚断（输入电流极小、输入阻抗极高），所以有源滤波器每一节的边界都是干净的。

有源滤波器不是万能的

运放有增益带宽积（GBW）和压摆率的限制，截止频率越高、Q 越高，对运放带宽的要求越苛刻。经验法则是运放的 GBW 至少取 fc 的 20 ~ 100 倍——比如你要做 fc = 100kHz 的二阶滤波器，运放的 GBW 最好在 2MHz 以上。

如果是几 MHz 以上的高频滤波，老老实实回到 LC 无源滤波或者专门的滤波器芯片，别用运放硬撑。

一阶 RC：低通、高通与带通，以及那个绕不开的 fc = 1/(2πRC)

一切都是从两个元件开始的。一阶低通就是「电阻串在信号路上，电容从信号线接到地」：

        R
Vin ────[  ]────┬──── Vout
                │
                │
               ─┴─  C
               ─┬─
                │
               ─┴─  GND
                │

工作原理（记住这句就够）：
  电容的容抗 Xc = 1/(2πfC) 随着频率升高而【变小】。
  · 低频时：Xc 很大，电容像「断路」，信号几乎原封不动传到 Vout
  · 高频时：Xc 很小，电容像「短路」，高频成分被它抄近路放到地

把电容看成一个随频率变化的电阻 Xc = 1/(jωC)（用相量表示，ω = 2πf 是角频率，单位 rad/s），这个电路就是一个分压器：

Vout = Vin · Xc / (R + Xc)

两边同时除以 Vin，把 Xc 代进去，上下同乘 jωC，就得到一阶低通的传递函数：

一阶低通传递函数

H(f) = Vout/Vin = 1 / (1 + j·f/fc)，其中

fc = 1 / (2πRC)

每一项的物理意义：分母里的 1 是「直通的那条路」，j·f/fc 是「被电容放掉的那条路」。频率 f 越低，第二项越小，输出越接近输入；频率越高，第二项越大，输出越小。fc 就是这两条路势均力敌的那个频率。

单位：R 用 Ω、C 用 F，算出来的 RC 单位是秒（s），所以 2πRC 也是秒，倒过来才是 Hz。工程上常用 τ = RC 表示这个时间常数，于是 fc = 1/(2πτ)。

把幅度和相位分开写出来，这两个式子要背下来：

  • 幅频特性：|H| = 1 / √(1 + (f/fc)²)，用 dB 表示就是 20·lg|H|。
  • 相频特性：φ = −arctan(f/fc)，输出总比输入「晚一点」。

时域和频域说的是同一件事

如果你给对方一个阶跃（比如从 0V 跳到 3.3V），输出不是立刻跟上，而是按指数爬升：

Vout(t) = 3.3 · (1 − e^(−t/τ))，τ = RC

工程上有几个必须记住的刻度：1τ 到 63.2%、3τ 到 95.0%、5τ 到 99.3%。也就是说，一个 τ = 1ms 的 RC，要等大约 5ms 才算「稳定到位」。这和频域的 −3dB 是同一件事的两种说法：滤波器在频域压掉高频，在时域就表现为「反应变慢」。这一点在 ADC 多路切换时非常要命——切换通道之后必须等至少 5τ 再采样，否则读到的是上一路残留的电压。

高通就是低通的「对偶」：把 R 和 C 换个位置

把电容从「对地」挪到「串联在信号路上」，电阻改为对地，就得到一阶高通：

        C
Vin ────┤├────┬──── Vout
               │
              [  ]  R
               │
              GND

H(f) = (j·f/fc) / (1 + j·f/fc)        fc = 1/(2πRC)
· f 远小于 fc：分母的 j·f/fc 很小 → |H| ≈ f/fc，几乎没有输出（直流被彻底挡住）
· f 远大于 fc：分子分母都是 j·f/fc → |H| ≈ 1，原样通过
· 直流（f = 0）：|H| = 0，这就是「隔直电容」的作用

高通最典型的用途是交流耦合：传感器输出带着 2.5V 直流偏置，你只想看上面叠加的几十毫伏交流信号，串一个电容就能把直流挡住。但要注意两个副作用：一是低频成分（包括你想要的缓慢变化）也会被挡掉，二是如果后级输入阻抗不够高，fc 会和它一起被改变——这正是前面说的「无源滤波器怕加载」。

带通：高通和低通串起来，但别直接串

一个高通（挡低频）+ 一个低通（挡高频）= 带通。理论上只要让 fc_high（高通）低于 fc_low（低通），中间那段就是你的通带。但前面说过，两个无源 RC 直接串联会互相加载，实际特性会和纸上算的差很远。所以带通通常做成有源形式：

        C1                 R2
Vin ────┤├────┬───────┬────[  ]────┬──── Vout
              │       │            │
             [  ] R1  │           ─┴─ C2
              │       │           ─┬─
             GND     ─┴─ 运放      │
                     ─┬─ 电压跟随  GND
                      │  （缓冲）
                      └─ 输出接 R2

高通节 → 缓冲 → 低通节：两级互不加载，各自的 fc 才是设计值。
通带 = fc_high ~ fc_low 之间那一段；带宽 BW = fc_low − fc_high。

一个具体例子能帮你把量级感建立起来：心电信号大概在 0.5 ~ 40Hz，而 50Hz 工频干扰正好在它的上边缘外面一点点。所以心电前端会做成 fc_high ≈ 0.5Hz、fc_low ≈ 40Hz 的带通，再配一个专门针对 50Hz 的陷波器——这就是为什么心电设备里滤波器一堆，而它们都在做同一件事：把信号频段之外的成分尽可能地推开。

到这里，你已经会做一阶低通、高通、带通了。下一小节要泼一盆冷水：一阶滤波器在真正需要「把某个频段压干净」的场合，几乎一定不够用。

先看一阶低通在双对数坐标（波特图）里的样子。对数坐标的好处是：低频段的曲线会被压成一条直线，一眼就能看出衰减速率。

     │             ╱

斜线的规律（工程口诀）：
   频率每升 10 倍，增益降 20dB  →  −20dB/十倍频（−20dB/decade）
   频率每升 1 倍（一个倍频程）→  降约 6dB    →  −6dB/倍频程

很多人第一次学到这里会觉得「20dB/十倍频」挺猛的：10 倍就是 10 倍衰减。但把它放到真实需求里一算，立刻就不够看了。假设你有一个 1kHz 的干扰必须被压到原来的 1/1000（−60dB），查一查需要多少倍频程：

看第一行最后两列：一阶滤波器想要 60dB 的衰减，干扰频率必须是截止频率的 1000 倍。这意味着如果你的有用信号在 100Hz，要压住 1kHz 的干扰 60dB，你得把 fc 定到 1Hz——而 100Hz 的信号早就被砍得只剩百分之几了。

这就是一阶滤波器最致命的短板，可以总结成三句话：

  • 它不是「不衰减」，而是「衰减得太慢」。斜线只有 −20dB/十倍频，过渡带非常宽，通带和阻带之间会拉出一大段「半死不活」的区域。
  • 它逼着你在「砍信号」和「留噪声」之间二选一。fc 定得低，有用信号被衰减且相位滞后；fc 定得高，噪声和混叠隐患漏过去。
  • 它没法做出「接近理想」的形状。无论怎么调 R 和 C，那条斜线的斜率都不会变——斜率由阶数决定，而不是由元件值决定。

举个和第 4 节呼应的数字感受一下这个两难（完整计算在第 3 节）：STM32 以 fs = 10kHz 采样，奈奎斯特频率是 5kHz，你希望 5kHz 处的干扰至少被压 40dB，而有用信号最高 100Hz。

  • 用一阶：要满足 5kHz 处 −40dB，需要 fc = 5kHz/100 = 50Hz。可 100Hz 的有用信号在 fc 的 2 倍处，已经被衰减到 −6.99dB（只剩 45%）——信号先被砍了一半，这还没算相位滞后带来的波形失真。
  • 用二阶：同样的 5kHz 处 −40dB，只需要 fc ≈ 500Hz，100Hz 处几乎没有任何衰减。同样一个需求，二阶让 fc 提高了 10 倍，两难就此化解。

顺便说，这就是为什么几乎所有 ADC 前端、音频输入、传感器调理电路都用二阶或更高阶——不是一阶不能用，是它把本来很宽裕的设计空间挤没了。

阶数从哪里来

一个 RC 是一阶（分母里 s 的最高次是 1 次），两个 RC 就是二阶（分母里 s²），每多一个独立的储能元件（电容）就多一阶，衰减速率就再加 20dB/十倍频。

但注意：「两个 RC 直接串联」并不等于一个设计良好的二阶滤波器。这样的电路两个极点都是实数、离得很远，等效 Q 只有 0.5（过阻尼），在 fc 附近就已经掉了 6dB，过渡带比理想二阶更宽。想要「平坦通带 + 陡过渡带」，必须让两个极点靠得足够近，也就是要靠运放引入反馈来「造」出想要的 Q。这就是下一小节的主题。

二阶有源滤波器：Sallen-Key 与多重反馈（MFB）两条主流路线

要把斜率从 −20dB/十倍频变成 −40dB/十倍频，就必须让传递函数的分母出现 s² 项，也就是要有两个独立的电容。这件事无源电路也能做，但会互相加载；用运放做则有两条成熟路线：Sallen-Key（SK，又叫压控电压源 VCVS）和多重反馈（MFB，又叫 Rauch 拓扑）。先把它们共同的目标写出来。

二阶低通的标准形式（所有二阶滤波器都长这样）

H(s) = A0 · ωc² / (s² + (ωc/Q)·s + ωc²)，其中 s = jω、ωc = 2π·fc

三个参数，各管一件事：

· A0——直流（低频）增益，通带里信号被放大或衰减多少倍。

· ωc——截止角频率（换算成 Hz 就是 fc = ωc/2π），决定「拐点」在哪儿。

· Q——品质因数，决定拐点附近的形状：是平滑地滑下去，还是先鼓起一个包再滑下去。

一个必须记住的结论：把 s = jωc 代进去算，可以得到 |H(fc)| = A0 · Q。也就是说，在截止频率处，输出幅度恰好是直流增益的 Q 倍。Q = 0.707 时它等于 0.707·A0，正好是 −3dB——这就是「巴特沃斯」的由来；Q = 1.305 时它等于 1.305·A0，即 fc 处反而鼓起来 +2.3dB（20·lg1.305 = 2.31dB）。

拓扑一：Sallen-Key（单位增益版）

这是最经典、元件最少的二阶有源低通。它的灵魂在于电容 C1 不是接地，而是接回运放的输出——输出跟着输入走，相当于把 C1 的「地」也抬了起来，形成一种自举（正反馈）效果，从而把两个极点推近、造出大于 0.5 的 Q：

                    R1            R2
   Vin ─────────────[  ]─────┬────[  ]──────┬───────────┐
                            │  A           │  B        │
                           ─┴─ C1        ─┴─ C2        │
                           ─┬─           ─┬─           │
                            │              │           │
                            │             GND          │
                            │                          │
                            └──────────────────────────┤  ← C1 另一端接【输出】
                                                       │
                                           ┌───────────┴───┐
                                           │  (+)          │
                                           │   运放         │
                                           │  电压跟随器    ├────── Vout
                                           │  (−)──────────┤
                                           └───────────────┘

   连接清单：
     ① Vin ── R1 ── 节点 A          ③ 节点 A ── C1 ── Vout（不是接地！）
     ② 节点 A ── R2 ── 节点 B       ④ 节点 B ── C2 ── GND
                                     ⑤ 节点 B 接运放同相输入，运放接成跟随器（增益 = 1）

推导只用两个节点方程加一条虚短，很值得跟着走一遍（s = jω，把电容写成导纳 sC）：

跟随器：Vout = V_B（虚短 + 虚断，输出等于同相端电压）

节点 A（KCL，流出电流之和为 0）：
   (V_A − Vin)/R1 + (V_A − V_B)/R2 + (V_A − Vout)·sC1 = 0

节点 B：
   (V_B − V_A)/R2 + V_B·sC2 = 0     →   V_B = V_A / (1 + sR2C2)

把 V_B 和 Vout = V_B 代回节点 A，消掉 V_A，整理成标准二阶形式：

   H(s) = ωc² / (s² + (ωc/Q)·s + ωc²)

   ωc = 1 / √(R1·R2·C1·C2)                     ← 四个元件的乘积开方
   Q  = √(R1·R2·C1·C2) / ( C2·(R1 + R2) )      ← 注意分子分母单位都是秒，Q 无量纲

观察这两个式子，就能得出后面设计要用的两条规律：
   · fc 由「四个元件的乘积」决定，所以单独改一个元件，fc 也会动
   · 要让 Q 变大（极点靠得更近），可以让 C1 相对 C2 变大，或者让 R1+R2 变小

把两个电阻取成相同值是最省事的设计方式，此时公式会简化成非常好记的形式：

Sallen-Key 等值设计（R1 = R2 = R）

fc = 1 / (2π·R·√(C1·C2))

Q = √(C1/C2) / 2，反过来写就是 C1/C2 = 4Q²

要 Q = 0.707（巴特沃斯）：C1/C2 = 4 × 0.707² = 2，即 C1 取 C2 的两倍。这就是为什么你在很多资料里看到「SK 低通用 10nF + 20nF」这种搭配。

要 Q = 0.577（贝塞尔）：C1/C2 = 1.33；要 Q = 1（轻微隆起 0dB）：C1/C2 = 4。

陷阱提醒：等值 C1 = C2 时 Q = 0.5，两个极点重合在临界阻尼上，fc 处衰减达 −6dB，过渡带比想象中宽——「两个电容取一样」不是巴特沃斯，这是新手最常犯的错。

拓扑一的变化：带增益的 Sallen-Key（VCVS 增益版）

如果不想用两个不同容值的电容（BOM 里多一种料号、贴片成本上升），可以让两个电容取相同值，改用电阻分压给运放设置增益 K 来造 Q：

   R1 = R2 = R ，C1 = C2 = C

   Vin ──[ R ]──┬──[ R ]──┬───────────┐
                │         │           │
               ─┴─ C       │          │
               ─┬─         │          │
                │          │          │
                └──────────┘          │   C 的另一端接输出
                                      │
                          ┌───────────┴───┐
                          │  (+)          │
                          │   运放         ├──── Vout
                          │  (−)───┬──────┤
                          └────────┼──────┘
                                   │
                              ┌────┴────┐
                              │  同相端 │  分压网络：增益 K = 1 + Rb/Ra
                              │  Rb  Ra │
                              └────┬────┘
                                  GND

   设计公式：
     fc = 1/(2πRC)                  ← 等值设计下非常干净
     Q  = 1/(3 − K)   等价于   K = 3 − 1/Q

用这个式子算一下：Q = 0.707 时 K = 3 − 1/0.707 = 1.586，也就是 Rb/Ra = 0.586（比如 Ra = 10kΩ、Rb = 5.86kΩ，取标准值 5.9kΩ 或 5.6kΩ 再反过来验算 Q）。

这个式子同时告诉你一个危险信号：K 越接近 3，Q 越趋向无穷大。K = 3 时分母为零，电路会直接自激振荡；K 略小于 3 时，Q 高达十几，fc 附近会鼓出一个大大的尖峰，任何一点元件误差或温漂都可能让它变成振荡器。所以教科书的结论是：SK 增益版的增益不要贪心，K 控制在 1 ~ 2 之间（对应 Q ≈ 0.5 ~ 1）最稳。想要高 Q，用下面要讲的 MFB 拓扑更合适。

拓扑二：多重反馈 MFB（反相结构）

MFB 把运放接成反相放大，用 3 个电阻 2 个电容实现二阶节。名字里的「多重反馈」指的是从输出回到反相输入端有两条以上的路径：一条经过 R2、R3，一条经过 C1。它的元件数和 SK 完全一样（3R + 2C + 1 运放），但特性互补：

                                                     C1
                              ┌──────────────────────┤├───────────┐
                              │                                  │
   Vin ──[ R1 ]───┬───[ R3 ]──┴───┬──────────────────────────────┤
                  │     A        │   B（运放反相输入端，虚地）   │
                 [ R2 ]          │            ┌─────────────────┴──┐
                  │              └────────────┤ (−)                │
                  │                           │       运放          ├──── Vout
                 ─┴─ C2                       │ (+)                │
                 ─┬─                          └─────────┬──────────┘
                  │                                     │
                 GND                                  Vref

   连接清单（照这个接，别照图的走向猜）：
     ① Vin ── R1 ── 节点 A          ④ 节点 A ── R3 ── 节点 B（反相输入端）
     ② 节点 A ── C2 ── GND          ⑤ 节点 B ── C1 ── Vout
     ③ 节点 A ── R2 ── Vout         ⑥ 同相输入端 ── Vref（单电源时取 VDD/2）

同样的两步节点法可以推出它的传递函数（节点 B 是虚地，电压为 0，这是推导能变简单的关键）：

节点 B（虚地，V_B = 0）：
   (0 − V_A)/R3 + (0 − Vout)·sC1 = 0     →   V_A = −s·C1·R3·Vout

节点 A：
   (V_A − Vin)/R1 + V_A·sC2 + V_A/R3 + (V_A − Vout)/R2 = 0

把 V_A 代入并整理：

   H(s) = −(R2/R1) / [ 1 + s·C1·(R2 + R3 + R2·R3/R1) + s²·C1·C2·R2·R3 ]

   直流增益 A0 = −R2/R1                        ← 反相（负号）
   ωc = 1 / √(C1·C2·R2·R3)                     ← 同样是四个元件乘积开方
   Q  = √(C2·R2·R3/C1) / (R2 + R3 + R2·R3/R1)  ← R3 出现在这里，用来单独调 Q

   等阻值设计 R1 = R2 = R3 = R（最省事的做法）：
     A0 = −1
     fc = 1/(2π·R·√(C1·C2))
     Q  = √(C2/C1) / 3        反过来写：C2/C1 = 9Q²

注意 MFB 里 Q 的调节旋钮是电容比值 C2/C1，而且要取 C2 = 9Q²·C1：Q = 0.707 时 C2/C1 = 4.5（比如 C1 = 10nF、C2 = 47nF，比值 4.7，对应 Q ≈ 0.72）。等值电容时 Q 只有 1/3，比 SK 的 0.5 还「钝」——所以无论哪种拓扑，「元件全取一样值」都得不到平坦的巴特沃斯响应。

典型用途ADC 前端、音频输入、需要同相且高输入阻抗的场合要求高 Q、增益小于 1、或不想被输入信号幅度限制的场合

给单片机项目的实用建议：传感器 → ADC 的前端，优先用单位增益 Sallen-Key。理由有三个：输入阻抗高（不会给传感器加载）、对运放带宽要求最低、增益为 1（不会把信号顶到电源轨上）。如果你需要同时做反相和增益，或者 Q 要求大于 1 很多，再换 MFB。

元件选型：滤波器的精度几乎全在电容上

电阻容易做到 1% 精度，温度和电压对它的影响也小；电容就不一样了。千万不要用 Y5V、Z5U 这类高介电常数瓷片电容做滤波器——它们的容量随温度和直流偏压能变 ±20% 以上，你的 fc 和 Q 会随温度一起漂。

滤波器里请用 C0G/NP0 瓷片电容（温度系数极小、几乎无压电效应）或者薄膜电容（如涤纶、聚丙烯）。容值误差选 5% 以内，电阻用 1% 金属膜。元件贵一点点，但你省下的是「电路时好时坏」这种最难查的故障。

还有一个实践小技巧：把 fc 设计得比需求高 20% ~ 50%，再用两个小电阻（比如 1kΩ + 100nF）在 ADC 引脚处补一级一阶低通。二阶滤波器的元件容差会让实测 fc 偏离设计值，留出余量比死抠计算值更靠谱。

巴特沃斯 / 切比雪夫 / 贝塞尔：同一个 fc，三种 Q，三种脾气

上一小节反复出现 Q，现在把它的物理意义彻底说清楚。Q 是「品质因数」，在二阶低通里它只有一个作用：决定 fc 附近是鼓起、平坦还是下垂。前面已经推出 |H(fc)| = A0·Q，于是：

  • Q < 0.707：fc 处已经衰减超过 3dB，曲线是「软塌塌」地滑下去（过阻尼）。
  • Q = 0.707：fc 处恰好 −3dB，通带内最平坦，没有任何隆起。这就是巴特沃斯。
  • Q > 0.707：fc 处出现增益尖峰，Q 越大尖峰越高、越尖（欠阻尼）。高 Q 换来的是过渡带更陡。

另一个常用的参数是阻尼系数 ζ（读作 zeta），它和 Q 的关系是倒数一半：ζ = 1/(2Q)，也就是 ωc/Q = 2ζωc。用 ζ 描述时：ζ = 1 是临界阻尼（两个极点重合），ζ < 1 是欠阻尼（会振铃），ζ > 1 是过阻尼。两种说法完全等价，看到哪个都别慌：

这张表里「阶跃响应过冲」的数字不是编的，它来自欠阻尼二阶系统的标准公式 过冲 = e^(−πζ/√(1−ζ²))。它的实践意义很直接：你在频域上追求陡峭，在时域上就会得到振铃。如果信号是方波、脉冲、或者你要测脉冲的峰值，这一点会直接毁掉测量结果。

「群延迟」是什么，为什么值得单独列一栏？简单说，它衡量的是「不同频率的成分经过滤波器后，各自被延迟了多久」。如果各频率的延迟不一样（群延迟不平坦），那么一个方波进来，它的高频成分（决定边沿）和低频成分（决定平顶）就会被延迟不同的时间，结果是：边沿变圆、平顶出现振铃、脉冲峰值测不准。阶数越高、Q 越高，群延迟在 fc 附近的波动越大。

所以选型的逻辑可以写成一句话的决策：

信号的【形状/峰值】重要吗？
   ├── 重要（脉冲、方波、多通道相位一致）
   │        └── 选【贝塞尔】（Q = 0.577，无过冲，但过渡带最缓）
   │
   └── 不重要，只要把干扰压下去
            ├── 过渡带够用就行 → 选【巴特沃斯】（Q = 0.707，最通用）
            │
            └── 干扰离信号太近、过渡带必须更陡
                     └── 选【切比雪夫】（Q 抬高，接受通带纹波与振铃）
                             或更稳妥的做法：【提高阶数】
                             （四阶巴特沃斯 = 两节二阶级联，比单节高 Q 更稳）

最后这句「提高阶数比提高 Q 更值得」是实际工程里最重要的经验：单节 Q 越高，对元件容差越敏感（Q 的误差大约按 Q 的倍数被放大），Q 到十几以后，5% 的电容误差就能让你做的滤波器在「尖峰」和「振荡」之间摇摆。所以真正需要陡过渡带时，正确做法是做四阶甚至六阶，让每节的 Q 保持在 1 附近：

四阶巴特沃斯低通 = 两节二阶级联，各自 fc 相同，Q 不同：

   第 1 节  Q1 = 0.541     ──►     第 2 节  Q2 = 1.307     ──►
   （过阻尼，最钝）                 （欠阻尼，贡献陡度）
   总衰减速率：−80dB/十倍频

为什么这么分配？
   · 单个 Q = 1.307 的节，fc 处有 +2.3dB 的鼓包，单独看不「平坦」
   · 但它的鼓包正好补上第一节在 fc 附近的下垂，两者相乘才得到平坦的四阶响应
   · 逐节相乘 = 对数域里逐节相加 → 这就是「用两节拼出更陡的砖墙」

实践建议：
   ① 把 Q 低的那一节放在【前级】：前级处理的信号幅度最大，
      低 Q 不会有尖峰，不容易把后级顶到电源轨上
   ② 每节之间信号幅度会变，单电源时要检查是否有哪一节提前饱和
   ③ 四阶巴特沃斯的常用 Q 分配：0.541 / 1.307
      六阶：0.518 / 0.707 / 1.932

至于「我这辈子到底要用几阶」，答案从来不是拍脑袋定的，而是从指标反推出来的标准流程——这正是下一个小节的内容。

压控电压源滤波器的设计步骤：先定 fc 与 Q，再算元件

前面把原理讲完了，这一小节把它变成一张「照着做就行」的流程。设计的正确顺序是先定指标，再定阶数，再定 fc 与 Q，最后才动元件值——很多同学反着来，先翻出一张「经典电路图」抄元件，结果 fc 对不上、Q 也不对，还找不到原因。

【第 0 步】写清指标（这是所有设计的起点，缺一个都会返工）
   · 有用信号的最高频率 f_sig        （比如传感器信号带宽 0 ~ 100Hz）
   · 需要被压住的干扰频率 f_stop     （比如 fs/2 = 5kHz，或某个开关噪声）
   · 该频率处至少衰减多少 dB  A_stop  （比如 40dB）
   · 通带增益 A0（要放大还是只要 1 倍）
   · 电源与信号摆幅（单 3.3V？信号是否带直流偏置？）

        │
        ▼
【第 1 步】算阶数 n
   巴特沃斯 n 阶的近似衰减：  A(f) ≈ 20·n·lg(f_stop / fc)  dB
   让 fc 略高于 f_sig（一般取 fc = 1.2 ~ 1.5 × f_sig，把 −3dB 的损失让出来）：
        n ≥ A_stop / (20·lg(f_stop / fc))
   算出小数就向上取整：1.3 → 2 阶，2.4 → 3 阶（实用上取 4 阶，用两节二阶拼）
   ★ 留余量：巴特沃斯在 fc 附近的衰减比渐近线【慢】，实际要再宽 10% ~ 20%

        │
        ▼
【第 2 步】定 fc 与每节的 Q
   单节：Q = 0.707（巴特沃斯）；带宽优先用贝塞尔时 Q = 0.577
   两节：按高阶分配的 Q 表取值（四阶巴特沃斯：0.541 / 1.307）

        │
        ▼
【第 3 步】先选电容，再算电阻（顺序不能反！）
   理由：电容的标称值系列比电阻粗得多，先定电容才好凑出需要的比值。
   · Sallen-Key 等值设计： C1 = 4Q²·C2
        Q = 0.707 → C1 = 2·C2     Q = 0.577 → C1 = 1.33·C2
   · 电容取值范围： 1nF ~ 1µF，最常用 4.7nF / 10nF / 22nF / 47nF / 100nF
        太小（几百 pF 以下）会被 PCB 寄生电容和运放输入电容影响
        太大（1µF 以上）体积大、漏电流大、介质吸收明显

        │
        ▼
【第 4 步】算电阻，取标准值（E24 系列，1% 金属膜）
   Sallen-Key： R = 1 / (2π·fc·√(C1·C2))
   取值范围： 1kΩ ~ 1MΩ，最常用 4.7kΩ ~ 100kΩ
        太小 → 前级要输出很大电流，且分压误差变大
        太大 → 运放输入偏置电流在它上面产生的误差电压变大

        │
        ▼
【第 5 步】验算（用取整后的标准值反算，这一步千万别省）
   ① 反算 fc、Q，确认 A_stop 仍然满足
   ② 检查信号摆幅：单电源 3.3V 时，输出不能接近 0V 或 3.3V（运放有摆幅损失）

        │
        ▼
【第 6 步】选运放
   · 增益带宽积 GBW ≥ 100 × fc（高 Q 时要求更高，取 200 倍更保险）
   · 单位增益稳定（做跟随器时必须确认！）
   · 单电源场合选轨到轨输入/输出（RRIO）的型号，如 MCP6001、TLV9051 等
   · 压摆率够用：SR ≥ 2π·fc·V_pp（V_pp 是输出峰峰值）

        │
        ▼
【第 7 步】偏置、去耦、布板
   · 单电源：同相端偏置到 VDD/2，分压电阻并联 100nF ~ 1µF 到地
   · 运放电源引脚旁放 100nF（靠近引脚）+ 10µF
   · 滤波器输入/输出走线短，远离 PWM、DC-DC、晶振

第 3 步和第 4 步里提到的「标准值」不是随便取的。E24 系列（1% 精度）是我们最常用的：每十倍频程里有 24 个值，比值约为 1.10。常用电阻值：1.0 / 1.1 / 1.2 / 1.3 / 1.5 / 1.6 / 1.8 / 2.0 / 2.2 / 2.4 / 2.7 / 3.0 / 3.3 / 3.6 / 3.9 / 4.3 / 4.7 / 5.1 / 5.6 / 6.2 / 6.8 / 7.5 / 8.2 / 9.1（乘以 10 的幂）。常用电容值：1.0 / 1.5 / 2.2 / 3.3 / 4.7 / 6.8（乘以 10 的幂），所以 10nF、22nF、47nF、100nF 是最常见的「库存必备」。

单电源偏置：不要忘了信号要「抬」到中间

STM32 的 ADC 只能测 0 ~ 3.3V，而传感器的交流信号往往是以 0V 为中心的（有正有负）。用单电源运放处理它有一个前提：把整个信号的「中心」抬到 VDD/2 = 1.65V，这样正负半周都落在 0 ~ 3.3V 之内。

                    3.3V
                     │
                    [Ra] 10kΩ
                     │
       ┌─────────────┼─────────────┐
       │             │             │
      [Rb] 10kΩ    ─┴─ 100nF    同相输入端（滤波器内部）
       │            ─┬─          （偏置点 = 1.65V）
      GND            │
                    GND

   要点：
     ① 分压点电压 = 3.3V × Rb/(Ra+Rb) = 1.65V（Ra = Rb 时正好一半）
     ② 必须在分压点并一个电容（100nF ~ 1µF）到地：
        分压点的等效源阻抗 = Ra∥Rb = 5kΩ，太大；电容把它在高频端「变低」
        否则电源上的噪声会直接从偏置网络漏进同相端，被滤波器原样放大
     ③ Ra、Rb 取值别太大：两只 1MΩ 电阻分压时，运放的输入偏置电流
        （拿 LM358 说，典型几十 nA）就会在 500kΩ 上产生几十 mV 的偏移误差
     ④ 偏置点也要考虑前后级一致：ADC 读到的将是 1.65V + 交流信号
设计时最容易翻车的三件事

第一，电容选错介质。前面说过，Y5V/Z5U 的容量随电压和温度剧烈变化，用它做的滤波器等于「随温度漂移的滤波器」。滤波器电容必须用 C0G/NP0 或薄膜电容。

第二，忘了算运放的输出摆幅。很多运放（尤其是老型号如 LM358）输出高电平只能到 VDD − 1.5V，输出低电平也只能到 20mV 左右（不是 0V）。3.3V 供电时，输出实际上只能覆盖 0.02V ~ 1.8V 这一段——如果信号摆幅设计成 0.5 ~ 3.0V，上半周会被硬生生削平，而且你从波形上看不出「是运放削的」还是「是滤波器坏的」。

第三，滤波器输出直接接 ADC 引脚却不留任何余量。ADC 采样瞬间会从引脚「抽走」一小口电荷给内部采样电容充电，如果信号源阻抗偏高、采样时间又设得太短，读数会系统性偏低。解决办法在第 4 节详细讲：让滤波器输出走运放的低阻输出，再串一个小电阻 + 引脚处并一个小电容。

抗混叠滤波器：为什么必须在 ADC 之前，而且必须在采样之前

这是整篇里最容易被忽视、后果最严重的一个知识点。先把采样定理的「工程版」摆出来：

采样定理的工程版

课本版：采样频率 fs 必须大于信号最高频率的两倍（fs ≥ 2·f_max），否则会发生混叠。

工程版（更重要）：上面的条件只是「不丢失信息」的必要条件，实际工程里你会希望 fs ≥ 5 ~ 10 × f_max，因为：

· fs/2 和 f_max 之间必须留出一段过渡带给抗混叠滤波器把干扰压下去；
· 采样点太少时，一个周期只有两三个点，任何采样时刻的抖动都会造成很大的幅度误差；
· 后级数字滤波（平均、FIR）需要有冗余数据才能减小随机噪声。

结论：抗混叠滤波器的存在，才是「采样定理能用」的前提。没有它，fs 再高也只是把混叠发生的地点换了个频率而已。

混叠是怎么发生的：把频率轴当成一根反复折叠的纸条

把频率轴想成一根纸条，采样把纸条以 fs 为周期反复折叠：

   ...├───────────┼───────────┼───────────┼───► 真实频率
      0          fs/2         fs        3fs/2
                 ↑            ↑
           奈奎斯特频率    采样频率
           （fs/2）         （fs）

规则：任何高于 fs/2 的成分，都会以 fs/2 为折痕翻折下来
   · fs/2 ~ fs    → 镜像折到 0 ~ fs/2
   · fs ~ 3fs/2   → 再折一次，还是落在 0 ~ fs/2 里
   · 公式：f_alias = | f_in − k·fs |，k 取使结果落在 0 ~ fs/2 的整数

fs = 10kHz（奈奎斯特 = 5kHz）时的三个例子：
   真实频率 10.05kHz  →  |10050 − 10000| = 50Hz   ← 落进信号频段，最危险
   真实频率 9.2kHz    →  |9200 − 10000|  = 800Hz
   真实频率 5.0kHz    →  正好在折痕上，相位最不稳定的临界点

第一行为什么「最危险」？因为你的有用信号正好在 0 ~ 100Hz。开关电源的开关频率通常在几十 kHz 到几百 kHz，它的谐波有一大堆可能正好落在 k·fs ± (0~100Hz) 这个位置上——一旦落进去，你在串口上看到的就是一个完美的、稳定的、看不出任何异常的 50Hz 信号，而它其实是完全虚假的。这类问题极难在软件里查出来，因为从数据上看不出任何破绽。

为什么软件滤波救不回来：两行数学就够了

很多同学的第一反应是「那我采样之后在程序里做个数字低通，把高频滤掉不就行了」。这个想法错在把混叠当成了噪声——它不是噪声，是信息丢失。看下面这个证明：

假设 fs = 10kHz，采样时刻是 t = n/10000 秒（n = 0, 1, 2, 3 ...）

  真实的 50Hz 信号：   x(t) = sin(2π·50·t)
  10.05kHz 的干扰：    y(t) = sin(2π·10050·t)

把采样时刻代进 y(t)：

  y(n/10000) = sin(2π·10050·n/10000)
             = sin(2π·50·n/10000 + 2π·n)       ← 10050 = 50 + 10000
             = sin(2π·50·n/10000)              ← 因为 sin 的周期是 2π
             = x(n/10000)

结论：两个完全不同的物理信号，在第 n 个采样点上取值【完全相同】。
      也就是说，ADC 送给程序的两串数字一模一样。

   → 数字滤波器拿到的是同一串数字，无论怎么写都不可能分出「哪个才是真的」
   → 混叠发生在【采样那一刻】，ADC 之前没挡住，ADC 之后就永远补不回来

这就是「抗混叠滤波器必须在 ADC 之前」的全部理由。它必须是一个模拟滤波器，接在传感器和 ADC 引脚之间；位置也不能颠倒——如果先过一个缓冲器、再经过一段长走线、最后才进 ADC，那走线上拾取的高频噪声一样会折叠进去。

那为什么现在的 ADC 好像都不需要它了？

你可能会问：既然混叠这么可怕，为什么很多芯片（包括 STM32）的手册里都不强调要加抗混叠滤波器？答案是过采样和 ΣΔ 架构把这件事搬到了芯片内部，而不是取消了它：

ADC 类型采样机制抗混叠怎么处理你要做什么
逐次逼近型 SAR
（STM32 的 ADC 就是这类）		 采样瞬间把引脚电压接到内部采样电容（几个 pF）上 没有任何内部抗混叠，采样开关的带宽高达几十 MHz，什么高频都能折叠进来 必须在外部加 RC 或二阶有源低通，并在引脚处放小电容
ΣΔ（sigma-delta）
（如 HX711、ADS1256）		 内部以很高的频率过采样（几百 kHz ~ MHz），再做数字滤波抽取 数字滤波器本身就完成了抗混叠，模拟端只需要很简单的 RC 外部只需一个 RC（甚至一个电容）；但要满足它的输入阻抗要求
带过采样的 SAR
（STM32 的 ADC 硬件过采样）		 硬件连续采多次求平均 只能把「白噪声」平均掉一部分，对已经折进来的混叠分量无能为力 仍然需要外部抗混叠滤波器，别指望过采样顶替它

所以正确的认知是：ΣΔ ADC 把抗混叠「内置」了，SAR ADC 把它留给了你。你手上这块 STM32 用的正是 SAR，所以外部抗混叠滤波器不是「可选优化」，而是「原理上必需」。

fc 怎么定：从指标反推，而不是拍脑袋

抗混叠滤波器的截止频率并不是「越低越好」，它被三件事夹在中间：

        低频 ←───────────────────────────────→ 高频
              │                │              │
        信号带宽 f_sig   截止频率 fc      奈奎斯特 fs/2
              │                │              │
   约束①：fc 必须【高于】f_sig，且留足余量
          fc ≥ 1.2 ~ 1.5 × f_sig
          否则有用信号的高频成分被衰减，幅度和相位都会失真

   约束②：fc 必须【远低于】fs/2，并在 fs/2 处提供足够的衰减
          在 f = fs/2 处要满足  A(fs/2) ≥ A_stop（比如 40dB）

   约束③：阶数 n 要足够，才能同时满足①②
          一阶：20dB/十倍频  二阶：40dB/十倍频  四阶：80dB/十倍频

   把①②③一起解，就得到阶数和 fc：
      一阶：只要 5kHz/50Hz = 100 倍频程 → 信号被砍 −7dB（不可接受）
      二阶：只要 5kHz/500Hz = 10 倍频程 → 信号几乎无损（这就是答案）

第 3 节的例题①会把这三条约束完整地算一遍，第 4 节则把算出来的元件值接到 STM32 的 ADC 上。

还有一件事：STM32 的 ADC 引脚处还需要一个小 RC

抗混叠滤波器负责「把高频挡在外面」，但它不负责「让 ADC 采样瞬间拿得到足够的电荷」。SAR ADC 的采样开关一闭合，内部采样电容（STM32F103 典型值约 8pF）要在很短的采样时间里充到引脚电压。如果信号源阻抗偏高，就会出现「充不满 → 读数偏低」的系统误差。

标准做法是在 ADC 引脚处放一个电荷桶：串联 100Ω ~ 1kΩ，对地并 1nF ~ 10nF（C0G）。这个小电容在采样瞬间充当「近处的电荷仓库」，同时它和串联电阻又构成一级额外的一阶低通（比如 1kΩ + 10nF，fc ≈ 15.9kHz），替你把高频再压一层。

另外，STM32 的 ADC 采样时间要设得足够长（常用 71.5 或 239.5 个 ADC 时钟周期），并注意手册里给的「最大允许信号源阻抗 RAIN」表——采样时间越短，允许的源阻抗越小，几个 ADC 周期时只有几百欧姆。

电压比较器：单限、滞回、窗口、过零，以及为什么不能用运放凑合

滤波器解决的是「信号干不干净」，比较器解决的是「信号有没有越过某条线」。它看起来简单到不像一个知识点——确实，单限比较器的原理一句话就能说完。但真正上板子以后，坑几乎全在细节里：为什么输出要加上拉电阻？为什么按键信号必须加正反馈？为什么运放不能当比较器用？这几个问题串起来，正好是一套完整的模拟前端知识。

单限比较器：一个阈值，两个状态

单限比较器只有一个门槛电压，输出只有两种可能的状态。它的核心器件是专用比较器芯片（不是运放），最经典的是 LM393（双路）和 LM339（四路）：

                3.3V
                 │
                [Rp] 10kΩ          ← 上拉电阻，必须有！
                 │
   传感器 ───┬────┤+         ┌─────────────── 输出（接 STM32 的 GPIO / EXTI）
   信号     │    │   LM393  │
            │    │   一半   │
   基准 ────┴────┤−         │
   Vref         └───────────┘
                 （另一路比较器不用时，输入端接地、输出悬空即可）

  工作逻辑（注意 LM393 是【开漏/开集】输出，逻辑和运放相反的感受）：
     V(+) 大于 V(−)  →  输出管截止  →  上拉电阻把输出拉高到 3.3V（高电平）
     V(+) 小于 V(−)  →  输出管导通  →  输出被拉到 GND（低电平，可灌 16mA）

  门限： V(+) 超过 Vref 就翻转，Vref 由分压或基准芯片给出

单限比较器的致命问题在于「阈值只有一条线，而现实里的信号在阈值附近从来不是干净的」。当输入信号缓慢地爬过 Vref 时，任何一点噪声、工频感应、电源纹波都会让它反复穿越这条线：

        Vref ┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈      ┌┐  ┌┐┌┐   ┌┐┌─┐
              ╱╲   ╱╲╱╲  ╱╲  ╱           ││  ││││   │││ │
     ────────╱  ╲╱     ╲╱  ╲╱            ┘└──┘└┘└───┘└┘ └────
          ╱                            
        ╱      ↑ 这一小段里，信号穿越了阈值 7 次
      ╱        每次穿越都会让输出翻转 → 7 个边沿 → 7 次中断
    ╱

  如果这个输出接的是 STM32 的 EXTI（外部中断）：
     · 一次按键 → 一串中断（按键的机械触点本来就会抖动 5 ~ 20ms）
     · 一路正弦波 → 在过零点附近疯狂触发，计数完全错乱
     · 转速测量 → 读数直接翻几倍甚至几十倍
     · 中断服务函数里如果有打印、HAL_Delay 之类的慢操作 → 程序卡死在中断里

解决办法只有一个方向：让比较器自己「记一点历史」——用正反馈造出一个滞回窗口。这就是下一小节的施密特触发器。先把「运放能不能顶替比较器」这件事说清楚，因为这是新手最容易犯的错。

为什么运放不能当比较器用（五个具体问题）

「运放有两个输入端，接上正反馈不就是一个比较器吗？」——在很多老教材的例题里确实这么画，因为原理上它是成立的。但在工程上，用通用运放当比较器会踩到五个坑，每一个我都给你具体数字：

问题具体表现专用比较器为什么没这个问题
饱和恢复慢 运放为了稳定，内部有相位补偿电容。输出一旦「贴着电源轨饱和」，再想退出来就要给补偿电容充放电，大信号阶跃的恢复时间能到几微秒到几十微秒 比较器内部不做频率补偿，输出级工作在开关状态，响应时间以纳秒计（LM393 典型 1.3µs，TLV3501 可到 4.5ns）
输出电平对不上逻辑 LM358 在 3.3V 供电时，输出高电平典型只有 VDD − 1.5V ≈ 1.8V 左右，而 STM32 的输入高电平门限 VIH 是 2.0V——正好卡在门槛下面，GPIO 可能一直读到 0 开漏输出配 3.3V 上拉，高电平就是干净的 3.3V；推挽输出的比较器也有轨到轨的型号
没有内部滞回 通用运放的输入失调温漂、噪声都不受控，阈值附近必然抖动；而给运放加正反馈又容易引发自激（它本来是按负反馈设计的） 多数专用比较器带内置迟滞（如 MCP6541 约 3mV 典型值），外加正反馈做滞回也是官方推荐用法
大差分输入会顶到输入保护 比较器应用时两个输入端可能相差好几伏（比如信号 5V、基准 0.5V）。运放输入端通常有背靠背保护二极管，这个压差会让二极管导通、输入级进入非正常状态，轻则恢复更慢，重则损坏 比较器允许输入端出现大差分电压（LM393 允许 ±36V 的差模输入），驱动能力也按这个场景设计
速度受压摆率限制 LM358 的压摆率典型 0.3V/µs，输出从 0V 跳到 3.3V 需要约 3.3 ÷ 0.3 = 11µs（考虑过冲按 3.6V 算约 12µs）。信号频率稍高，输出就变成三角波，边沿时间比信号周期还长 比较器按「大信号开关」设计，不受运放那种小信号压摆率约束
一句话总结

运放是「让输出等于输入的某种函数」，比较器是「让输出在两条电源轨之间跳」。它们的内部分工完全不同：运放要的是线性度和稳定性，比较器要的是速度和确定的开关状态。单片机项目里还请老老实实用 LM393 / LM339 / TLV3501 这类专用件。

LM393 是学生项目里用得最多的比较器，它的关键参数值得记下来（都是数据手册上的典型值，型号后缀不同会有差别）：

参数典型值 / 范围对你的设计意味着什么
输出结构开集（开漏）必须外接上拉电阻，否则高电平悬空
供电范围2V ~ 36V（单电源）3.3V 单电源完全可用
响应时间1.3µs（典型）能处理几十 kHz 的方波信号；测转速足够

滞回比较器（施密特触发器）：把一条线变成两条线

滞回比较器的思路是：让阈值本身跟着输出一起变。输出高的时候用一个「高一点的门槛」，输出低的时候用一个「低一点的门槛」，两条线之间就是死区——噪声幅度只要小于死区宽度，就永远翻不过去，输出自然干净。

实现方法是正反馈：从输出端拉一只电阻回到同相输入端。这一点和运放的负反馈恰好相反，也是它被称为「施密特触发器」的原因。

                     3.3V
                      │
                     [Rp] 10kΩ      ← 开漏输出的上拉电阻
                      │
                      ├──────────────┐
                      │              │
    输入 Vin ────[R1]──┼───┬──────────┼──── Vref（基准电压）
                      │   │          │
                      │   │      ┌───┴───────────┐
                      │   └──────┤+              │
                      │          │     LM393     ├──── 输出 Vout
                      │     ┌────┤−              │
                      │     │    └───────────────┘
                      │     │
                      └──[Rf]┘        ← 正反馈电阻：把输出「拉回」同相输入端
                      （Rf 接在输出与同相端之间）

   元件角色：
     R1  输入电阻，和 Rf 一起决定滞回窗口宽度
     Rf  正反馈电阻，越大 → 窗口越窄；越小 → 窗口越宽
     Vref 接在反相端，决定【窗口的中心位置】

两个阈值怎么推？用叠加原理就够了：同相端的电压是「输入 Vin 通过 R1」和「输出 Vout 通过 Rf」两个电源共同作用的结果，而比较器翻转的条件永远是同相端电压等于反相端电压（Vref）。把 Vout 的两种取值分别代进去，就得到两条阈值线：

同相端电压（把 Vin 和 Vout 看成两个源，用叠加）：

   V+ = Vin × Rf/(R1+Rf)  +  Vout × R1/(R1+Rf)

翻转条件：  V+ = Vref

① 当输出为【低】电平 VOL 时，输入必须上升到 V_TH 才翻转：
      V_TH × Rf/(R1+Rf) + VOL × R1/(R1+Rf) = Vref
   →  V_TH = Vref × (1 + R1/Rf) − VOL × R1/Rf
   （推导：两边乘 (R1+Rf)/Rf，把 VOL 项移过去）

② 当输出为【高】电平 VOH 时，输入必须下降到 V_TL 才翻回来：
   →  V_TL = Vref × (1 + R1/Rf) − VOH × R1/Rf

滞回窗口宽度（两式相减，Vref 项消掉）：
      ΔV = V_TH − V_TL = (VOH − VOL) × R1 / Rf

窗口中心：
      V_center = Vref × (1 + R1/Rf) − (VOH+VOL)/2 × R1/Rf

   ★ 注意：VOH 指的是上拉电源电压（3.3V），VOL 是开漏管导通时的
     饱和压降（LM393 灌电流很小时约 0.1 ~ 0.25V，取 0.15V 估算）

由指标反推元件（实用设计顺序）：
   ① 先定窗口宽度 ΔV  →  取 R1 = 10kΩ，则 Rf = (VOH − VOL) × R1 / ΔV
   ② 再定窗口中心      →  Vref = [V_center + (VOH+VOL)/2 × R1/Rf] / (1 + R1/Rf)
   ③ Rf 并一个小电容（10nF 量级）可以进一步抑制边沿毛刺（可选）

顺便体会一下这个电路的物理意义：R1 和 Rf 组成的是一个「把输出的一部分送回输入端」的分压器。因为送回的是同相端，它是正反馈；正反馈系数越大（R1/Rf 越大），窗口就越宽。极限情况下如果 Rf 开路，正反馈消失，电路就退化成单限比较器——这也是为什么「不加 Rf 就等于把滞回窗口设成了 0」。

为什么按键和长线必须用滞回，而不是单限

这一段给两个真实的量级推演，你以后判断「要不要加滞回」时可以直接套：

场景一：机械按键。按键和拨动开关的触点在闭合瞬间会有 5 ~ 20ms 的机械抖动（典型按 10ms 估）。在这 10ms 里，触点电压可能已经「越过阈值」了十几次。如果比较器是单限的，每次抖动的反弹都会在输出上多出一个边沿；STM32 若配置成双边沿触发，一次按下就能进十几次中断。加上 200mV 的滞回之后，触点抖动通常只有几十 mV 的幅度（因为上拉电阻和触点电阻的分压在接触瞬间变化有限），根本翻不出滞回窗口，输出只剩一个干净的下降沿。

场景二：长线传输的慢变信号。传感器离板子两米远，走的是普通杜邦线，没有屏蔽。线上的工频感应和开关噪声很容易做到 20 ~ 100mV 的峰峰值，而信号本身可能只是每秒变化 1V 的缓慢电平（比如温度、液位）。我们来算一下不加滞回会发生什么：

已知：
   信号变化速率  dV/dt = 1 V/s（缓慢上升的传感信号）
   阈值附近的噪声峰峰值 Vn = 20mV
   噪声带宽（受前级运放和后级比较器限制）约 B = 10kHz
   噪声在阈值附近的穿越速率约为 B 的千分之几 ~ 十分之几，按 2kHz 保守估

计算信号「待在阈值附近」的时间：
   T = Vn / (dV/dt) = 20mV ÷ 1V/s = 20ms

在这 20ms 内，噪声以约 2kHz 的速率来回穿越阈值：
   边沿数 ≈ 2000 × 0.02 = 40 个边沿

   → 一次「信号缓慢过阈值」，产生约 40 次 EXTI 中断
   → 如果中断里还有串口打印（每次 100µs），20ms 内要占用 4ms 的 CPU
   → 如果信号在这条线附近停留（比如电池电压正好在阈值上），中断会【持续不断】

加上 210mV 的滞回窗口后：
   噪声只有 20mV，连窗口的十分之一都不到 → 额外边沿数 = 0

所以判断标准很朴素：只要信号在阈值附近的停留时间远远大于噪声周期（也就是信号「不够陡」），就必须用滞回。正弦波在过零点的斜率是最陡的，也照样会抖——因为它每次穿越阈值时，穿越时间同样取决于噪声幅度与信号斜率的比值。

滞回窗口不是越大越好

窗口宽了抗干扰强，但它同时吃掉了信号的一部分动态范围。如果信号的整体摆幅只有 200mV，而你把滞回窗口设成了 300mV，那么输出会「锁死」在某个状态再也不翻转——因为信号无论怎么走，都凑不出足够大的变化去穿越另一条阈值线。

经验值：滞回窗口取预期噪声峰峰值的 3 ~ 10 倍，同时不超过信号有效摆幅的 1/3 ~ 1/5。两头都要留余量，这就是第 3 节例题③要算的东西。

开漏输出：为什么必须上拉，而且上拉到 3.3V 而不是 5V

LM393 的输出级是一只 NPN 三极管的集电极开路（开漏）结构，它只有两种状态：导通（把输出拉到地）和截止（输出对外呈高阻，什么都不做）。它自己没有能力输出高电平——高电平是上拉电阻「外面给的」。

所以：不加上拉电阻，输出高电平就是悬空。悬空的引脚电压不确定，STM32 读到的值会随环境漂移（有时候手靠近就会跳变），而且悬空输入会让 CMOS 输入级处于中间电平、额外消耗电流。这不是「可以省掉的小元件」，是必须有的。

那上拉到多少伏？答案是拉到 3.3V，也就是和单片机同一套电源，原因有三条：

  • ① 逻辑电平要匹配。上拉到 3.3V，高电平就是 3.3V，远高于 STM32 的 VIH（2.0V），低电平是 0V 左右，余量充足。上拉到 5V 则会让 GPIO 承受 5V——大多数 STM32 引脚虽然有「FT（5V 容忍）」标注，但那是作输入时的容忍度，且需要在数据手册里查具体引脚；接上拉后它是被外部电路持续注入电流的，一旦遇到非 FT 引脚（比如某些模拟相关引脚）就会损坏。
  • ② 上下电顺序问题。如果比较器电路用 5V 供电、上拉到 5V，而 STM32 的 3.3V 还没建立（或者被复位拉低），5V 会通过 10kΩ 电阻往 GPIO 的输入保护结构里灌电流，形成「倒灌供电」，可能让芯片处于半死不活的状态，甚至损坏。同一套 3.3V 供电时这个问题不存在。
  • ③ 开漏上拉本身很灵活。开漏输出的好处正是「电平由你决定」：同一个 LM393 的输出可以上拉到 3.3V 给 MCU 看，也可以上拉到 12V 去驱动继电器，还能把多个开漏输出接在同一根上拉线上实现「线与」（窗口比较器就是这么做的）。

上拉电阻取多少？4.7kΩ ~ 10kΩ 是常用范围，取值要在两个方向之间权衡：

上拉电阻太大（比如 100kΩ）会怎样？

  上升沿是「上拉电阻给寄生电容充电」的过程：
     时间常数 τ = Rp × C_total
     其中 C_total 包括：GPIO 引脚电容（约 5pF）、
                      PCB 走线电容、杜邦线电容、示波器探头（10pF 以上）

  假设 C_total = 100pF（两米杜邦线的典型量级）：
     Rp = 10kΩ   →  τ = 1µs    上升时间约 2.2τ ≈ 2.2µs   ✅ 干净
     Rp = 100kΩ  →  τ = 10µs   上升时间约 22µs           ❌ 边沿变缓
     Rp = 1MΩ    →  τ = 100µs  上升时间约 220µs          ❌ 比信号周期还长

  边沿变缓的后果：
     ① 缓慢的上升沿在 STM32 输入门限附近停留很久
        → 输入级的噪声会让 GPIO 在门限附近产生多次翻转
        → 明明是比较器的一个边沿，EXTI 却触发了多次（"边沿抖动"）
     ② 如果信号频率稍高，方波会变成三角波，占空比失真
     ③ 边沿变缓还会让 EXTI 的边沿检测电路「看不准」时间戳

  所以：
     · 上拉电阻别超过 10kΩ（除非是被迫省电的低功耗设计）
     · 不要依赖 STM32 的内部上拉！内部上拉典型 30 ~ 50kΩ，
       且容差很大，边沿会明显变慢
     · GPIO 模式配成「输入浮空」（外部已有上拉），或「输入上拉」
       都可以，但外部上拉必须存在
     · 长线场景额外加 100nF 到地（构成 RC 低通），
       同时也能吸收线缆拾取的高频干扰

窗口比较器：判断「在不在区间里」

单限比较器只能回答「大于还是小于」。如果需求是「电池电压在 10.8V 到 13.8V 之间算正常」，就需要两条线——这就是窗口比较器。用两路比较器（一片 LM393 正好两路）搭出来即可：

   被测电压 Vx ──┬──────────────┬─────────────┐
   （已分压）     │              │             │
                  │              │             │
             ┌────┴─────┐   ┌────┴─────┐       │
      VH ────┤−         │   │+         ├──── VL（下阈值）
   （上阈值） │  LM393-A ├───┤  LM393-B │
             └──────────┘   └──────────┘
                  │              │
                  └──────┬───────┘      ← 两个开漏输出直接接在一起 = 「线与」
                         │
                        [Rp] 10kΩ → 3.3V
                         │
                         └──────── 送到 STM32 的一个 GPIO

   逻辑（线与后的结果）：
     两个输出都截止（都「不导通」）→ 上拉把线拉高  = 电压在窗口【内】✅
     任意一个导通（拉到地）        → 线被拉低      = 电压在窗口【外】❌

   也可以不线与，分别接两个 GPIO：
     比较器 A 输出低 → Vx 高于 VH（过压）
     比较器 B 输出低 → Vx 低于 VL（欠压）
     程序里读两个引脚就能区分「过压 / 正常 / 欠压」三种状态

这里「线与」的写法值得多说一句：因为开漏输出只能拉低、不能拉高，所以把两个（甚至更多）开漏输出接到同一根上拉线上是完全安全的——不会像推挽输出那样发生「一个输出高、一个输出低」的直接短路。谁导通谁就把线拉低，全部截止才由电阻拉高。这就是 I²C 总线和各种故障汇总线（fault line）都用开漏的原因。

过零比较器：正弦波整形的老办法

把阈值设在 0V，比较器就变成了过零检测器——输入信号每穿过一次零点，输出就翻转一次。它是把正弦波（或任何以零为中心变化的波形）整形成方波最直接的方法，常用于频率测量、相位检测和「交流信号有没有」的判断。

但过零比较器在单电源系统里有一个必须注意的坑：LM393 的输入共模范围是 0 ~ VDD − 1.5V，它可以到地，但不能低于地。如果你把一个以 0V 为中心、带负半周的正弦波直接接到输入端，负半周会被输入端的保护二极管钳位（电流灌进芯片），既测不准，时间长了还可能损坏。

  错误接法：交流信号直接进比较器
      交流信号（有负半周，最低 −2V）──────→ 比较器输入   ❌ 会灌电流

  正确接法一：把信号抬到 VDD/2，比较阈值也设成 VDD/2
      交流信号 ──[C 隔直]──┬── 比较器 Vin
                           │
                        [R 分压偏置到 1.65V]
                           │
      阈值 = 1.65V  ───────┴── 比较器 Vref
      → 相当于检测「交流信号相对 1.65V 的过零点」

  正确接法二：用双电源（±5V）供电
      比较器 V+ 接 +5V、V− 接 −5V、地做参考
      → 阈值直接设 0V 即可，最干净（但板子上要多一路负电源，成本高）

  正确接法三：输入端串限流电阻 + 钳位二极管
      交流信号 ──[10kΩ]──┬── 比较器输入
                         ├── 1N4148 → 3.3V
                         └── 1N4148 → GND
      → 限流电阻把灌入电流限制在 mA 级（保证安全），
        但负半周依然是被钳位掉的，只是「不至于烧芯片」

如果是要把一路正弦波整形后送进 STM32 的外部中断做频率测量，最省事的组合其实是：隔直电容 + 1.65V 偏置 + 过零比较器 + 少量滞回。第 4 节会给出完整的连接和代码。

比较器输出接单片机 GPIO 的三件事

从比较器输出到 STM32 的引脚，中间这三件事必须都想到，缺一件就可能在现场莫名其妙地出错：

   比较器输出 ──┬── [Rp] 10kΩ ──── 3.3V     ① 上拉（开漏输出必须有）
                │
                └───[Rs] 100Ω───┬─────────── STM32 GPIO
                                │
                               ─┴─ 1nF ~ 10nF 到地   ② 小电容：边沿整形 + 抗高频干扰
                               ─┬─
                                │
                               GND

   ③ 去抖（三道防线，可以叠加使用）：
      · 硬件滞回：把窗口设到噪声的 3 ~ 10 倍（最根本，首选）
      · 硬件 RC：Rs + C 构成低通，τ = 100Ω × 10nF = 1µs（压高频毛刺）
      · 软件去抖：中断里只置标志位；主循环或用定时器延时 10 ~ 20ms 后再确认
        （按键场景的标准做法，不要用 HAL_Delay 卡在中断里）

   在 STM32 侧的配置建议：
      · GPIO 模式：输入浮空（外部已有上拉）或输入上拉（双保险，边沿略慢一点）
      · EXTI 触发边沿：计数/测频用【上升沿】或【下降沿】单边沿即可；
        只有需要测周期/占空比时才用双边沿
      · 中断优先级：保护类信号（过压/过流）给最高优先级
      · NVIC 里别忘记使能中断，并确认 EXTI 线与、AFIO 时钟（F1 系列要开 AFIO 时钟）
留一个「不接线也能验证」的习惯

比较器电路最难查的就是「它到底什么时候翻转」。上板之前先做两件事：① 用可调电源或电位器给输入端一个可调电压，慢慢旋过阈值，用万用表/示波器看输出在哪两个电压点翻转（这两个电压之差就是实际的滞回窗口）；② 把翻转点记下来，和计算值比对。如果两个翻转点几乎重合，说明 Rf 没接上或者焊错了；如果窗口比算出来的宽很多，检查 R1/Rf 是不是取错了一个数量级。

3 · 动手算一遍

这一节四道例题，都是你在 STM32 项目里真会遇到的活儿：给 ADC 配抗混叠滤波器、给一个指定截止频率的 Sallen-Key 选元件、给按键/整形电路算滞回窗口、给电池做过压欠压区间判断。每道题我都按「写指标 → 定阶数 → 定 fc 与 Q → 选电容 → 算电阻 → 取标准值 → 反算验算」的完整流程走一遍，你可以直接照着这个格式算自己的电路。

例题① 给 STM32 的 ADC 设计抗混叠低通：从指标反推元件

题目：你要用 STM32 的 ADC 采集一个温度/压力传感器的信号，采样率定为 fs = 10kHz。传感器的有用信号带宽是 0 ~ 100Hz，板上有开关电源（开关频率 100kHz 量级）和电机 PWM（20kHz 量级）。要求：在奈奎斯特频率（fs/2 = 5kHz）处，干扰至少被衰减 40dB；通带内 100Hz 以下的信号不能被明显衰减（幅度损失控制在 3% 以内）；用单电源 3.3V 供电、单位增益。

【已知】
   采样率        fs   = 10kHz
   奈奎斯特频率  fs/2 = 5kHz
   有用信号带宽  f_sig = 100Hz
   要求衰减      A_stop = 40dB（在 5kHz 处）
   通带增益      A0 = 1（单位增益）
   电源          3.3V 单电源

【第 1 步】单级一阶够不够？先试一阶
   一阶低通在 f 处的衰减： A(f) = 20·lg(f/fc)  dB（远大于 fc 时）
   要在 5kHz 处达到 40dB： 20·lg(5000/fc) = 40
                       →  lg(5000/fc) = 2
                       →  5000/fc = 100
                       →  fc = 50Hz

   但 100Hz 的信号是【有用信号】！检查它在一阶 fc = 50Hz 时被砍了多少：
       f/fc = 100/50 = 2
       |H| = 1/√(1+2²) = 1/√5 = 0.447
       衰减 = 20·lg(0.447) = −6.99dB        ← 幅度只剩 45%！

   结论：一阶方案要求 fc 低到 50Hz，直接把有用信号砍掉 7dB。
        而且相位滞后 63°，对闭环控制之类需要相位的场合更糟。
        ❌ 一阶出局

【第 1 步（续）】试二阶
   二阶低通（巴特沃斯）在 f 处的衰减近似： A(f) = 40·lg(f/fc)  dB
   要在 5kHz 处达到 40dB： 40·lg(5000/fc) = 40
                       →  5000/fc = 10
                       →  fc = 500Hz

   检查有用信号：100Hz 处 f/fc = 0.2
       |H| = 1/√(1+0.2⁴) = 1/√(1.0016) = 0.9992
       衰减 = −0.007dB                        ← 几乎无损 ✅

   再看相位：100Hz 处 f/fc = 0.2，二阶在 f 远小于 fc 时相位滞后很小
       （二阶巴特沃斯在 f = 0.2fc 处相位约 −16.4°，可以接受）

   结论：二阶 fc = 500Hz 同时满足①②  ✅ 就用二阶
为什么这里正好落在 40dB 上

二阶巴特沃斯低通的幅度平方是 |H|² = 1/(1+(f/fc)⁴)。当 f/fc = 10 时，(f/fc)⁴ = 10000，所以 |H| = 1/√10001 ≈ 1/100.005，衰减 = 40.0004dB——二阶滤波器在「10 倍截止频率」处正好衰减 40dB，这个巧合非常方便记，也是抗混叠设计最常用的速算依据。

顺带记住这张表，选阶数时用得上：

需要的衰减一阶二阶四阶
20dB10 × fc3.16 × fc1.78 × fc

【第 2 步】定 fc 与 Q
   fc = 500Hz        （第 1 步算出）
   Q  = 0.707        （巴特沃斯：通带最平，fc 处正好 −3dB，无尖峰）

   元件拓扑：Sallen-Key 单位增益低通（后级是电压跟随器，输出阻抗低，
             正好可以直接驱动 ADC 的采样电容）

【第 3 步】先选电容（电容系列粗，先定电容才好凑比值）
   等值设计关系： C1 = 4Q² · C2 = 4 × 0.707² × C2 = 2 × C2
   取 C2 = 100nF（最常见的 C0G/薄膜标称值）
   则 C1 = 200nF  ← 200nF 不常见，用【两只 100nF 并联】得到：
        · 并联后容量 200nF，容差不会变差（两个 5% 并联 → 仍按 5% 估）
        · 温度特性、介质吸收都与单只相同，比找一只 220nF 更放心

【第 4 步】算电阻
   R = 1 / (2π · fc · √(C1·C2))
     = 1 / (2π × 500 × √(200nF × 100nF))
     = 1 / (2π × 500 × √(2×10⁻¹⁴))
     = 1 / (2π × 500 × 1.4142×10⁻⁷)
     = 1 / (4.443×10⁻⁴)
     = 2250.6 Ω

   取 E24 标准值： R = 2.2kΩ（也可以取 E96 的 2.26kΩ 更准）

【第 5 步】用标准值反算验算
   ① 反算 fc：
        fc = 1 / (2π × 2200 × 1.4142×10⁻⁷)
           = 1 / (1.955×10⁻³)
           = 511.5 Hz           ← 比设计值高 2.3%，可接受 ✅
   ② Q 不变（由电容比值决定）： Q = √(C1/C2)/2 = √2/2 = 0.7071 ✅
   ③ 检查 5kHz 处的衰减：
        f/fc = 5000/511.5 = 9.775
        (f/fc)⁴ = 9131
        |H| = 1/√(1+9131) = 1/95.55
        衰减 = 20·lg(1/95.55) = −39.6dB   ← 差 0.4dB，几乎达标
   ④ 保险起见把 R 换成 2.4kΩ 再算一次：
        fc = 1/(2π × 2400 × 1.4142×10⁻⁷) = 469 Hz
        f/fc = 5000/469 = 10.66， (f/fc)⁴ = 12910
        衰减 = −41.1dB                    ← 留出 1dB 余量 ✅ 推荐
   ⑤ 顺手算一下 10kHz 处（开关电源的基频）：
        f/fc = 10000/469 = 21.3， |H| ≈ 1/454

     运放    = MCP6001（GBW 1MHz，单位增益稳定，轨到轨，单电源 1.8~6V）
     偏置    = 10kΩ + 10kΩ + 100nF
     ADC 引脚处 = 1kΩ 串联 + 10nF 到地（电荷桶 + 额外一级 RC）
     ADC 采样时间设 71.5 个 ADC 时钟周期（源阻抗约 2.4kΩ，留足充电时间）

   设计结果核对：
     截止频率 fc ≈ 469Hz（设计 500Hz）
     100Hz 处衰减 ≈ −0.01dB（通带几乎无损）✅
     5kHz 处衰减 ≈ −41.1dB（要求 40dB）✅

例题② 指定 fc = 1kHz、Q = 0.707 的 Sallen-Key 低通，选标准元件值

题目：要求一个二阶巴特沃斯低通，fc = 1kHz，Q = 0.707，单位增益，用手头最常见的 10nF / 22nF 电容。请给出完整的电阻电容取值，并说明取标准值之后的实际 fc 与 Q 变成了多少。

【第 1 步】确定拓扑与关系式
   Sallen-Key 单位增益（运放接成电压跟随器）：
        ωc = 1/√(R1R2C1C2)
        Q  = √(R1R2C1C2) / (C2(R1+R2))
   取 R1 = R2 = R（等值设计，最省事、也最容易买料）：
        fc = 1 / (2πR√(C1C2))
        Q  = √(C1/C2) / 2

   由 Q = 0.707 反解电容比：
        √(C1/C2) = 2Q = 1.414
        C1/C2 = 2      ← Q = 0.707 时，C1 正好是 C2 的两倍

【第 2 步】选电容
   方案 A（教科书标准值）： C2 = 10nF， C1 = 20nF（两只 10nF 并联）
   方案 B（手头只有 22nF）： C2 = 10nF， C1 = 22nF
        → C1/C2 = 2.2， Q = √2.2/2 = 1.4832/2 = 0.7416

【第 3 步】算电阻（用方案 A 的电容）（补：两种方案都算一遍）
   方案 A： √(C1C2) = √(20n × 10n) = √(2×10⁻¹⁶) = 1.4142×10⁻⁸
        R = 1/(2π × 1000 × 1.4142×10⁻⁸)
          = 1/(8.8858×10⁻⁵)
          = 11253 Ω
        取标准值 R = 11kΩ（1% 金属膜）

   方案 B： √(C1C2) = √(22n × 10n) = √(2.2×10⁻¹⁶) = 1.4832×10⁻⁸
        R = 1/(2π × 1000 × 1.4832×10⁻⁸)
          = 1/(9.3192×10⁻⁵)
          = 10730 Ω
        取标准值 R = 11kΩ

【第 4 步】反算验算
   方案 A（R = 11kΩ，C1 = 20nF，C2 = 10nF）：
        fc = 1/(2π × 11000 × 1.4142×10⁻⁸) = 1/(9.7744×10⁻⁴) = 1023 Hz
        Q  = 0.7071
        fc 比设计值高 2.3%（因为 11k 比 11.25k 小）
        fc 处的增益： A(fc) = A0 × Q = 0.707 → −3.01dB（巴特沃斯的定义值）✅

   方案 B（R = 11kΩ，C1 = 22nF，C2 = 10nF）：
        fc = 1/(2π × 11000 × 1.4832×10⁻⁸) = 1/(1.0252×10⁻³) = 976 Hz
        Q  = 0.7416
        fc 处增益尖峰 = 20·lg(0.7416/0.7071) = +0.41dB
        （只比巴特沃斯多隆起了 0.4dB，完全可以用）✅

【第 5 步】检查运放够不够快
   GBW 要求： ≥ 100 × fc = 100kHz（保守取 200 × fc = 200kHz）
   MCP6001 的 GBW = 1MHz  ✅ 余量 10 倍
   压摆率要求： SR ≥ 2π·fc·V_pp = 2π × 1000 × 1V = 6.3×10³ V/s = 0.0063 V/µs
   MCP6001 的压摆率 ≈ 0.6V/µs  ✅ 余量巨大（这座滤波器信号摆幅小，很容易满足）

【第 6 步】误差预算（顺便看一眼元件精度的影响）
   电阻用 1%、电容用 5% 时：
     fc 的相对误差 ≈ (ΔR/R) + ½(ΔC1/C1 + ΔC2/C2)
                    ≈ 1% + 5% = 6% 量级（最坏情况）
     实际批量生产的 fc 会落在 940Hz ~ 1080Hz 之间
   Q 对电容比更敏感：
     C1/C2 变化 10% → Q 变化约 5% → Q 在 0.67 ~ 0.74 之间
   如果一个产品的 fc 要求严格（比如音频分频），就要用 1% 电容或加微调电位器
常见错误：等值设计的 Q 只有 0.5

很多同学把 Sallen-Key 的 C1 和 C2 都取成 10nF（「对称、好看」），结果得到的是 Q = 0.5 的过阻尼响应——fc 附近不是 −3dB 而是 −6dB，过渡带比巴特沃斯更缓，但通带边缘更「软」。它不算坏电路，只是不是你要的巴特沃斯。

记住这条：在 Sallen-Key 里，Q 完全由电容比值决定（单位增益版本）。要 Q = 0.707 就必须 C1 = 2C2；要 Q = 0.577（贝塞尔）就取 C1 = 1.33C2；两个电容相等时 Q 恒为 0.5。

例题③ 滞回比较器：给定上下阈值，反算正反馈电阻与参考电压

题目：一个缓慢变化的传感器信号（摆幅约 1V 的有效范围，中心在 1.65V），叠加了约 30mV 峰峰值的噪声。要求用 LM393 把它整形成干净的数字信号送进 STM32 的 EXTI：滞回窗口取 200mV，窗口中心取 1.645V。3.3V 单电源，输出上拉到 3.3V，开漏低电平按 VOL = 0.15V 估算。求 R1、Rf 和 Vref。

【已知】
   窗口宽度 ΔV = 200mV = 0.200V
   窗口中心 V_center = 1.645V
   VOH = 3.3V（上拉到 3.3V，输出截止时上拉把电平拉满）
   VOL = 0.15V（开漏管导通时的饱和压降，小电流下取这个量级）

【第 1 步】取 R1 = 10kΩ，反算 Rf
   由 ΔV = (VOH − VOL) × R1/Rf ：
        Rf = (VOH − VOL) × R1 / ΔV
           = (3.3 − 0.15) × 10k / 0.2
           = 3.15 × 10k / 0.2
           = 157.5 kΩ
   取 E24 标准值 Rf = 150kΩ

   用 150kΩ 反算实际窗口：
        ΔV = 3.15 × 10k/150k = 3.15 × 0.06667 = 0.210V = 210mV
        （比目标 200mV 宽 5%，方向上是「更抗干扰」，可以接受 ✅）

【第 2 步】由窗口中心反算 Vref
   公式： Vref = [ V_center + ((VOH+VOL)/2) × (R1/Rf) ] / (1 + R1/Rf)
   其中：
        (VOH+VOL)/2 = (3.3 + 0.15)/2 = 1.725V
        R1/Rf = 10k/150k = 0.066667
        1 + R1/Rf = 1.066667
   代入：
        Vref = (1.645 + 1.725 × 0.066667) / 1.066667
             = (1.645 + 0.115) / 1.066667
             = 1.760 / 1.066667
             = 1.650V

   ★ 好巧：正好是 1.65V —— 也就是 3.3V 对半分压！
     实现：两只 10kΩ 从 3.3V 分压到地，分压点并 100nF 到地。

【第 3 步】算出两个阈值，验证窗口
   V_TH = Vref × (1 + R1/Rf) − VOL × (R1/Rf)
        = 1.65 × 1.066667 − 0.15 × 0.066667
        = 1.760 − 0.010
        = 1.750V          ← 输入【上升】到这里，输出翻转为低

   V_TL = Vref × (1 + R1/Rf) − VOH × (R1/Rf)
        = 1.65 × 1.066667 − 3.3 × 0.066667
        = 1.760 − 0.220
        = 1.540V          ← 输入【下降】到这里，输出翻回高

   窗口宽度 = 1.750 − 1.540 = 0.210V = 210mV  ✅ 与第 1 步一致
   窗口中心 = (1.750 + 1.540)/2 = 1.645V      ✅ 与目标一致

【第 4 步】验证它真的能抗住这个噪声
   噪声峰峰值 30mV，窗口 210mV：
        210 / 30 = 7 倍  → 噪声远不能翻出窗口 ✅
   再验证「窗口没有吃掉太多动态范围」：
        信号有效摆幅约 1V，窗口 210mV
        210mV / 1V = 21%  → 低于经验上限（1/3 ~ 1/5）✅
   两个方向都合格，设计通过。

【第 5 步】给出完整外围参数
   R1 = 10kΩ         （输入电阻）
   Rf = 150kΩ        （正反馈电阻，接在【输出】与【同相端】之间）
   Vref = 1.65V      （两只 10kΩ 分压 + 100nF 去耦，接【反相端】）
   Rp = 10kΩ         （输出上拉到 3.3V）
   Rf 两端可以并一只 10nF 电容（可选，进一步压边沿毛刺）

【第 6 步】检查输入源阻抗
   如果传感器信号经过一只 10kΩ 的串联电阻才进来，那它要和 R1 一起算：
        实际 R1_eff = 10k + 10k = 20kΩ
        → 窗口变成 3.15 × 20k/150k = 420mV（翻倍！）
   ★ 结论：滞回窗口的计算里，【源阻抗必须算进 R1】，
     或者在前级加一级跟随器把源阻抗做低。

例题④ 电池过压/欠压：窗口比较器的阈值、分压与滞回

题目：用 3.3V 供电的 LM393 监测 12V 电池：正常范围 10.8V ~ 13.8V，高于 13.8V 判为过压（要立刻关断充电 PWM），低于 10.8V 判为欠压（要报警并降低负载）。要求：把 12V 分压到 LM393 能接受的输入范围；给出两路阈值电压；给两路各加约 250mV（折算到 12V 侧）的滞回。计算分压比、基准电压、滞回电阻。

【第 1 步】定分压比 —— 先看 LM393 的输入上限！

   LM393 的输入共模范围是 0 ~ VDD − 1.5V。
   3.3V 供电时，输入上限只有 3.3 − 1.5 = 1.8V。

   ⚠️ 如果按「分压到 3.3V 以内就行」的思路，取 1/6 分压：
        13.8V × 1/6 = 2.30V   →  超过 1.8V 的上限！❌
        这时比较器的工作会不正常（输入级进入非线性区，甚至输出翻转错误）

   ✅ 正确做法：把最高电压压到 1.8V 以内，取 1/9 量级的分压比。
      选 R_top = 82kΩ， R_bot = 10kΩ：
        分压比 = 10/(82+10) = 10/92 = 0.10870  （约 1/9.2）

      验算三档电压在分压点上的值：
        13.8V × 0.10870 = 1.500V   ✅ 低于 1.8V
        12.0V × 0.10870 = 1.304V   ✅
        10.8V × 0.10870 = 1.174V   ✅ 高于 0V

   ★ 顺带一提：也可以让 LM393 用 5V 供电（共模上限变成 5 − 1.5 = 3.5V），
     这样分压比可以放宽。因为 LM393 是【开漏】输出，它的输出电平由
     上拉电阻决定，所以「5V 供电 + 上拉到 3.3V」完全可以给 STM32 用。
     但要注意上电顺序：5V 先建立、3.3V 后建立时不会有问题（输出只是被
     上拉电阻悬着），反过来则要留意 12V 分压在芯片未上电时灌入输入端的电流。

   分压网络的耗电（电池设备必须算）：
        电流 = 13.8V / 92kΩ ≈ 150µA
        一年耗电 ≈ 150µA × 8760h ≈ 1.3Ah
     如果把分压电阻取小 10 倍（8.2k + 1k），电流就变成 1.5mA，一年 13Ah——
     对一块 7Ah 的小电池来说，光是分压就把电耗光了。所以别嫌 82k 大。

【第 2 步】由 3.3V 造出两路基准电压

   过压阈值（13.8V 对应的分压点）：
        目标 = 13.8 × 0.10870 = 1.500V
        用 3.3V 分压得到： Rb/(Ra+Rb) = 1.5/3.3 = 0.4545
        取 Ra = 12kΩ、Rb = 10kΩ → 10/22 = 0.4545
        实际基准 = 3.3 × 0.4545 = 1.500V  ✅ 正好

   欠压阈值（10.8V 对应的分压点）：
        目标 = 10.8 × 0.10870 = 1.174V
        用 3.3V 分压得到： Rb/(Ra+Rb) = 1.174/3.3 = 0.3558
        取 Ra = 18kΩ、Rb = 10kΩ → 10/28 = 0.3571
        实际基准 = 3.3 × 0.3571 = 1.179V
        折算回 12V 侧： 1.179 / 0.10870 = 10.84V  ✅ 与 10.8V 相差 0.4%

【第 3 步】核对两路比较器的接法
   过压比较器（LM393-A）：
        ＋端 = 分压节点（被测电压）
        −端 = 1.500V（过压基准）
        输出低 → 分压点高于 1.500V → 电池电压高于 13.8V → 过压 ✅
   欠压比较器（LM393-B）：
        ＋端 = 1.179V（欠压基准）
        −端 = 分压节点（被测电压）
        输出低 → 分压点低于 1.179V → 电池电压低于 10.8V → 欠压 ✅
   正常区间（10.84V ~ 13.80V）：两路输出都是截止 → 都是高电平 ✅

【第 4 步】加滞回（关键是先算清【节点源阻抗】）
   分压节点的源阻抗（戴维南）： Rs = 82k ∥ 10k = 8.91kΩ
   过压路：Rf1 = 1MΩ 从【输出】接回【分压节点】
        节点上的滞回量 = (VOH − VOL) × Rs/(Rs + Rf1)
                        = 3.15 × 8.91k/1008.91k
                        = 3.15 × 0.008833
                        = 27.8mV
        折算到 12V 侧： 27.8mV / 0.10870 = 256mV  ✅ 约 0.26V

   欠压路的正反馈要接在它自己的【＋端】，也就是 1.179V 基准节点：
        基准节点源阻抗 = 18k ∥ 10k = 6.43kΩ
        Rf2 = 1MΩ 时，节点上的滞回量 = 3.15 × 6.43k/1006.43k = 20.1mV
        折算到 12V 侧： 20.1mV / 0.10870 = 185mV  ✅ 约 0.19V

   ★ 两路的滞回量不相等，因为两个节点的源阻抗不同（8.91k vs 6.43k）。
     想让它们一致，就调 Rf2（比如用 680kΩ 得到更宽）或把两路基准的
     分压电阻改成同一阻值量级。

   ★ 额外效果与代价：过压路的 Rf1 会把电流注入分压节点，而分压节点
     同时是欠压路的【−端】——两路之间存在一个小小的耦合（27.8mV 量级）。
     同时如果这个分压点还要送去 ADC 采样电池电压，比较器输出翻转时
     ADC 的读数会偏移约 28mV（折算 12V 侧 0.26V）。
     对精度要求高的场合，就让 ADC 单独分一路、或者加一级跟随器隔离。

【第 5 步】最终元件清单
   R_top = 82kΩ，R_bot = 10kΩ        （分压，节点并 100nF 到地滤高频）
   过压基准：12kΩ + 10kΩ + 100nF  → 1.500V
   欠压基准：18kΩ + 10kΩ + 100nF  → 1.179V
   Rf1 = 1MΩ（过压路：输出 → 分压节点）
   Rf2 = 1MΩ（欠压路：输出 → 1.179V 基准节点）
   两路输出各上拉 10kΩ 到 3.3V，分别接两个 GPIO（或线与后接一个 GPIO）

补充例题 用 MFB（多重反馈）实现同一个 1kHz 低通

把例题②的指标换成 MFB 拓扑，体会一下「同一组指标，不同拓扑给出不同元件值」的感觉。MFB 的等阻值设计关系是 Q = √(C2/C1)/3 和 fc = 1/(2πR√(C1C2))：

【第 1 步】由 Q 反解电容比
   Q = √(C2/C1)/3  →  √(C2/C1) = 3Q = 3 × 0.707 = 2.121
   →  C2/C1 = 2.121² = 4.5

【第 2 步】选电容
   C1 = 10nF
   C2 = 45nF → 取标准值 47nF
   实际 Q = √(47/10)/3 = 2.168/3 = 0.7226
   （比 0.707 高 2%，fc 处只多隆起 0.19dB，可以接受）

【第 3 步】算电阻（等阻值 R1 = R2 = R3 = R）
   √(C1C2) = √(10n × 47n) = √(4.7×10⁻¹⁶) = 2.168×10⁻⁸
   R = 1/(2π × 1000 × 2.168×10⁻⁸)
     = 1/(1.362×10⁻⁴)
     = 7341 Ω
   取标准值 R = 7.5kΩ

【第 4 步】反算验算
   fc = 1/(2π × 7500 × 2.168×10⁻⁸) = 1/(1.0214×10⁻³) = 979 Hz
   直流增益 = −R2/R1 = −1（反相，输出与输入相位差 180°）
   Q = 0.7226

   对比一下同一个指标的两种拓扑：
     Sallen-Key：R = 11kΩ ×2，C = 20nF + 10nF，输出【同相】，增益 +1
     MFB       ：R = 7.5kΩ ×3，C = 10nF + 47nF，输出【反相】，增益 −1
   元件数量只差一只电阻，但输出极性和对运放的要求都不一样（见第 2 节对比表）。
算完一定要反算——这是本节的中心思想

四道例题里每一步的「取标准值」后面，都跟着一次反算。原因很实在：元件只有标准值，而公式里的数字是连续的。取整以后 fc 偏 2%、窗口偏 5% 都很正常，关键是你要知道它偏到哪儿去了、还满不满足指标。判断标准也很简单：偏 2% ~ 5% 通常无所谓（元件本身的容差就有 1% ~ 5%），偏 20% 以上就要回头重新选值。

反算还有个额外好处：它是你上板子之后唯一能对照的「预期值」。测出来 fc = 480Hz 而算出来是 469Hz，说明焊接和元件都没问题；测出来 240Hz，那就是电容焊错了一个数量级——这种问题只有算过的人才能一眼看出来。

场景一：把抗混叠低通接到 ADC 前端

用例题①算出来的电路（二阶 Sallen-Key，fc ≈ 469Hz，配 1kΩ + 10nF 电荷桶）。接好之后，软件上有三件事必须做对，否则前面的模拟设计全白费：

① 采样时间：不是「越快越好」
   STM32 的 ADC 一次转换 = 采样时间 + 逐次逼近时间（12.5 个周期）
   采样时间由你设定（1.5 / 7.5 / 13.5 / 28.5 / 41.5 / 55.5 / 71.5 / 239.5 周期）
   · 源阻抗越高，需要越长的采样时间（内部采样电容约 8pF 要充到目标电压）
   · 数据手册给出「最大允许源阻抗 RAIN」表：采样时间越短，允许的源阻抗越小
     （几个周期时只有几百欧姆，239.5 周期时可以放宽到几 kΩ）
   · 本设计源阻抗约 2.4kΩ（滤波器输出 + 1kΩ 串联），取 71.5 周期最稳妥
   · 总转换时间 = (71.5 + 12.5) / 14MHz = 6.0µs
     采样周期 1/10kHz = 100µs → 占用 6%，绰绰有余

② 采样率要由【定时器】来定，不要用主循环
   主循环里 while(1) { HAL_ADC_GetValue(); HAL_Delay(1); } 的采样间隔
   会因为串口打印、按键扫描、别的任务而抖动几十微秒到几毫秒。
   采样间隔一抖动，等效采样率就不再是 10kHz：
     · 抗混叠滤波器的设计前提（fs = 10kHz）被破坏
     · 后续任何按「等间隔采样」做的数字滤波（FIR/FFT）全部失真
   ✅ 正确做法：TIM 更新事件触发 ADC（TRGO），再用 DMA 搬运。
      这样采样间隔由硬件保证，CPU 一点抖动都影响不到它。

③ 过采样不能替代抗混叠
   STM32 的硬件过采样（把 N 次转换求平均）能把【白噪声】平均掉
   （理论上 N 次平均可降 √N 倍噪声），但对已经折进来的混叠分量毫无办法。
   抗混叠必须在 ADC 之前【模拟】完成，这件事没有软件替代方案。

对应的代码大致长这样（以 STM32F1 的 HAL 库为例，其他系列 API 名不同但结构一样）：

/* 抗混叠滤波器之后的 ADC 采集
 * 硬件：二阶 Sallen-Key 低通（fc 约 469Hz）+ 1kΩ/10nF 电荷桶
 * 采样：TIM2 更新事件触发 ADC1，DMA 搬 64 个样本，采满置标志
 */
#define ADC_BUF_LEN   64

static uint16_t adc_buf[ADC_BUF_LEN];
volatile uint8_t adc_ready = 0;

/* ① ADC 通道：采样时间给足，让 8pF 采样电容充满 */
static void adc_channel_setup(void)
{
    ADC_ChannelConfTypeDef cfg = {0};
    cfg.Channel      = ADC_CHANNEL_0;               /* PA0 */
    cfg.Rank         = ADC_REGULAR_RANK_1;
    cfg.SamplingTime = ADC_SAMPLETIME_71CYCLES_5;   /* 71.5 + 12.5 = 84 周期 */
    HAL_ADC_ConfigChannel(&hadc1, &cfg);
}

/* ② TIM2：72MHz / (72 x 100) = 10kHz，用更新事件当 ADC 的触发源 */
static void tim2_trigger_setup(void)
{
    TIM_MasterConfigTypeDef mcfg = {0};

    htim2.Init.Prescaler = 72 - 1;      /* 1MHz 计数时钟 */
    htim2.Init.Period    = 100 - 1;     /* 100 个计数 = 10kHz */
    HAL_TIM_Base_Init(&htim2);

    mcfg.MasterOutputTrigger = TIM_TRGO_UPDATE;     /* 更新事件输出到 TRGO */
    mcfg.MasterSlaveMode     = TIM_MASTERSLAVEMODE_DISABLE;
    HAL_TIMEx_MasterConfigSynchronization(&htim2, &mcfg);
}

/* ③ 启动：ADC 挂在 DMA 上，采满 64 个点进中断 */
void adc_front_start(void)
{
    HAL_ADC_Start_DMA(&hadc1, (uint32_t *)adc_buf, ADC_BUF_LEN);
    HAL_TIM_Base_Start(&htim2);
}

/* ④ 中断里只置标志：处理（滤波、换算、上报）放到主循环 */
void HAL_ADC_ConvCpltCallback(ADC_HandleTypeDef *hadc)
{
    if (hadc->Instance == ADC1) {
        adc_ready = 1;
    }
}

/* ⑤ 主循环：数字侧最后一道防线 —— 滑动平均
 *    注意它只能压随机噪声，不能修复已经发生的混叠 */
uint16_t adc_filtered(void)
{
    uint32_t sum = 0;
    for (uint8_t i = 0; i < ADC_BUF_LEN; i++) {
        sum += adc_buf[i];
    }
    return (uint16_t)(sum / ADC_BUF_LEN);
}
数字滤波救不了混叠，但它值得留着

滑动平均在这里的作用是提高有效分辨率、压掉随机噪声：64 个样本平均后，白噪声理论上降到 1/8，等效位数提升约 3 位。它和抗混叠滤波器是「两道不同的防线」：模拟滤波器管频率折叠，数字平均管随机噪声。两件事都要做，但顺序不能颠倒。

还有一个细节：平均 N 个点相当于一个简单的 FIR 低通，它的零点在 fs/N 的整数倍处，同时本身也有一个衰减特性。如果 N 取 64、fs = 10kHz，它对 100Hz 以下信号的影响很小，可以放心用。

场景二：滞回比较器整形成方波，再进外部中断

第二种场景是最常见的：你有一个正弦信号（比如流量计的线圈输出、电感式转速传感器、或者一个缓慢变化的液位信号），想用 STM32 数它的周期或个数。直接把这个信号接 GPIO 是不行的——STM32 的输入门限是一条（或两条）固定的线，信号在门限附近来回磨蹭，中断就会疯狂触发。

正确链路是：隔直电容 → 偏置到 1.65V → 滞回比较器 → 上拉到 3.3V → EXTI 引脚。其中隔直电容把信号的直流分量去掉（防止它把工作点顶偏），偏置把信号抬到 VDD/2 让正负半周都落在 0 ~ 3.3V 内，滞回比较器负责「一锤定音」。

假设：
   信号：1kHz 正弦，峰峰值 2V（在偏置点 1.65V 上摆动）
   阈值：1.65V（过零点）
   阈值附近的噪声：峰峰值 20mV（前级运放噪声 + 工频感应，很容易达到）

先算信号穿越阈值有多快：
   正弦信号在过零点的斜率 = 2π·f·V_peak = 2π × 1000 × 1V = 6283 V/s

再算信号「待在噪声带里」的时间（噪声带宽 Vn = 20mV）：
   T = Vn / (dV/dt) = 0.02 / 6283 = 3.2µs

在这 3.2µs 内，噪声以多快的速率穿越阈值？
   受比较器响应时间（LM393 典型 1.3µs）和输入网络的带宽限制，
   穿越速率大约在几百 kHz 量级 → 3.2µs 内可能产生 1 ~ 3 个额外边沿

   → 1kHz 的信号，每秒约 1000 次穿越，每次多出 1 ~ 3 个边沿
   → EXTI 中断次数从 1000/s 涨到 2000 ~ 4000/s ❌
   → 频率读数直接偏高一倍以上，而且读数会随噪声大小乱跳

加上 210mV 的滞回（例题③ 的设计）：
   信号必须从 1.750V 降到 1.540V 才算一次「反向穿越」
   噪声 20mV 只是窗口的 1/10 → 一个额外边沿都没有 ✅
   代价：过零点检测的相位/时间有约 ±100mV/6283V/s ≈ ±16µs 的偏移，
        换算到 1kHz 的周期上是 1.6% —— 对测转速完全够用；
        对相位测量要求高的场合才需要专门设计。

所以：滞回窗口的代价是「精度」，收益是「确定的边沿」。绝大多数单片机项目要的是后者。下面是对应的代码，核心思想是中断里只做计数，其他事都交给主循环：

/* 硬件：LM393 滞回比较器（V_TH = 1.750V, V_TL = 1.540V）
 *       输出上拉 10kΩ 到 3.3V，接 PA0（EXTI0，上升沿触发）
 * 策略：中断里只加一个计数，频率结算放到主循环
 */
volatile uint32_t g_edge_cnt = 0;      /* 上升沿个数 */
volatile uint32_t g_freq_hz  = 0;      /* 测量结果 */

/* ① 中断服务：越短越好，不调用任何阻塞函数 */
void HAL_GPIO_EXTI_Callback(uint16_t pin)
{
    if (pin == GPIO_PIN_0) {
        g_edge_cnt++;
    }
}

/* ② 主循环里每 1 秒结算一次（用毫秒滴答计时，不用 HAL_Delay） */
void freq_task(void)
{
    static uint32_t last = 0;
    uint32_t now = HAL_GetTick();

    if (now - last >= 1000) {
        uint32_t cnt;

        __disable_irq();               /* 读-清零要原子，防止丢边沿 */
        cnt        = g_edge_cnt;
        g_edge_cnt = 0;
        __enable_irq();

        g_freq_hz = cnt;               /* 1 秒内的上升沿数 = 频率(Hz) */
        last += 1000;
    }
}

/* ③ 低频信号改用「测周法」更准：
 *    用定时器输入捕获记录相邻两个上升沿之间的计数值，再换算周期
 *    1Hz 的信号用测频法要等 1 秒才有 1 个计数（分辨率 100%）
 *    用测周法在 1MHz 计数时钟下，1 个周期就有 10^6 个计数（分辨率 10^-6）
 */
去抖的三道防线，按顺序上

第一道（硬件，最根本）：滞回窗口设到预期噪声的 3 ~ 10 倍。它从原理上消除了「噪声穿越」，后面的软件都只是补充。

第二道（硬件，便宜）：比较器输出串 100Ω、并在 GPIO 附近放 1nF ~ 10nF 到地。它把边沿上的高频毛刺和长线拾取的干扰压掉，同时让边沿更干净（代价是边沿稍微变慢，所以电容别太大）。

第三道（软件，兜底）：按键类慢信号的标准做法是——中断里只置标志 + 关掉这个中断，延时 10 ~ 20ms 后再读电平确认。千万不要在中断里用 HAL_Delay 去抖，那是在中断里空转 20ms，其他中断全被堵住，遇到连续抖动还可能直接卡死。

场景三：过压/欠压保护与电池区间判断

这个场景的价值在于响应速度：如果过压是靠主循环里读 ADC 判断的，响应时间取决于循环周期（可能几毫秒到几十毫秒），而比较器方案从「电压越限」到「PWM 关断」只需要比较器响应时间（约 1.3µs）+ 中断延迟（约 1µs 量级）+ 几行寄存器操作，量级上快一百倍以上。

方案                     检测延迟            关断延迟        总响应时间
─────────────────────────────────────────────────────────────────────────
主循环轮询 ADC           1 个循环周期        下一行代码      几 ms ~ 几十 ms
                         (含所有任务耗时)
比较器 + EXTI 中断       1.3µs（比较器）     中断服务里      ≈ 3 ~ 10µs
                                             写寄存器
比较器 + 定时器刹车      1.3µs（比较器）     硬件直接封锁     ≈ 2µs（CPU 不参与）
（BKIN 引脚）                                 PWM 输出

   如果负载是功率 MOS 驱动电机/加热丝：
     · 10µs 的过压延迟，对功率器件通常是可以接受的
     · 但主循环轮询的 10ms 延迟，可能已经让 MOS 管过压击穿
     · 所以保护类信号一定要走【硬件比较器 + 中断】，并且中断优先级最高
   如果 STM32 的定时器有 BKIN（刹车输入）功能，还能更进一步：
     把比较器输出直接接到 BKIN 引脚，硬件在一个时钟周期内封锁 PWM 输出，
     完全不依赖中断响应 —— 这是功能安全设计里常见的做法。

中断服务函数里做的事情越少越可靠。下面这段代码展示了「过压 → 立刻关 PWM」的标准写法，注意关输出的动作在置标志之前：

/* 硬件：12V 经 82k/10k 分压，过压比较器阈值 1.500V（对应 13.8V）
 *       欠压比较器阈值 1.179V（对应 10.8V），两路输出上拉到 3.3V
 *       分别接 PA1 / PA2，都配成下降沿触发（开漏输出「低」= 故障）
 */
#define FAULT_NONE   0
#define FAULT_OVP    1
#define FAULT_UVP    2

volatile uint8_t g_fault = FAULT_NONE;

void HAL_GPIO_EXTI_Callback(uint16_t pin)
{
    if (pin == GPIO_PIN_1) {                /* 过压：最高优先级处理 */
        /* ① 先关断，再记录 —— 顺序反了就可能来不及 */
        HAL_TIM_PWM_Stop(&htim1, TIM_CHANNEL_1);
        __HAL_TIM_SET_COMPARE(&htim1, TIM_CHANNEL_1, 0);
        HAL_GPIO_WritePin(FAULT_LED_GPIO_Port, FAULT_LED_Pin, GPIO_PIN_SET);
        /* ② 只置标志，打印/上报/恢复策略都交给主循环 */
        g_fault = FAULT_OVP;
    }
    else if (pin == GPIO_PIN_2) {           /* 欠压：降载而不是立刻停机 */
        g_fault = FAULT_UVP;
    }
}

/* 主循环：负责「慢」的事情 —— 上报、闪烁、恢复判断 */
void fault_task(void)
{
    switch (g_fault) {
    case FAULT_OVP:
        /* 已经关断 PWM；等电压回落到 13.8V 以下（滞回约 0.26V）再决定恢复 */
        break;
    case FAULT_UVP:
        /* 欠压通常不需要立刻关断：降占空比、点亮告警、限制负载 */
        __HAL_TIM_SET_COMPARE(&htim1, TIM_CHANNEL_1, SAFE_DUTY);
        break;
    default:
        break;
    }
}
中断服务函数里的三条铁律

① 不做阻塞操作。不要 HAL_Delay()、不要死等标志位、不要 HAL_UART_Transmit() 阻塞式发串口。一次 115200bps 的串口打印约 1ms，如果中断以 kHz 频率进来，CPU 会全部耗在打印上。

② 不碰浮点和耗时的数学。中断里算 float 除法、开方、滤波（尤其是几百点的 FIR）都会显著拉长中断时间。把原始数据放进环形缓冲区，让主循环去算。

③ 共享变量要防竞态。中断里改、主循环读的变量（比如上面的 g_edge_cnt）必须加 volatile；「读出来再清零」这种读-改-写操作在 32 位机上虽然大多是原子的，但为了保险，用 __disable_irq() / __enable_irq() 包一下更稳妥。

最后是电池区间判断的状态机。两路比较器分别接两个 GPIO，程序只要读两个引脚就能分清三种状态；如果两个开漏输出「线与」成一个引脚，就读一个引脚区分「正常 / 异常」，再用 ADC 采一次分压值来判断到底是过压还是欠压：

/* 两路比较器（一片 LM393）：
 *   OVP 引脚：低 = 电池高于 13.8V（过压）
 *   UVP 引脚：低 = 电池低于 10.8V（欠压）
 *   两个都高 = 电压在 10.84V ~ 13.80V（正常）
 */
typedef enum {
    BAT_UV = 0,      /* 欠压 */
    BAT_OK,          /* 正常 */
    BAT_OV           /* 过压 */
} bat_state_t;

bat_state_t battery_state(void)
{
    uint8_t ov_low = (HAL_GPIO_ReadPin(OVP_GPIO_Port, OVP_Pin) == GPIO_PIN_RESET);
    uint8_t uv_low = (HAL_GPIO_ReadPin(UVP_GPIO_Port, UVP_Pin) == GPIO_PIN_RESET);

    if (ov_low) {
        return BAT_OV;           /* 过压优先判断，安全第一 */
    }
    if (uv_low) {
        return BAT_UV;
    }
    return BAT_OK;
}

/* 结合 ADC 读数做「双重确认」：
 *   比较器负责【快】（µs 级保护动作，不依赖软件）
 *   ADC 负责【准】（能读出具体电压值，用于显示和电量估算）
 *   两者用同一个分压点时，注意比较器翻转会带来约 28mV 的节点扰动
 */
状态两个比较器输出电池电压（12V 侧）建议动作
过压 BAT_OVOVP 低、UVP 高高于 13.80V立刻关断充电 PWM；等回落到 13.54V 以下（滞回 0.26V）再释放
正常 BAT_OK两路都高10.84V ~ 13.80V正常工作；可继续用 ADC 做电量估算与显示
欠压 BAT_UVOVP 高、UVP 低低于 10.84V降低负载占空比、点亮告警；到 10.5V 以下强制休眠保护电池
这一节的三条主线

① 采样链路的时序由硬件保证（定时器触发 + DMA），软件别插手采样时刻；
② 中断源要「干净」——滞回比较器把模拟世界的抖动挡在门外，中断里只做计数和关断这类微秒级动作；
③ 快慢分离——保护动作（快、在中断里做）和数据处理/上报（慢、在主循环做）严格分开，这是所有可靠嵌入式系统的共同结构。

5 · 常见误解与坑

下面这十条，都是我在帮同学看板子时反复遇到的。每一条都按「错误认知 → 为什么错 → 正确做法」写，你可以当成一份上板前的检查清单。

坑 1：「ADC 前面随便加个 100nF 电容就够了」

错误认知：滤波嘛，就是在信号线上并一个电容到地，看到读数稳了就算完事。

为什么错：一个电容配合信号源的输出阻抗确实构成了一阶 RC，但它的 fc 完全由「源阻抗」决定——而源阻抗往往是你不控制、也不知道的（传感器输出阻抗可能从几百欧到几十千欧）。更关键的是：这个电容只在引脚附近起作用，它挡不住长走线上拾取的高频干扰；而且它没有解决电荷桶的问题——ADC 采样瞬间抽走电荷，电容被拉低后必须靠源阻抗重新充回来，源阻抗高就会造成系统性偏低。

正确做法：① 按指标（信号带宽 + fs/2 处衰减）算出 fc 和阶数，用有源滤波器实现；② 滤波器输出走运放的低阻输出，不要从 RC 节点直接取；③ ADC 引脚处再放「串联 100Ω ~ 1kΩ + 对地 1nF ~ 10nF」的电荷桶；④ 采样时间按源阻抗选够（源阻抗几 kΩ 时取 71.5 或 239.5 个周期）。

坑 2：「采样之后在程序里做数字滤波，就等于抗混叠了」

错误认知：高频干扰既然能被滤掉，那我采完样在软件里滤不也一样？还能省掉运放和电容。

为什么错：混叠发生在采样那一刻，而且是不可逆的信息丢失。fs = 10kHz 时，10.05kHz 的干扰和真实的 50Hz 信号在每一个采样点上的取值完全相同——sin(2π × 10050 × n/10000) = sin(2π × 50 × n/10000)。程序拿到的两串数字一模一样，任何算法都分不出来。数字滤波能做的是压随机噪声，不是修复混叠。

正确做法：抗混叠必须用模拟滤波器，放在 ADC 之前（而且尽量靠近 ADC 引脚，别让长走线把高频又捡回来）。数字侧再叠加滑动平均/中值滤波来提高分辨率，两道防线各管一件事。

坑 3：「一阶 RC 低通够用了，何必用运放」

错误认知：一阶 RC 便宜、简单、无源，能滤掉高频噪声。

为什么错：一阶滤波器的衰减斜率只有 −20dB/十倍频。要在 5kHz 处衰减 40dB，截止频率必须低到 50Hz——而 100Hz 的有用信号在 50Hz 的截止频率下已经被砍掉了 6.99dB（幅度只剩 45%）。换句话说：一阶滤波器做不到「既保住通带又压住阻带」，这不是元件精度问题，是数学上的硬限制。

正确做法：算阶数：n ≥ A_stop / (20·lg(f_stop/fc))。需要 40dB 就老老实实上二阶（40dB/十倍频），需要 60dB 上四阶，或者干脆提高采样率让 f_stop 更远。记住这张对照：要 60dB 衰减，一阶需要 1000 × fc 的频率距离，二阶只要 31.6 × fc。

坑 4：「Sallen-Key 的两个电容取一样大，对称好看」

错误认知：元件对称的电路性能更好，所以 C1 = C2 = 10nF。

为什么错：在单位增益的 Sallen-Key 低通里，Q 完全由电容比值决定：Q = √(C1/C2)/2。C1 = C2 时 Q 恰好等于 0.5，这是一个过阻尼的二阶系统——fc 处不是 −3dB（而是 −6dB），过渡带更缓，通带边缘「软塌塌」。它不会振荡，但绝不是巴特沃斯。

正确做法：用 C1 = 4Q²·C2：巴特沃斯（Q = 0.707）取 C1 = 2C2；贝塞尔（Q = 0.577）取 C1 = 1.33C2；切比雪夫（Q = 0.957，1dB 纹波）取 C1 = 3.66C2。想两边都对称又要有 Q = 0.707，就改用带增益的 VCVS 版本：让增益 K = 3 − 1/Q = 1.586，此时可以 C1 = C2。

坑 5：「Q 越高滤波效果越好」

错误认知：Q 越大说明滤波器越「锐」，性能越强，所以把 Q 往大了取。

为什么错：Q 描述的是极点靠近虚轴的程度，它同时决定了三件事：① fc 处的增益（|H(fc)| = A0·Q）；② 阶跃响应的过冲与振铃；③ 对元件容差的敏感度。Q = 1.305 时 fc 处会隆起 +2.3dB，看起来很「陡」，但一个阶跃信号会让它振荡好几下；Q 再往上，轻微过冲的方波就会让输出严重振铃甚至接近不稳定。而且高 Q 电路的滤波效果对元件误差极其敏感，批量生产时一致性很差。

正确做法：按用途选 Q——通带平坦、通用测量用巴特沃斯 Q = 0.707；方波/脉冲保真（要求群延迟平坦、无过冲）用贝塞尔 Q = 0.577；只在「必须用很低的阶数达到很陡的过渡带」时才用切比雪夫（纹波 1dB 时 Q ≈ 0.96，此时接受通带纹波和振铃的代价）。

坑 6：「运放有两个输入端，直接当比较器用就行」

错误认知：比较器就是运放加正反馈，手边有 LM358，何必再买 LM393。

为什么错：五个具体问题：① 饱和恢复慢——运放内部的补偿电容让输出从饱和状态退出来要几微秒到几十微秒；② 输出电平对不上——LM358 在 3.3V 供电时输出高电平典型只有 VDD − 1.5V ≈ 1.8V，而 STM32 的 VIH 是 2.0V，逻辑可能一直读 0；③ 没有受控滞回，加正反馈又容易自激；④ 大差分输入会顶到输入保护二极管（比较器应用时输入端常相差好几伏），可能损坏或进入非正常状态；⑤ 压摆率限制——LM358 典型 0.3V/µs，3.3V 的跳变要 11µs 以上，边沿直接变成斜坡。

正确做法：用专用比较器（LM393 / LM339 / LM311 / TLV3501 / MCP6541 等）。它们的输出级就是为「在两条轨之间快速跳」设计的，而且允许大差分输入电压，参数表里直接给响应时间和滞回，不用你去赌运放的行为。

坑 7：「开漏输出不接上拉也能用；要接就接到 5V 更保险」

错误认知：上拉电阻是可选的；电压高一点抗干扰更好，所以上拉到 5V。

为什么错：开漏（开集）输出的高电平完全来自上拉电阻，不加上拉时引脚悬空：STM32 读到的是随环境漂移的随机值，悬空的 CMOS 输入还会因为停在中间电平而额外耗电。另一方面，上拉到 5V 会把 5V 直接送到 GPIO 上——即使某些引脚标了「FT（5V 容忍）」，那也是对输入信号的容忍，而且要逐个查手册确认；一旦碰上非 FT 引脚就会损坏。更隐蔽的是上下电顺序问题：3.3V 还没建立时，5V 通过上拉电阻向 GPIO 灌电流（倒灌供电），芯片会处于不可预期的状态。

正确做法：上拉电阻必需的，取 4.7kΩ ~ 10kΩ，上拉到 3.3V（和 MCU 同一套电源）。想让开漏输出驱动更高电压的负载（继电器、LED 串）没问题，但要明确那是另一条支路，不能接到 MCU 引脚上。上拉电阻也别取太大：100kΩ 配 100pF 的线缆电容，上升时间就有 22µs，边沿变缓反而会在 GPIO 门限附近产生多次翻转——并且不要指望 STM32 的内部上拉（典型 30 ~ 50kΩ，容差大）。

坑 8：「单限比较器就够了，滞回是多余的正反馈」

错误认知：阈值定好了，输入高于它就输出高、低于它就输出低，不是很清楚吗？加正反馈反而把阈值搞乱了。

为什么错：现实中的信号在阈值附近从来不是单调的。信号变化速率 1V/s、噪声峰峰值 20mV 时，信号会在阈值附近「停留」20ms，而噪声在这个窗口里以 kHz 量级来回穿越——一次缓慢的过阈值可以产生几十个边沿，每个边沿一次 EXTI 中断。按键（机械抖动 5 ~ 20ms）、长线（工频与开关噪声）、慢变传感器信号，三者都必然遇到这个问题。中断次数暴涨的直接后果是：计数翻几倍、频率读数乱跳、中断里的耗时操作把 CPU 吃光。

正确做法：加正反馈做滞回（施密特触发器）：窗口宽度 ΔV = (VOH − VOL)·R1/Rf，取预期噪声峰峰值的 3 ~ 10 倍。同时对外通信/按键信号再加一层软件去抖（中断里只置标志，10 ~ 20ms 后确认电平），两者叠加使用。

坑 9：「滞回窗口越大越抗干扰，干脆开大点」

错误认知：既然滞回能抗噪，窗口宽一点当然更好，反正信号摆幅挺大的。

为什么错：窗口是从信号的动态范围里切走的一块。信号摆幅只有 200mV 而窗口设成 300mV 时，输入无论怎么变化都凑不出足够的变化量去穿越另一条阈值线，输出会锁死在某个状态永不翻转——表现上就像「比较器坏了」，但其实是设计参数问题。此外窗口越宽，过零/阈值判断的时间误差越大（过零检测里，误差时间 ≈ ΔV / (dV/dt)）。

正确做法：窗口取「预期噪声峰峰值的 3 ~ 10 倍」，同时不超过「信号有效摆幅的 1/3 ~ 1/5」，两头都留余量。设计完用例题③那套流程反算一遍：算出 V_TH、V_TL，确认信号确实能跨越这两个值，再确认噪声翻不出这个窗口。

坑 10：「阈值电压从电源随手分压就行，电阻大点还省电」

错误认知：参考电压只是个直流电平，两只 1MΩ 电阻分压最省电，还不用加电容。

为什么错：三件事同时发生：① 比较器的输入偏置电流会在高分压电阻上产生误差——LM393 典型 25nA，乘 1MΩ 就是 25mV 的阈值偏移，而且它随温度变化；② 分压点的等效源阻抗很高，电源上的任何噪声都会被完整送到阈值上，等于把噪声直接搬进了比较器的判决条件；③ 如果分压点还要驱动后级或接长线，高源阻抗会让边沿变缓、电平不准。类似的还有「阈值电压直接取 5V 分压」——用 5V 做参考，阈值就会跟着 5V 电源漂移，而 5V（USB 供电）可能是 4.75 ~ 5.25V，误差 10%。

正确做法：① 分压电阻取 10kΩ ~ 100kΩ 量级（别到 MΩ），并用同一路稳定电源（推荐 3.3V）；② 分压点并一只 100nF ~ 1µF 到地做去耦，噪声直接短路掉；③ 需要精确阈值时改用基准芯片（如 TL431、REF3030）或低失调比较器；④ 记住一条总原则：阈值精度 = 基准精度 + 比较器失调 + 分压误差 + 偏置电流误差，这四项要一起算，别只盯着电阻的 1%。

6 · 小结与自检

这一篇从「为什么要滤波」一路走到「比较器怎么接单片机」，核心其实只有两句话：滤波器负责把有用信号和干扰在频率上分开，比较器负责在幅度上做一次干脆的判决。剩下所有的公式、元件、参数，都是为这两件事服务的。

还有五条「思路层面」的结论

  • ① 滤波的本质是频率分离。先搞清信号和噪声各自在什么频段，再决定 fc 和阶数——而不是先画电路再凑参数。
  • ② 阶数由指标决定，不由喜好决定。指标里那句「在某个频率处要衰减多少 dB」直接决定你用几阶、fc 取多少。
  • ③ Q 决定形状，不是越高越好。巴特沃斯（0.707）是通用默认值；脉冲保真挑贝塞尔（0.577）；只有为了省阶数才用切比雪夫。
  • ④ 抗混叠滤波器必须在 ADC 之前，且必须是模拟的。混叠发生在采样那一瞬间，软件只能处理采样之后的数字，救不回来。
  • ⑤ 比较器的价值在于「确定的判决」。滞回把「阈值附近的不确定」变成「两条线之间的确定」，这样单片机看到的中断源才是干净的。

自测题（先自己答，再看答案）

题 1

一个一阶 RC 低通，fc = 1kHz。在 10kHz 处的衰减大约是多少？如果换成同样 fc 的二阶巴特沃斯低通，10kHz 处的衰减又是多少？

答案：一阶约 −20dB（10 倍频率、20dB/十倍频）。二阶巴特沃斯 |H|² = 1/(1+(f/fc)⁴)，f/fc = 10 时 (f/fc)⁴ = 10000，衰减 = 10·lg(10001) ≈ −40dB。这就是「多一阶，多 20dB/十倍频」的直接体现。

题 2

一个单位增益的 Sallen-Key 低通，R1 = R2 = 10kΩ，C1 = C2 = 10nF。求它的 fc 和 Q。如果想把它改成巴特沃斯（Q = 0.707），应该改哪个元件、改成多少？改完以后 fc 变成多少？

答案：fc = 1/(2π × 10k × 10n) = 1591Hz；Q = √(C1/C2)/2 = √1/2 = 0.5（过阻尼，不是巴特沃斯）。改电容：按 C1 = 4Q²C2 = 2C2，把 C1 改成 20nF（两只 10nF 并联）即可，R 不用动。改完 fc = 1/(2π × 10k × √(20n × 10n)) = 1/(2π × 10k × 1.4142×10⁻⁸) ≈ 1125Hz（截止频率变低了，因为电容变大了）。

题 3

STM32 的 ADC 采样率是 fs = 20kHz，有用信号带宽 0 ~ 50Hz，要求奈奎斯特频率处的干扰至少衰减 40dB。应该用几阶滤波器？fc 取多少？

答案：奈奎斯特频率 = fs/2 = 10kHz。40dB 用二阶（40dB/十倍频）即可满足：10kHz = 10 × fc → fc = 1kHz。检查有用信号：50Hz 处 f/fc = 0.05，衰减几乎为 0 ✅。如果想留余量，fc 可以取 800Hz ~ 1kHz。（对比一下：若坚持用一阶，40dB 要求 fc = 100Hz，而 50Hz 的有用信号在 fc = 100Hz 时会被砍掉 −0.97dB、相位滞后 27°——勉强能用但余量很差。）

题 4

滞回比较器：VOH = 3.3V、VOL = 0.15V、R1 = 10kΩ、Rf = 220kΩ、Vref = 1.65V。求 V_TH、V_TL 和滞回窗口宽度。

答案：先算 R1/Rf = 10/220 = 0.04545，1 + R1/Rf = 1.04545。
V_TH = 1.65 × 1.04545 − 0.15 × 0.04545 = 1.725 − 0.0068 = 1.718V
V_TL = 1.65 × 1.04545 − 3.3 × 0.04545 = 1.725 − 0.150 = 1.575V
窗口 = 1.718 − 1.575 = 0.143V（143mV），也可以直接用 ΔV = (VOH−VOL)R1/Rf = 3.15 × 10/220 = 143mV 验算 ✅

题 5

LM393 的输出为什么必须外接上拉电阻？把上拉接到 5V 有什么风险？上拉电阻取 1MΩ 会怎样？

答案：LM393 是开集（开漏）输出，内部只有一只把输出拉到地的三极管，自己没有输出高电平的能力——高电平完全靠上拉电阻提供，不接就悬空、读数随机。
接 5V 的风险：① 5V 会直接加到 STM32 引脚上，非 FT 引脚会损坏，FT 引脚也要逐个确认；② 上下电顺序不当时 5V 会通过上拉电阻倒灌进 GPIO。
取 1MΩ 的后果：上升沿由 τ = Rp × C 决定，1MΩ × 100pF = 100µs，边沿变成缓坡，在 GPIO 门限附近停留很久，反而产生多次误触发，同时方波的占空比/频率特性都会被破坏。所以取 4.7kΩ ~ 10kΩ。

题 6

一个 1kHz、峰峰值 2V 的正弦信号送进单限比较器（阈值在中心），阈值附近的噪声约 30mV。不加滞回，每秒大约会多出多少次中断？加了 200mV 滞回之后为什么就好了？

答案：正弦在过零点的斜率 = 2πfV_peak = 2π × 1000 × 1 = 6283V/s。信号「待在 30mV 噪声带里」的时间 = 0.03/6283 = 4.8µs。在这段时间里，受比较器响应时间（LM393 典型 1.3µs）限制，噪声可能造成 1 ~ 3 次额外穿越——1kHz 信号每秒 1000 次穿越，于是中断从 1000/s 涨到 2000 ~ 4000/s，频率读数严重偏高且不稳定。
加 200mV 滞回后：信号要反向变化 200mV 才可能翻回来，而噪声只有 30mV，连窗口的 1/6 都不到，一个额外边沿都不会产生。代价是判决点比理想过零点略有偏移（约 ±100mV/6283V/s ≈ ±16µs，对 1kHz 而言约 1.6%），测转速完全够用。

练习（建议动手做完再看下一篇）

  1. 给自己的项目算一个抗混叠滤波器。写下你的 fs、有用信号带宽、最想压住的干扰频率与目标衰减，按例题①的六步流程算出阶数、fc、元件值，并用 E24 标准值反算实际 fc 和实际衰减。最后算一下 ADC 的源阻抗，确定采样时间该设多少。
  2. 做一个光控开关。用光敏电阻 + 分压 + LM393 滞回比较器，要求在光照逐渐变暗时点亮 LED：自己定阈值（比如 1.65V）、定滞回窗口（比如 150mV），算出 R1、Rf、Vref 与上拉电阻；再写出如何用示波器或万用表实测「翻转点」，验证窗口宽度是否符合设计（提示：缓慢调节输入电压，记录输出翻转时对应的两个输入电压）。
  3. 把电池监测扩展成四区间。在例题④的基础上增加「严重过压（14.4V 以上，立刻断开充电并报警）」和「严重欠压（10.2V 以下，强制休眠）」，用一片 LM339 实现四个区间，写出阈值、分压参数和一张完整的状态转换表。
  4. 用 MFB 拓扑做一个带增益的低通。指标：fc = 2kHz、Q = 0.707、直流增益 −2。
    提示：第 2 节 MFB 的关系式是 A0 = −R2/R1、fc = 1/(2π√(C1C2R2R3))、Q = √(C2R2R3/C1)/(R2+R3+R2R3/R1)。
    取 R2 = R3 = R（最省事），则 Q = √(C2/C1)/4，即 C2/C1 = 16Q² = 8；再取 C1 = 10nF、C2 = 82nF，算出 R 与 R1（R1 = R2/|A0|），最后反算实际的 fc 与 Q，并说明输出与输入相差多少度相位。
下一步学什么

这一篇把「模拟信号怎么进单片机」这条链路走通了：滤波 → 判决 → 中断。接下来两件事会接着往上走：一是运放本身的内部结构、失调与带宽（为什么 GBW 会限制滤波器的高频表现、为什么失调会影响阈值精度），见集成运放与信号调理；二是反馈与稳定性——为什么加正反馈能做滞回、而负反馈加错了会振荡，见反馈与稳定性入门。另外，本篇反复用到的「电容在频域里的表现」如果还有点模糊，回头翻一下正弦交流电路与相量法会轻松很多。
