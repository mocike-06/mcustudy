电路定理：叠加、戴维宁与诺顿

上一篇你把电阻串并联、分压分流玩熟了，能算限流电阻、能算采样网络。但真实电路很少长得那么老实：一块板子上有 USB 的 5V、有电池、有 LDO、有分压网络、有传感器的输出阻抗，它们互相咬在一起。这时候你需要一个「把整块电路压扁」的本事——不管左边多复杂，从右边两个端子看进去，它永远只等于一个电源串一个电阻。这就是戴维宁定理。这一篇要讲的三件事——叠加、戴维宁/诺顿、最大功率传输——是你以后估算 ADC 采样误差、判断 IO 能不能直接驱动某个负载、决定传感器后面要不要加电压跟随器的全部理论依据。

为什么需要它

先讲两个你早晚会撞上的现场。

现场一：万用表量 3.3V，接上模块就变成 2.6V。你把 PA5 配置成推挽输出高电平，万用表量引脚对 GND 清清楚楚是 3.3V，你确信「这个引脚能输出 3.3V」。于是你把一个需要 3.3V 供电的小模块直接挂到这个引脚上——模块不工作，再一量，引脚上只有 2.6V。你把引脚换一个再试，还是这样。你开始怀疑「是不是这个型号的 IO 驱动能力不行」。

现场二：电池电压检测，空载准、带载就不准。你用一个 9V 电池经 10kΩ 和 10kΩ 分压接到 ADC，程序里乘 2 换算回电池电压，空载时读数 9.0V，完全正确。一按电机，读数掉到 8.1V。你以为是电机干扰，加了电容、换了屏蔽线，没用。换一节新电池，还是 8.1V。

这两个现场看起来毫无关系，但它们的根是同一件事：你一直把电源和引脚当成「理想的」——以为它输出的电压是固定的，不管接什么负载都不变。而现实里每一个源都有内阻，每一条支路都在互相影响。

这一篇会给你三件武器，正好对付这类问题：

  • 叠加定理——一个电路里有好几个电源，它们一起作用时算不清。那就一次只留一个，其他全关掉，把几次的结果加起来。它回答的是「多个源各自贡献了多少」。
  • 戴维宁定理 / 诺顿定理——不管左边那一大坨电路多复杂，只要它是线性的、对外只有两个端子，那么从这两个端子看进去，它永远等于一个电压源串一个电阻。它回答的是「这个东西到底有多大劲、有多软」。
  • 最大功率传输定理——负载电阻取多少，才能从这个源里拿到最大的功率？答案是 RL = Req。但更有用的是它后面的那句：这时候的效率只有 50%。很多场合你根本不想要这个「最优」。

戴维宁定理是这三件里最值钱的一件。学会它之后，你看电路图的方式会变：以前你看到的是「一堆电阻电容三极管」，之后你看到的是「一个 2.5V 的源，内阻 5kΩ 」「一个 3.3V 的源，内阻 50Ω」。有了这两个数，任何「能不能带动」「会不会掉压」「误差多大」的问题，都变成一道除法题。

先记住一句话，后面所有内容都是它的注脚

任何一个由电阻和电源组成的线性电路，对外看都只有一个电压和一个内阻。

你说的每一句话其实都已经用到了它：「这个电池带不动电机」（内阻大）、「这个电源很稳」（内阻小）、「这个信号源太弱，一接就被拉下去了」（内阻大）。戴维宁定理只是把这种直觉，变成了一个能算出来的数。

学习顺序上，这一篇是承上启下的位置：上一篇《电阻电路的等效变换与分压分流》教了你怎么把电阻串并联化简——那是「没电源的网络」。这一篇把它扩展到「有电源的网络」，于是你能化简的东西一下子多了十倍。而下一篇《一阶动态电路》里的电容充电、上电延时，用的正是这一篇里「等效电阻 Req 与电容相乘」的套路。

核心概念

这一节按「从零散到整体」的顺序推：先讲怎么把多个电源拆开（叠加），再讲怎么把一条已知支路换掉（替代），然后是本篇的主角——怎么把整个网络压成一个源加一个电阻（戴维宁、诺顿），最后讲这个等效源接上负载后功率怎么分配（最大功率传输）。

叠加定理：把多个电源拆开算

定理内容：在线性电路中，当有多个独立源同时作用时，任一支路上的电流（或任意两点间的电压），等于各个独立源单独作用时在该支路上产生的电流（或电压）的代数和。

「单独作用」的操作方法是固定的三步，背下来就行：

【第一步】只留下一个独立源，其余独立源全部「置零」

     · 不用的【理想电压源】→ 短路（因为它两端电压本来是固定的，置零就是 0V）
     · 不用的【理想电流源】→ 开路（因为它支路电流本来是固定的，置零就是 0A）
     · 【受控源】→ 一个都不能动！受控源不是激励，必须原样保留

【第二步】在这个只剩一个源的电路里，求出你关心的那个电流或电压

     这时候电路通常简单很多：一个源 + 几个电阻的串并联，
     用上一篇的分压分流公式就能直接算。

【第三步】对每个源重复第一、二步，然后把所有结果【按参考方向】相加

     · 方向和你规定的正方向一致 → 取正号
     · 方向相反 → 取负号
     · 这就是「代数和」，不是简单相加，符号搞错是最常见的错

【口语化记忆】
     把多个源当成多个「说话的人」，
     一次只让一个人说话，记下他的话，
     最后把所有话加起来 —— 但要注意有人是在「反着说」（负号）。

为什么要求「线性」？因为叠加的本质是数学上的线性性质：如果 y = f(x) 满足 f(x1 + x2) = f(x1) + f(x2)，才谈得上叠加。电阻、独立源、受控源都是线性的；二极管、三极管的大信号模型、饱和的运放、开关电源，都是非线性的，叠加定理对它们直接失效。

最容易掉进去的坑：功率不能叠加

这是叠加定理在全书中被考得最多、也坑得最多的一条：叠加定理只能用来求电流和电压，绝对不能用来求功率。

原因是数学上的：功率是电流（或电压）的二次函数。P = I²R，你把 I = I1 + I2 代进去展开，得到的是

P = (I1 + I2)²R = I1²R + I2²R + 2I1I2R

后面那个 2I1I2R 是「交叉项」，而 P1 + P2 = I1²R + I2²R 里根本没有它。所以

P ≠ P1 + P2。第三节的例题里我会给你一组真实数字，你会看到「分成两份算出来的功率加起来 4.08W，而真实功率是 6W」，差了将近一半。

正确做法：要算某个电阻的功率，先用叠加定理求出它上面的总电流（代数和），再用 P = I²R 算一次。顺序不能颠倒。

叠加定理有什么用？它的实用价值有两个：一是把复杂电路拆成若干个简单电路，每个都只用分压分流就能算（第三节例题 2 会让你亲手体会）；二是它是戴维宁定理的证明基础——教科书里戴维宁定理就是用叠加定理推出来的。另外还有一个很实用的场景：当你只想看「某个干扰源贡献了多少」时，叠加定理是唯一的答案。比如板子上有开关电源的纹波和电机的噪声两个干扰源，想知道各自在被测信号上贡献了多少毫伏，就是叠加定理的典型用法。

替代定理：换掉一条已知支路

替代定理（也叫置换定理）形式非常简单，但它是理解后面戴维宁定理的钥匙。

定理内容：在一个有唯一解的电路中，如果已知第 k 条支路的电压为 uk、电流为 ik，那么这条支路可以换成一个电压为 uk 的理想电压源，或者换成一个电流为 ik 的理想电流源，换完之后电路里其他各处的电压电流完全不变。

【原来的电路】                       【换法一：换成电压源】

   ┌──[ 网络 N ]──┬── a               ┌──[ 网络 N ]──┬── a
   │              │                   │              │
   │            [ 支路 k ]            │           ┌──┴──┐
   │            （任意元件：           │           │ uk  │  ← 电压为 uk 的理想电压源
   │             电阻/电源/            │           └──┬──┘
   │             二极管都行）           │              │
   └──────────────┴── b               └──────────────┴── b

【换法二：换成电流源】               【注意】
                                     ① 换之前必须先【已知】uk 或 ik，
   ┌──[ 网络 N ]──┬── a                 不知道就无从换起；
   │              │                   ② 换电压源时，参考方向要和原来的
   │           ┌──┴──┐                   uk 一致；换电流源时同理；
   │           │ ↑ik │  ← 电流为 ik     ③ 替代后电路必须有唯一解；
   │           └──┬──┘     的理想电流源  ④ N 内部【不能有】受这条支路
   │              │                     电流/电压控制的受控源，
   └──────────────┴── b                否则一换就自相矛盾。

【三种电路在 a、b 之外的所有地方，电压电流完全相同】

它凭什么成立？因为电路的解由基尔霍夫定律和元件特性唯一确定。既然你已经知道这条支路上的电压是 uk，那么你用任何一个「电压同样是 uk」的东西去替换它，外部网络看到的边界条件一个字都没变，解自然也不会变。

它在工程上的影子：你其实一直在用替代定理。比如你把一个复杂的传感器模块当成「输出 0~5V 的电压源」来画等效电路——你并不知道它内部有什么，你只知道它输出端呈现的电压。再比如你做仿真时，把一个模块用「理想电压源 + 内阻」这个二端网络代替，也是一样的道理。替代定理说的就是：只要对外端口的行为一样，里面是什么根本无所谓。

替代定理和等效变换的区别（很多人混）

等效变换（上一篇的串并联、Y-Δ）是两个电路对外完全等效，替换之后连内部都「说得通」，属于双向可逆的等价关系。

替代定理是针对某一个具体工作状态的：你必须先知道这条支路此刻的电压或电流是多少，才能做替换。工作状态一变，替换出来的电源值也得跟着变。所以它是一次性的、依赖于具体解的，不是等价变换。

戴维宁定理：一个源加一个电阻

现在进入本篇的正题。

定理内容：任何一个线性含源二端网络，对外电路来说，都可以等效为一个理想电压源 Uoc 串联一个电阻 Req。其中：

  • Uoc 是这个网络在端口处的开路电压（open-circuit voltage，下标 oc 就是这个词），单位 V。
  • Req 是这个网络的等效电阻（也叫输出电阻、内阻、戴维宁电阻），单位 Ω。它是把网络内部所有独立源置零之后，从端口看进去的电阻。
【原电路】左边这一大坨，从 a、b 两个端子看出去接负载

        ┌────[ R1 ]────┬──[ R3 ]──┐
        │              │          │
      [Us1]          [R2]      [Us2]        ┌──────┐
        │              │          │      a ─┤      │
        └──────────────┴──────────┴─── b ───┤ 负载 │
        └──────── 网络 N（随便多复杂）──┘    └──────┘
                                              ↑
                                   负载只看得见 a、b 两个端子，
                                   它根本不关心里面有什么

【戴维宁等效电路】负载看到的东西，永远长这样

                              ┌──[ Req ]──┬──── a
                              │           │
                           [ Uoc ]     ┌──┴──┐
                              │        │ 负载 │
                              └──────────┴── b ─┘

        ┌───────────────────────────────────────────────┐
        │  对【任意】负载，两个电路端口上的电压 u 和     │
        │  电流 i 的关系完全相同 —— 这就是「对外等效」   │
        └───────────────────────────────────────────────┘

「对外等效」这四个字是戴维宁定理的灵魂，也是最容易被误解的地方。它到底等在哪里？等的是端口上的伏安特性——也就是「端口电压 u」和「端口电流 i」之间那条关系曲线。这条曲线只有两个参数：截距是 Uoc，斜率是 −Req。

   端口电压 u
        ▲
   Uoc ─┤●
        │  ╲
        │    ╲            这条直线就是网络 N 的全部「对外性格」
        │      ╲          原电路画出来是它，
        │        ╲        戴维宁等效电路画出来也是它，
        │          ╲      二者【逐点重合】
      0 ┤────────────●──────────► 端口电流 i
                    Isc
                     ↑
              短路时的电流 Isc = Uoc / Req

   直线方程：  u = Uoc − Req · i

   · 空载（i = 0）：端口电压 = Uoc          ← 这叫「开路电压」
   · 短路（u = 0）：端口电流 = Uoc / Req    ← 这叫「短路电流」
   · 带载：负载自己那条 u = i · RL 的直线，
           和这条线相交的点，就是实际工作点

【结论】只要两件事对得上，两个电路对任何负载都等价：
        ① 开路电压一样 ② 等效电阻一样
「对外等效」不等于「对内等效」

这是戴维宁定理最反直觉的一点：等效电路和原电路，对外部负载的表现一模一样，但内部的功率账本完全不同。

原电路内部可能有五个电阻在发热、有一个电源在被反向充电；而等效电路内部只有一个电阻在发热。所以：

  • 可以用等效电路算负载上的电流、电压、功率——这些对外量完全正确。
  • 不能用等效电路算原电路内部某个电阻的功率、某个电源发出的功率、整体效率。要算这些必须回到原电路。

第三节例题 1 里我会给你看具体数字：同一个负载在原电路里拿到的效率是 42.9%，在等效电路里算出来却是 60%。两个都不算错，只是回答的不是同一个问题。

求 Req 的一个小技巧：先看端口是不是「直接跨在电源上」

如果置零之后你发现 a、b 之间出现了一条纯导线通路（中间没有任何电阻），那么 Req = 0。这时候戴维宁等效电路退化成一个理想电压源，短路电流为无穷大——第 ③ 步的「开路短路法」会直接失效（分母是 0），只能靠置零化简或者从定义上判断。这个坑在第五节还会再提一次。

诺顿定理：电流源并联电阻

定理内容：同一个线性含源二端网络，也可以等效为一个理想电流源 Isc 并联一个电阻 Req。其中 Isc 是端口的短路电流（short-circuit current），Req 与戴维宁等效里的那个电阻是同一个值。

【怎么求 Isc】把 a、b 用一根理想导线（电流表）直接短接

        ┌────[ 网络 N ]────┬──── a
        │                  │
        │                  ├─────────┐
        │                  │         │  ← 短路电流 Isc 从 a 流到 b
        └──────────────────┴──── b ───┘

   此时端口电压 u = 0，量到的电流就是 Isc。
   ★ 注意：短路电流可能很大，现实中量之前先估算一下，
     别拿真电路去怼 —— 这一步在纸上算就好。

【诺顿等效电路】

                              ┌──── a
                              │
                           ┌──┴──┐
                           │ ↑Isc│   ← 电流源，恒为 Isc
                           └──┬──┘
                              │
                           [ Req ]       ← 与电流源【并联】
                              │
                              └──── b

   负载上的电流： I = Isc × Req / (Req + RL)   ← 分流公式

什么时候用诺顿比戴维宁方便？当你的电路里有电流源、或者有多条支路并联的时候。因为诺顿等效电路天生就是「并联」结构，和这类电路「长相一致」，代数上往往更短；反之，遇到串联为主、电压源为主的电路，戴维宁更顺手。两者数学上完全等价，用哪个纯粹看哪个算得快。

一个工程上的判断口诀：看负载想要什么

负载是电压驱动型的（比如 ADC 输入、MOS 管栅极、CMOS 输入），你关心的是「源的电压稳不稳」，用戴维宁模型看最直观——串联的 Req 越小，带载后电压掉得越少。

负载是电流驱动型的（比如 LED 恒流、4~20mA 电流环、电流互感器），你关心的是「源的电流稳不稳」，用诺顿模型看最直观——并联的 Req 越大，改变负载时电流变化越小。同一个东西的两种画法，各看一面。

戴维宁与诺顿的互换

既然两个等效电路描述的是同一个网络，它们之间必然可以自由互换。互换公式只有一组，非常好记：

【电压源 + 串联电阻】→【电流源 + 并联电阻】

            Uoc = Isc × Req

            等效电路长这样：

     ┌──[ Req ]──┬── a              ┌──── a
     │           │                   │
  [ Uoc ]    （负载）             ┌──┴──┐
     │           │                │ ↑Isc│   Isc = Uoc / Req
     └───────────┴── b             └──┬──┘
                                    │
                                 [ Req ]   ← 同一个 Req，从串联变并联
                                    │
                                    └──── b

【三个量，记住这一句就够】
   「电压源串电阻」和「电流源并电阻」是一回事，
   换算靠欧姆定律：  Uoc = Isc × Req
   而且【Req 在两边是同一个数值】，只是从串联挪到了并联。

【记忆口诀】
   串联变并联，源的性质跟着换 ——
     电压源 → 电流源（除以 Req）
     电流源 → 电压源（乘以 Req）
   电阻不动。

【方向别搞错】
   电压源的【正极】那一端，对应电流源【流出】的那一端。
   换的时候在心里走一遍：电流从正极流出去，经过负载回来。
对比项戴维宁等效诺顿等效
电路结构电压源 串联 电阻电流源 并联 电阻
源的参数Uoc = 端口开路电压，单位 VIsc = 端口短路电流，单位 A
电阻参数完全相同的 Req，求法也一样
换算关系Uoc = Isc · ReqIsc = Uoc / Req
负载电流I = Uoc / (Req + RL)I = Isc · Req / (Req + RL)
什么电路用它更省事电压源多、串联结构为主电流源多、并联结构为主
什么时候会退化Req = 0 → 变成理想电压源Req = ∞ → 变成理想电流源
适合的负载类型电压驱动型：ADC、CMOS 输入、栅极电流驱动型：LED 恒流、电流环
「理想电压源」和「理想电流源」是两种极端，别把它们当成真器件

Req = 0 表示这个源无论输出多大电流，端口电压纹丝不动——这是理想电压源，现实中不存在，只有「内阻小到可以忽略」的近似（比如实验室稳压电源接粗短导线时，可以按 0.01Ω 量级估算）。

Req = ∞ 表示这个源无论端口电压怎么变，输出电流都恒定——这是理想电流源，同样不存在，近似它的是恒流源电路、光电二极管在特定条件下的输出等。

你在工程上做的每一次「近似」，本质都是在判断「这个 Req 相对负载是大还是小，大到什么程度可以当 0，小到什么程度可以当 ∞」。这个判断力比会算公式重要得多。

含受控源：加压求流法与开路短路法

受控源是电路理论里一个特殊的存在：它的电压或电流不独立，而是由电路里另一处的电压或电流决定。常见的四种：

类型全称控制量被控量系数量纲
VCVS压控电压源某处的电压 U电压无量纲（放大倍数 μ）
VCCS压控电流源某处的电压 U电流电导 S（西门子）
CCVS流控电压源某处的电流 I电压电阻 Ω（跨阻）
CCCS流控电流源某处的电流 I电流无量纲（放大倍数 β）

你以后会遇到的所有小信号模型——三极管的 β·ib、MOS 管的 gm·ugs、运放的 A·ud——全都是受控源。所以「含受控源电路怎么求等效电阻」不是一道考试题，而是你以后看任何放大器输入输出阻抗的基本功。

为什么受控源不能置零？因为「置零」这个操作的含义是「让这个激励变成 0」，对独立源成立——把电压源短掉，它就是一个 0V 的源。但受控源不是激励，它是一个由别的变量决定的约束关系。如果你把它置零，就等于强行规定「控制量恒为 0」，电路的结构被改了，算出来的当然不是原来的等效电阻。所以：独立源置零，受控源保留。

【第 1 步】把网络内部【所有独立源置零】，【受控源全部保留】

【第 2 步】在端口 a、b 之间外加一个电压源 U

开路短路法：不用外加电源，直接量两头
════════════════════════════════════════════════════════════

【第 1 步】端口开路 → 求开路电压 Uoc
【第 2 步】端口短路 → 求短路电流 Isc
【第 3 步】

                    Req = Uoc / Isc

   这个式子的来源很直观：从 u-i 直线看，
   空载点 (0, Uoc) 和短路点 (Isc, 0) 连起来的斜率就是 −Req。

【★ 一个重要的前提：Uoc 必须 ≠ 0】
   如果网络内部没有独立源（纯电阻 + 受控源），
   那么 Uoc = 0，Isc 也必然是 0，0/0 得不出任何东西。
   这时候【只能】用加压求流法。

【★ 另一个前提：Isc 必须是有限值】
   如果端口置零后 a、b 之间是一条纯导线（Req = 0），
   短路电流在理论上无穷大，这个式子同样失效。

【什么时候开路短路法特别好用？】
   网络里有独立源、端口短路后电路变得特别简单的时候。
   比如端口一短，某个受控源的控制量正好变成 0，
   受控源自动「消失」，短路电流一眼就能看出来。
两个方法选哪个？一句话决策

网络里有独立源 → 两个方法都能用，看哪个算得快（短路后受控源消失就选开路短路法）。

网络里没有独立源（纯电阻 + 受控源）→ 只能加压求流法，因为开路短路法会得到 0/0。

两个方法算出来的结果必须一致，这也是你自检的最好手段。第三节例题 4 我会把两个方法都走一遍。

最大功率传输与效率的权衡

有了戴维宁等效电路，「负载能拿到多少功率」就变成一个纯粹的数学问题。

负载接在等效源后面，整个回路是 Uoc、Req、RL 三者串联：

I = Uoc / (Req + RL)，于是负载上的功率

PL = I² RL = Uoc² · RL / (Req + RL)²

把 RL 当成自变量，对 PL 求极值（令 dPL/dRL = 0），得到的结论是：

最大功率传输定理

当负载电阻等于等效内阻，即 RL = Req 时，负载从电源获得的功率最大。

此时的最大功率是（注意分母上的 4）：

Pmax = Uoc² / (4 Req)

而在这一点上，负载得到的功率和电源内阻上消耗的功率正好相等（各占一半），所以

效率 η = 50%。

  负载功率 PL
      ▲
      │            ╭──╮
      │          ╱      ╲
      │        ╱          ╲            ← 峰值点：RL = Req
      │      ╱              ╲
      │    ╱                  ╲
      │  ╱                      ╲╲
      │╱                          ╲╲╲
      └────┴───────────────────────────╲──► 负载电阻 RL
          RL = Req

   效率 η = RL / (RL + Req) 的变化方向【正好相反】：

   RL 很小时  → 功率小、效率低（大部分功率烧在内阻上）
   RL = Req   → 功率最大、效率 50%
   RL = 3Req  → 效率 75%，但功率只有峰值的 75%
   RL = 9Req  → 效率 90%，功率只剩峰值的 36%
   RL → ∞     → 效率趋近 100%，功率趋近 0（等于空载）

【一句话】功率最大点，恰好是效率的中间点。
         想要功率就得忍受一半的损耗；
         想要效率就得放弃功率。
         工程上从来没有「两者都要」，只有「你要哪一个」。

这就是为什么「阻抗匹配」在工程上被分成两个完全相反的流派：

应用场景追求什么负载怎么取典型效率为什么
电力系统（发电、输电）效率RL ≫ Req90% 以上电是要卖的，烧在内阻上的每一瓦都是钱和热量
射频 / 天线 / 功放输出功率RL = Req（共轭匹配）理论 50%信号能量本来就少，能传出去多少算多少；且不匹配会反射
音频功放（电子管时代）功率匹配低输出变压器做阻抗变换，榨干每一毫瓦
单片机的信号链
（ADC 采样、传感器接口）		电压准确度RL ≫ Req
（要的是「几乎不取电流」）		不用谈效率要的是「被测电压不失真地传过来」，功率根本不是目标
单片机驱动负载能不能带动看 RL 与 Req 的比值——比值越大，负载上分到的电压越接近源电压
给单片机开发者的一句话

你做的绝大多数事情，属于表格最后两行：你要的是「电压传得准」和「能不能带动」，而不是「功率最大」。

所以当有人在论坛上告诉你「这里要做阻抗匹配」时，先问一句：匹配到多少？——如果对方回答「让负载阻抗远大于源阻抗」，那他说的是信号链的思路（RL ≫ Req）；如果对方说「让两者相等」，那他说的是射频或功率传输的思路（RL = Req）。这两种说法都对，但用错了地方就全错。第四节会给你一个具体的例子。

例题 1：用戴维宁定理求支路电流

按第二节的四步流程走。

第 ① 步：摘掉负载，标出端子。把 RL 从节点 B 和地之间拿掉。端口的 a 端就是节点 B，b 端就是参考节点（地）。

第 ② 步：求开路电压 Uoc。负载摘掉之后，R3 变成了一条「悬空的尾巴」——它一端接节点 A，另一端接节点 B，而节点 B 现在没有别的支路了。这意味着没有电流能流过 R3（KCL：节点 B 只有 R3 一条支路，流入必须等于流出，所以只能是 0）。

R3 上没有电流 → R3 上没有电压降 → UB = UA。于是问题退化成：只有 R1、R2 两条支路的节点 A 的电压是多少。

对节点 A 写 KCL（流出节点 A 的电流之和 = 0）：

   从 Us1 支路流向 A 的电流：  (12 − UA) / 3
   从 Us2 支路流向 A 的电流：  (6  − UA) / 6
   R3 支路：没有电流（上面已经论证过）

   令流出 A 的电流总和为零：

        (UA − 12)/3 + (UA − 6)/6 = 0

   两边同乘 6 消掉分母：

        2(UA − 12) + (UA − 6) = 0
        2UA − 24 + UA − 6 = 0
        3UA = 30

        UA = 10 V

   【所以】

        Uoc = UB = UA = 10 V      （a 端为正，即上端为正）

   【物理意义】这就是这块电路「空载时能给出 10V」——
              两个电源 12V 和 6V 经过 R1、R2 的分压混合，
              在 A 点合成了一个 10V。

第 ③ 步：求等效电阻 Req。电路里没有受控源，所以走「情况 A」：把两个独立电压源都短路。Us1 短路后，R1 的上端变成接地；Us2 短路后，R2 的下端也变成接地。于是 R1 和 R2 都变成了「从节点 A 到地」的电阻，两者并联。

【置零后的电路】

              R1 = 3Ω          A       R3 = 2Ω       B
      ┌───────────[████]────────┬───────[████]────────┬─── a
      │                           │                     │
     GND                       ┌──┴──┐                  │
   (Us1 被短路)                │ R2  │ 6Ω               │
                               │     │                  │
                               └──┬──┘                  │
                                  │                     │
                                 GND                    │
                            (Us2 被短路)                │
      └─────────────────────────────────────────────────┴─── b

【从 a、b 端口看进去】
   · R1 接在 A 与地之间
   · R2 接在 A 与地之间      → 两者【并联】
   · 并联结果再与 R3【串联】，因为电流必须从 A 经过 R3 才能到 b

        R1 ∥ R2 = (3 × 6) / (3 + 6) = 18 / 9 = 2 Ω

        Req = R3 + (R1 ∥ R2) = 2 + 2 = 4 Ω

   【物理意义】这块电路「看上去是个 10V 的源，
              但它的内阻有 4Ω，并不硬」。

第 ④ 步：接回负载求解。

【戴维宁等效电路 + 负载】

           ┌──[ Req = 4Ω ]──┬──── a
           │                 │
        [ Uoc = 10V ]     [ RL = 6Ω ]
           │                 │
           └─────────────────┴──── b

   回路总电阻 = Req + RL = 4 + 6 = 10 Ω

        I = Uoc / (Req + RL) = 10 / 10 = 1.0 A

        UL = I × RL = 1.0 × 6 = 6.0 V

        PL = I² × RL = 1.0² × 6 = 6.0 W

   【答案】流过 RL 的电流是 1.0 A，负载上电压 6.0 V，
           负载消耗功率 6.0 W。

   【顺便算一下端口上的「损失」】
        Req 上消耗 = I² × Req = 1² × 4 = 4 W
        等效源发出 = Uoc × I = 10 × 1 = 10 W
        效率 = 6 / 10 = 60%（这是【等效电路】里的账）

第 ⑤ 步：回原电路验算。这一步不能省。直接在原电路上用节点法独立算一遍：

【节点 B 的 KCL】（流出 B 的电流和为 0）
        (UB − UA)/2 + UB/6 = 0
   两边乘 6：  3(UB − UA) + UB = 0
              4UB = 3UA
              UB = 0.75 UA                    ……(式 1)

【节点 A 的 KCL】（流出 A 的电流和为 0）
        (UA − 12)/3 + (UA − 6)/6 + (UA − UB)/2 = 0
   两边乘 6：  2(UA − 12) + (UA − 6) + 3(UA − UB) = 0
              2UA − 24 + UA − 6 + 3UA − 3UB = 0
              6UA − 3UB = 30
              2UA − UB = 10                    ……(式 2)

【联立求解】
   把 (式 1) 代入 (式 2)：  2UA − 0.75UA = 10
                            1.25UA = 10
                            UA = 8 V
                            UB = 0.75 × 8 = 6 V

【负载电流】
        I = UB / RL = 6 / 6 = 1.0 A     ✅ 与戴维宁结果完全一致

   【注意一个细节】原电路里 UA = 8V，
   而戴维宁等效电路里端口开路电压是 10V —— 这不是矛盾。
   开路电压是「负载拿掉」时的电压，现在负载接着，
   端口被 RL 拉到了 6V，A 点自然也跟着低下来。
   10V 是【空载】值，6V 是【带 6Ω 负载】值，两者本来就不同。

现在来看「对内不等效」这件事的真实数字。回到原电路，算一算每个电源到底在干什么：

【各支路电流】
   Us1 支路： I1 = (12 − UA)/3 = (12 − 8)/3 = +1.333 A   （流出正极，发出功率）
   Us2 支路： I2 = (6  − UA)/6 = (6  − 8)/6 = −0.333 A   （【负号】：电流倒着流）
   R3 支路：  I3 = (UA − UB)/2 = (8 − 6)/2 = 1.0 A

【电源的功率】
   Us1 发出： 12V × 1.333A = 16 W
   Us2 发出： 6V × (−0.333A) = −2 W
              → 负号表示 Us2 实际在【吸收】2W，
                它被 Us1 逼着反向充电

【电阻的功率】
   R1： 1.333² × 3 = 5.33 W
   R2： 0.333² × 6 = 0.67 W
   R3： 1.0²   × 2 = 2.00 W
   RL： 1.0²   × 6 = 6.00 W
   电阻合计 = 14.00 W

【验算】电源净发出 = 16 − 2 = 14 W = 电阻总消耗 ✅ 能量守恒

【原电路的真实效率】
   负载拿到 6W，电源一共发出 14W
   效率 = 6 / 14 = 42.9 %

【对比：等效电路给出的效率是 60%】
   ┌──────────────────────────────────────────────────────┐
   │ 两个数字都不错，只是回答的不是同一个问题：           │
   │   42.9%  ← 整个电路的真实效率（必须回原电路算）       │
   │   60%    ← 只把 Req 当成唯一内阻时的效率             │
   │                                                      │
   │ 戴维宁等效保证的是【负载上的电流、电压、功率正确】，  │
   │ 它【不保证】内部功率分布正确。                       │
   │ 原电路里 R1、R2、R3 三个电阻各自发热多少，           │
   │ 等效电路里只有一个 Req 在发热，账对不上是必然的。     │
   └──────────────────────────────────────────────────────┘

例题 2：用叠加定理算同一个电路

这次不摘负载，直接在原电路上做叠加。要算的目标仍然是流过 RL 的电流 I。顺序是：先只留 Us1，再只留 Us2，最后相加。

【电路变形】
   Us2 被短路 → R2 的下端直接接地了，
   所以 R2 变成「从节点 A 到地」的一条支路。

                 R1 = 3Ω          A      R3 = 2Ω      B
      ┌───────────[████]──────────┬──────[████]───────┬──────┐
      │                           │                   │      │
   [ 12V ]                     [ R2 = 6Ω ]         [ RL = 6Ω ]
      │                           │                   │      │
      └───────────────────────────┴───────────────────┴──────┘
                                 GND

【第一步：从 A 点看，负载等效成什么？】
   B 点只有两条支路（R3 和 RL），所以 R3 与 RL 串联：
        R_AB = R3 + RL = 2 + 6 = 8 Ω

【第二步：R2 与 R_AB 并联，得到 A 点对地的等效电阻】
        R_A = R2 ∥ R_AB = (6 × 8) / (6 + 8) = 48 / 14 = 3.4286 Ω

【第三步：12V 经 R1 与 R_A 分压，求 UA'】
        UA' = 12 × R_A / (R1 + R_A)
            = 12 × 3.4286 / (3 + 3.4286)
            = 12 × 3.4286 / 6.4286
            = 6.400 V

【第四步：求流过 RL 的电流 I'】
        通过 R3 与 RL 这一串的电流 = UA' / R_AB
        I' = 6.400 / 8 = 0.800 A     方向：A → B → 地
【电路变形】
   Us1 被短路 → R1 的上端直接接地，
   所以 R1 变成「从节点 A 到地」的一条支路。

                 R1 = 3Ω          A      R3 = 2Ω      B
      ┌───────────[████]──────────┬──────[████]───────┬──────┐
      │                           │                   │      │
     GND                       [ R2 = 6Ω ]         [ RL = 6Ω ]
                                  │                   │      │
                              [ 6V ]                  │      │
                                  │                   │      │
      └───────────────────────────┴───────────────────┴──────┘

【第一步：负载侧仍是 R3 与 RL 串联】
        R_AB = 2 + 6 = 8 Ω

【第二步：R1 与 R_AB 并联，得到 A 点对地的等效电阻】
        R_A = R1 ∥ R_AB = (3 × 8) / (3 + 8) = 24 / 11 = 2.1818 Ω

【第三步：6V 经 R2 与 R_A 分压，求 UA''】
        UA'' = 6 × R_A / (R2 + R_A)
             = 6 × 2.1818 / (6 + 2.1818)
             = 6 × 2.1818 / 8.1818
             = 1.600 V

【第四步：求流过 RL 的电流 I''】
        I'' = UA'' / R_AB = 1.600 / 8 = 0.200 A   方向：A → B → 地
【方向核对】
   I'  的方向：从 A 经 R3、RL 到地（我们规定的正方向）→ 取【正号】
   I'' 的方向：同上                                   → 取【正号】

【叠加】
        I = I' + I'' = 0.800 + 0.200 = 1.000 A

   ✅ 与例题 1 用戴维宁定理算出的 1.0 A 完全一致。
      两条完全不同的路径得到同一个数，说明两边都没算错。

【从这道题能看出的两件事】
   ① 叠加定理确实能把「两个源混在一起」的电路，
      拆成两个「一个源 + 串并联」的简单电路，
      每个都只用分压公式就能算 —— 这就是它的实用价值。
   ② 但当电路的规模变大时，
      「每个源都要重算一遍」的开销会线性增长。
      而戴维宁定理只要求一次开路电压 + 一次等效电阻，
      所以工程上做估算，戴维宁用得比叠加多得多。
现在来算算「功率不能叠加」到底差多少

刚才两个分电流是 I' = 0.8A 和 I'' = 0.2A，负载是 RL = 6Ω。

错误做法（把功率也叠加）：

P' = 0.8² × 6 = 3.84 W，P'' = 0.2² × 6 = 0.24 W，加起来 = 4.08 W。

正确做法（先叠加电流，再算一次功率）：

I = 1.0 A → P = 1.0² × 6 = 6.00 W。

差了 6.00 − 4.08 = 1.92 W，相对误差 32%。这不是「有点不准」，是彻底错了。差的那 1.92W 正是交叉项 2I'I''RL = 2 × 0.8 × 0.2 × 6 = 1.92 W——两个源的贡献在负载上「互相做功」的那一部分，叠加定理的线性形式抓不到它。

例题 3：最大功率传输与效率的权衡

继续用例题 1 得到的等效源：Uoc = 10V、Req = 4Ω。现在问三个问题。

【直接套定理】
        RL = Req = 4 Ω

【此时的具体数值】
        回路总电阻 = 4 + 4 = 8 Ω
        I = 10 / 8 = 1.25 A
        UL = 1.25 × 4 = 5.0 V
        PL = I² × RL = 1.25² × 4 = 6.25 W

【用最大功率公式核对】
        Pmax = Uoc² / (4 Req) = 100 / (4 × 4) = 100 / 16 = 6.25 W ✅

【注意端口电压只有 5V】
   源的开路电压是 10V，接上匹配负载后端口只剩 5V ——
   一半的电压掉在了内阻上。这不是「故障」，
   而是匹配状态的必然结果。
   公式： I = 10/(4+RL)      PL = I²·RL       η = RL/(4+RL)

   ┌────────┬─────────┬────────┬─────────┬───────────┬────────┐
   │  RL/Ω  │ I / A   │ UL / V │  PL / W │ 电源发出/W │ 效率   │
   ├────────┼─────────┼────────┼─────────┼───────────┼────────┤
   │   2    │  1.667  │  3.33  │  5.56   │   16.67   │  33%   │
   │   4 ★  │  1.250  │  5.00  │  6.25   │   12.50   │  50%   │
   │   6    │  1.000  │  6.00  │  6.00   │   10.00   │  60%   │
   │  12    │  0.625  │  7.50  │  4.69   │    6.25   │  75%   │
   │  36    │  0.250  │  9.00  │  2.25   │    2.50   │  90%   │
   │   ∞    │   0     │ 10.00  │   0     │     0     │ 100%   │
   └────────┴─────────┴────────┴─────────┴───────────┴────────┘
      ★ = 最大功率点

   【三个值得盯着看的现象】
   ① 从 RL = 4Ω 加到 36Ω（电阻变成 9 倍），
      功率从 6.25W 掉到 2.25W（掉到 36%），
      但效率从 50% 升到 90%。【一升一降，方向相反】。

   ② RL 从 4Ω 减到 2Ω：效率掉到 33%，
      功率也跟着掉到 5.56W ——
      【匹配点两侧都亏，匹配点独一份】。

   ③ 真正做电源的人，眼睛盯着的是最后一列；
      真正做射频的人，眼睛盯着的是第四列。
      两拨人吵架，往往是因为没说是哪一列。

【回到例题 1 的真实电路做对比】
   例题 1 里 RL = 6Ω，负载拿到 6W，
   而这个等效源能给出的最大功率是 6.25W ——
   也就是说，现在的负载已经拿到了最大可用功率的 96%，
   再优化负载电阻，最多还能多榨出 0.25W（4%）。
   【这个「值不值得调」的判断，才是等效源模型的用处】
【场景 A：这是射频功放的输出级，负载是天线】
   → 选 RL = 4Ω 匹配。
     理由：信号的功率是【全部目标】，效率再低也无所谓，
           反正总功率就那么大，多传 1mW 就是 1mW。
           （在射频里还要考虑「不匹配会反射、驻波比升高」，
             这是比效率更硬的理由。）

【场景 B：这是电池供电的传感器节点，负载是加热丝】
   → 绝对不能选 RL = 4Ω。
     理由：一半的电都烧在 Req 上了，电池续航直接砍半。
           这时候宁可让 RL 大得多（比如 36Ω），
           功率小一点，但效率 90%，
           同样的电池能多工作一倍时间。
           【而且要注意：Req = 4Ω 是【等效】出来的，
             它未必真的在发热 —— 原电路里烧掉的是 R1，
             但能量确实是从电池里出来的，钱一样要花。】

【场景 C：这是单片机的 ADC 输入，负载是采样电容】
   → 既不看功率，也不看效率，看的是【电压传得准不准】。
     要求 RL ≫ Req，让采样电容上得到的电压尽可能等于 Uoc。
     （这一条在第四节展开。）

【结论】
   同一个 Req = 4Ω，三种场合给出三种完全不同的「最优 RL」。
   【「最优」这个词，永远要先问「对什么最优」。】

例题 4：含受控源，求等效电阻

换两个新电路。这道题的重点不是数算得对不对，而是体会「受控源不能置零」这一条到底意味着什么。

【电路】端口 a、b 之间：

        a ────[ R1 = 4Ω ]────┬──── X
                             │
                          ┌──┴──┐
                          │     │
                       [ R2 ]  │ ▼     ← 受控电流源 CCCS
                       4Ω     │ 0.5·i1    （电流 = 0.5 × i1）
                          │   │      方向：从 X 向下流向 b
                          │   │
        b ────────────────┴───┘

   其中 i1 是【流过 R1、从 a 指向 X 的电流】。

【为什么不能用开路短路法】
   网络里没有任何独立源 → 端口开路时 UA = 0，Uoc = 0；
   端口短路时所有电流都是 0，Isc = 0。
   Req = 0 / 0，无意义。【只能加压求流】。

【加压求流】

   第 1 步：在 a、b 之间加电压 U（a 为正），
            设从 a 流入端口的电流为 I。

   第 2 步：KCL 在节点 a ——
            从 a 流入的电流 I 没有别的去处，只能全部流过 R1：

                    i1 = I                    ……(式 1)

   第 3 步：KCL 在节点 X（流入 = 流出）——

            流入：i1 = I
            流出：流过 R2 的电流 + 受控源的电流
                  = UX / 4 + 0.5·i1

                    I = UX/4 + 0.5 I
                    0.5 I = UX/4
                    UX = 2 I                  ……(式 2)

   第 4 步：KVL 沿 a → X → b 走一圈——

                    U = i1 · R1 + UX
                      = I × 4 + 2I
                      = 6 I

   第 5 步：相除

                    Req = U / I = 6 Ω

【交叉验证：如果没有那个受控源会是多少？】
   没有受控源时，R2 就是单纯的 4Ω 并联支路：
        Req = R1 + R2 = 4 + 4 = 8 Ω
   有了受控源（它注入 0.5I 的电流，相当于「帮」端口多喂了
   一部分电流给节点 X），等效电阻降到了 6Ω。
   【受控源可以增大也可以减小等效电阻，
     甚至可以让 Req 变成负数 —— 那就是「有源」电路的标志。】
【电路】端口 a（就是节点 A）、b（地）之间：

      ┌──[ R1 = 2Ω ]──┬──── a
      │               │
   [ Us = 12V ]    [ R2 = 2Ω ]
      │               │
      │            ┌──┴──┐
      │            │  ▼  │  ← 受控电流源 VCCS
      │            │ 0.25·UA
      │            └──┬──┘
      │               │
      └───────────────┴──── b（地）

   受控电流源的电流 = 0.25 × UA（单位 A，UA 单位 V），
   所以它是一个【压控电流源】，系数 0.25 的电导量纲（S）。

────────────────────────────────────────────────────────
方法一：开路短路法
────────────────────────────────────────────────────────

【第 1 步：求 Uoc】端口开路，求 UA。

   节点 A 的 KCL（流入 = 流出）：
        流入：从 Us 支路来 (12 − UA)/2
        流出：R2 支路 UA/2，受控源支路 0.25·UA

        (12 − UA)/2 = UA/2 + 0.25 UA
        6 − 0.5 UA  = 0.5 UA + 0.25 UA
        6 = 1.25 UA

        UA = 4.8 V
        Uoc = 4.8 V

【第 2 步：求 Isc】把端口 a 直接短接到地。

   短路后 UA = 0 —— 这是关键一步：
        ① 受控源的电流 = 0.25 × 0 = 0，【它自己消失了】
        ② R2 两端都是 0V，没有电流
        ③ 于是短路线上的电流，就是 Us 经 R1 灌下来的全部电流

        Isc = 12 / 2 = 6 A

【第 3 步：相除】
        Req = Uoc / Isc = 4.8 / 6 = 0.8 Ω

────────────────────────────────────────────────────────
方法二：加压求流法（用于验证）
────────────────────────────────────────────────────────

【第 1 步】把独立源 Us 置零 → 短路，R1 的上端变成接地。
           【受控源保留！】

【第 2 步】端口加电压 U（a 为正），设从 a 流入节点 A 的电流为 I。

【第 3 步】节点 A 的 KCL（流入 = 流出）：
        流入：从 R1 支路来 (0 − U)/2 = −0.5U
              从端口来 I
        流出：R2 支路 U/2；受控源支路 0.25U

        I − 0.5U = 0.5U + 0.25U
        I = 1.25 U

【第 4 步】
        Req = U / I = 1 / 1.25 = 0.8 Ω     ✅ 与方法一一致

────────────────────────────────────────────────────────
【这道题最大的教学价值】
   方法一里，端口一短路，受控源的控制量 UA 变成 0，
   受控源自动「下班」了 —— 短路电流一眼可见。
   这就是【开路短路法特别好用】的典型场合。

   方法二里，独立源置零而受控源必须保留，
   这是【最容易做错的一步】。
   如果你把受控源也一并去掉：
        Req 会算成 R1 ∥ R2 = 2 ∥ 2 = 1 Ω
   而正确答案是 0.8 Ω —— 错了 25%。
   【这个错误在考卷上非常常见，在工作中同样常见。】

在单片机上的样子

前面四道题都是纸上电路。这一节把它们全部换回你焊在板子上的东西——分压网络、IO 引脚、传感器、电源。你会发现每一个「莫名其妙」的现场，背后都是一个 Req。

分压网络 = 一个戴维宁源：ADC 采样误差从哪来

你在原理图上画的「传感器 → R1 → ADC 引脚 → R2 → GND」，在戴维宁眼里不是三个器件，而是一个电压源串一个电阻。

【你在原理图上画的】                【戴维宁等效后的真实图景】

  传感器                            Uoc = Vin·R2/(R1+R2)
   OUT ──[ R1 ]──┬──► PA0                 ──[ Req ]──┬──► 采样开关
                 │                          Req = R1∥R2│
               [ R2 ]                                    ├──[ R_ADC ]──┬──
                 │                                    [ C_ADC ]      │
                GND                                       │         ───
                                                        GND        采样电容

   ★ 关键：ADC 引脚在【采样瞬间】并不是高阻，
     它把一个约 8pF 的小电容（C_ADC）通过一个
     约 1kΩ 的开关电阻（R_ADC）接到引脚上，
     靠【你的源】给这个电容充电。
     充得够不够，取决于 时间常数 τ = (Req + R_ADC) × C_ADC
     和 你给ADC留的采样窗口长度。

【充电过程】电容电压按指数逼近 Uoc：

   u(t) = Uoc × (1 − e^(−t/τ))

   经过 1τ  →  充到 63.2%     误差 36.8%
   经过 3τ  →  充到 95.0%     误差 5.0%
   经过 5τ  →  充到 99.3%     误差 0.7%
   经过 9τ  →  充到 99.99%    误差约 0.012%

   【12 位 ADC 的 1 个 LSB 是 1/4096 ≈ 0.024%，
     要求误差小于半个 LSB = 0.012%，所以大约需要 9τ。】

现在把最常见的一个现场算清楚

你按上一篇的做法选了 R1 = 10kΩ、R2 = 15kΩ，把 0~5V 降到 0~3V 接进 PA0。这个分压网络的等效电阻是多少？

Req = R1 ∥ R2 = (10k × 15k) / (10k + 15k) = 150k/25k = 6 kΩ

对照上表：6kΩ 已经超过了 1.5 周期（0.4kΩ）和 7.5 周期（5.9kΩ）的允许值，必须把采样时间加到 13.5 周期以上。如果你在 CubeMX 里偷懒用了默认的 1.5 周期，算一下误差：

τ = (6000 + 1000) × 8pF = 56 ns；采样窗口 107 ns = 1.9τ；

充电到 1 − e−1.9 = 85.0%，读数会系统性偏低约 15.0%。

而把采样时间改成 13.5 周期（964ns = 17τ），误差 e−17 ≈ 4×10−8，完全可以忽略。同一块板子、同一段代码，只改一个配置项，误差从 15.0% 变成 0.——这就是「懂一点电路」和「不懂」的区别。

按 τ 估算时用的是「一阶近似」：认为采样开关是一个恒定电阻 RADC（手册给的最大值 1kΩ）串一个恒定电容 CADC（典型 8pF）。真实器件里这两个量都不是严格常数，所以这个估算用来「判断够不够」，不用来「算到小数点后三位」。

还有第二层误差，很多人完全没意识到：分压公式只在「信号源内阻为 0」时成立。而真实传感器的输出阻抗不是 0。把传感器的输出阻抗 Rs 一起算进去，分压网络真正的等效源是：

【带源阻抗的完整等效】

   理想化公式（中学版，只在 Rs = 0 时成立）：
        Uoc = Vin × R2 / (R1 + R2)

   真实公式（把 Rs 也算进来）：
        Uoc = Vin × R2 / (Rs + R1 + R2)
        Req = (Rs + R1) ∥ R2

────────────────────────────────────────────────────────
【代入数字：Rs = 1kΩ（一个普通运放输出级的量级）】
────────────────────────────────────────────────────────
   R1 = 10kΩ, R2 = 15kΩ

   你以为的：  Uoc = Vin × 15/25 = 0.600 Vin
   实际的：    Uoc = Vin × 15/(1+10+15) = Vin × 15/26 = 0.5769 Vin

   相对误差 = (0.600 − 0.5769) / 0.600 = 3.8 %

   【3.8% 是什么概念】12 位 ADC 的满量程是 4095 个码，
     3.8% 相当于读数整体偏了约 156 个码。
     你会以为是电阻精度问题（碳膜电阻误差 ±5%），
     换一堆精密电阻也没用 —— 因为病根在 Rs 上。

────────────────────────────────────────────────────────
【再代入一个高阻源：Rs = 10kΩ（光敏电阻、湿敏电阻常见）】
────────────────────────────────────────────────────────
   实际的：  Uoc = Vin × 15/(10+10+15) = Vin × 15/35 = 0.4286 Vin

   相对误差 = (0.600 − 0.4286) / 0.600 = 28.6 %

   【读数会比真实值低将近三成。】
     这时候无论怎么校准系数都是错的 ——
     因为 Rs 会随温度、湿度、批次变，
     它不是「一个可以提前量出来填进代码的常数」。

【正确的做法有两个】
   ① 把 R1、R2 的阻值提高到远大于 Rs 的量级（比如都取 1MΩ），
      但这样 Req 也跟着变大，又回到 ADC 采样时间的问题上；
   ② 在传感器和分压网络之间插一级【电压跟随器】，
      把 Rs 从 10kΩ 变成 1Ω 以下 —— 第四节第三小节细讲。

把上面这些结论落成代码，就是在初始化时把三个数算出来并做一次判断：

/* ============================================================================
 * 分压采样网络的「戴维宁等效」自检 + 电压换算
 *
 * 硬件：
 *   传感器 OUT ── R1 ──┬── PA0（ADC1_IN0）
 *                      │
 *                      R2
 *                      │
 *                     GND
 *
 * 核心思想：这个分压网络对外就是一个戴维宁源
 *      Uoc = Vin * R2 / (Rs + R1 + R2)
 *      Req = (Rs + R1) || R2
 *   Rs（传感器输出阻抗）不为 0 时，分压比会偏，必须算进去。
 * ============================================================================ */

#include "main.h"
#include <stdio.h>

extern ADC_HandleTypeDef hadc1;

/* ---------- 电阻实际值（单位 Ω）：用万用表量出来填，别填标称值 ---------- */
#define R1_OHM          10000.0f    /* 上分压电阻 */
#define R2_OHM          15000.0f    /* 下分压电阻 */

/* ---------- 传感器输出阻抗 ----------
 * 0.0f  = 理想源（运放跟随器输出、稳压电源）
 * 1000.0f = 普通运放输出级的量级
 * 10000.0f = 光敏/湿敏电阻分压输出的量级
 * ★ 拿不准就先填 0，观察读数是否随温度/湿度漂移，再回来改。 */
#define SOURCE_RS_OHM   0.0f

/* ---------- ADC 参数（来自 STM32F103 数据手册） ---------- */
#define ADC_VREF        3.300f      /* VREF+ 接 3.3V */
#define ADC_FULL_SCALE  4095.0f     /* 12 位 */
#define ADC_C_ADC_PF    8.0f        /* 采样电容典型值，pF */
#define ADC_R_ADC_OHM   1000.0f     /* 采样开关电阻最大值，Ω */

/* ---------- 本次配置的采样时间 ----------
 * 在 CubeMX 的 ADC → Parameter Settings → Sampling Time 里选。
 * 下面填的是「周期数」，用于估算采样窗口长度。 */
#define ADC_SAMPLING_CYCLES   13.5f
#define ADC_CLOCK_HZ          14000000.0f   /* F103 的 ADC 时钟上限 14MHz */

/* ============================================================================
 * 求分压网络的戴维宁等效参数
 * ============================================================================ */
static float thevenin_uoc(float vin)
{
  return vin * R2_OHM / (SOURCE_RS_OHM + R1_OHM + R2_OHM);
}

static float thevenin_req(void)
{
  float upper = SOURCE_RS_OHM + R1_OHM;   /* 与源串联的那一部分 */
  return (upper * R2_OHM) / (upper + R2_OHM);
}

/* ============================================================================
 * 开机自检：算一算这个网络的 Req 会不会拖垮采样精度
 * ============================================================================ */
static void check_sampling_margin(void)
{
  float req   = thevenin_req();
  float tau_s = (req + ADC_R_ADC_OHM) * (ADC_C_ADC_PF * 1e-12f);
  float t_win = ADC_SAMPLING_CYCLES / ADC_CLOCK_HZ;
  float ratio = t_win / tau_s;                 /* 相当于几个时间常数 */
  float err   = 100.0f * expf(-ratio);         /* 剩余误差（百分比） */

  /* 12 位 ADC 要半个 LSB 以内，即 0.012% → 约需 9 个 τ */
  printf("[等效源自检]\r\n");
  printf("  分压网络 Req = %.0f Ω\r\n", req);
  printf("  采样时间常数 τ = %.1f ns\r\n", tau_s * 1e9f);
  printf("  采样窗口   = %.0f ns (= %.1f τ)\r\n", t_win * 1e9f, ratio);
  printf("  预估采样误差 = %.3f %%\r\n", err);

  if (ratio < 9.0f)
  {
    printf("  ⚠ 采样窗口不足 9τ，读数会系统性偏低！\r\n");
    printf("     处置：把 Sampling Time 调大一档，");
    printf("或在传感器后加一级电压跟随器。\r\n");
  }
  else
  {
    printf("  ✅ 采样窗口充足。\r\n");
  }

  /* 源阻抗不匹配带来的分压比误差，单独提醒一次 */
  if (SOURCE_RS_OHM > 0.0f)
  {
    float ideal = R2_OHM / (R1_OHM + R2_OHM);
    float real  = R2_OHM / (SOURCE_RS_OHM + R1_OHM + R2_OHM);
    printf("  分压比误差 = %.2f %% （理想 %.4f，实际 %.4f）\r\n",
           100.0f * (ideal - real) / ideal, ideal, real);
  }
}

/* ============================================================================
 * 把引脚电压反推成传感器原始电压
 *   注意：这里用的是【含 Rs 的真实分压比】，
 *   而不是中学版的 R2/(R1+R2)。
 * ============================================================================ */
static float pin_to_source(float v_pin)
{
  /* Vin = v_pin * (Rs + R1 + R2) / R2 */
  return v_pin * (SOURCE_RS_OHM + R1_OHM + R2_OHM) / R2_OHM;
}

int main(void)
{
  uint32_t raw;
  float    v_pin;
  float    v_src;

  HAL_Init();
  SystemClock_Config();
  MX_GPIO_Init();
  MX_ADC1_Init();
  HAL_ADCEx_Calibration_Start(&hadc1);   /* 别漏：不做校准会有几十 LSB 的固定偏差 */

  check_sampling_margin();                /* ★ 开机先做一次等效源自检 */

  while (1)
  {
    HAL_ADC_Start(&hadc1);
    if (HAL_ADC_PollForConversion(&hadc1, 100) == HAL_OK)
    {
      raw   = HAL_ADC_GetValue(&hadc1);
      v_pin = (float)raw * ADC_VREF / ADC_FULL_SCALE;
      v_src = pin_to_source(v_pin);

      printf("引脚 %.3f V → 传感器 %.3f V (原始码 %lu)\r\n",
             v_pin, v_src, (unsigned long)raw);
    }
    HAL_ADC_Stop(&hadc1);
    HAL_Delay(500);
  }
}

/* ============================================================================
 * 【这段代码真正想教你的三件事】
 *
 * ① Req 不是一个「电路理论的抽象概念」，它是你代码里必须出现的一个数。
 *    它决定了采样时间该选多大，也决定了你的读数要不要修正。
 *
 * ② 分压比不是常数，它随源阻抗变化。
 *    把 Rs 写进宏定义、让它在代码里显式出现，
 *    比在注释里写一句「注意传感器阻抗」有用一百倍。
 *
 * ③ 「预估误差」这行 printf 的价值，在于让你在【板子还没焊错】的时候
 *    就知道误差有多少。等读数不对了再去反推，要花十倍时间。
 * ============================================================================ */

IO 口 = 理想源 + 输出阻抗：为什么「3.3V」带不动负载

现在回到开头那个现场：万用表量 3.3V，接上负载变 2.6V。答案就在 STM32F103 数据手册的输出特性里：

数据手册怎么说

STM32F103 数据手册的输出驱动电流特性表里写：在 3.3V 供电下，当引脚输出 8mA 电流时，VOH 最低不低于 VDD − 0.4V（约 2.9V），VOL 最高不超过 0.4V。

把这句话翻译成戴维宁语言：引脚内部有一个 MOS 管当开关，它导通时不是理想的 0Ω，而是有一个导通电阻。

ROL ≈ 0.4V / 8mA = 50Ω（这是按最坏情况估算的上限值；典型值比这个小，大约 25~40Ω，但做设计要按最坏情况算。）

【你以为的】                        【真实的】

   引脚 ──── 3.3V                       VDD = 3.3V（理想源）
              │                             │
              │                        ┌────┴────┐
              │                        │  R_OL   │  ≈ 50Ω
              │                        │ (PMOS)  │
              │                        └────┬────┘
              │                             │
           负载 RL                          ├────────► 引脚 PA5
              │                             │
             GND                         负载 RL
                                            │
                                           GND

   负载上的电压：  UL = 3.3 × RL / (R_OL + RL)

   ★ 这个式子和【分压公式长得一模一样】——
     因为 IO 口内部就是一个分压网络，
     只不过「上电阻」是它自己的输出阻抗。

【推论一：负载越重（RL 越小），电压掉得越多】

   RL = 10 kΩ  →  UL = 3.3 × 10000/10050 = 3.284 V   （掉了 0.5%）
   RL = 1 kΩ   →  UL = 3.3 × 1000/1050   = 3.143 V   （掉了 4.8%）
   RL = 330 Ω  →  UL = 3.3 × 330/380     = 2.866 V   （掉了 13%）
   RL = 100 Ω  →  UL = 3.3 × 100/150     = 2.200 V   （掉了 33%）
   RL = 50 Ω   →  UL = 3.3 × 50/100      = 1.650 V   （只剩一半）

【推论二：判断「能不能驱动」的方法，就是比较 RL 和 R_OL】

   判据：想让负载上的电压不低于源电压的 95%，
        需要  RL / (RL + 50) ≥ 0.95，即 RL ≥ 950 Ω。

   所以：
     ✅ 另一个 CMOS 输入脚（输入阻抗 10^6 Ω 以上）→ 随便带
     ✅ MOS 管栅极（直流阻抗近乎无穷）→ 随便带
     ✅ LED 串一个几百欧的限流电阻（回路总阻抗约 500Ω）→ 能用
     ❌ 5V 继电器线圈（直流电阻约 70Ω）→ 电压掉到 1.9V，根本不吸合
     ❌ 直接给模块供电（模块电流几十 mA）→ 既掉压又超 20mA 上限

算例一：IO 直驱继电器线圈（最常见的错误）
════════════════════════════════════════════════════════════
   5V 小型继电器线圈直流电阻约 70Ω。

【按理想源算（错）】
        I = 3.3V / 70Ω = 47 mA
        → 结论：「超了 20mA 上限，但也许能吸合？」   ❌ 两个判断都错

【按戴维宁模型算（对）】
        I = 3.3V / (50 + 70) = 3.3 / 120 = 27.5 mA
        线圈上的电压 = 27.5mA × 70Ω = 1.93 V
        → 结论：
           ① 电流 27.5mA 仍然超 20mA 的单脚上限；
           ② 线圈只拿到 1.93V，远远达不到 5V 继电器的
              吸合电压（通常需要额定电压的 70% 以上，即 3.5V）。
           【根本吸不动，而且引脚在超载工作。】

算例二：算 LED 限流电阻时忘了减去 R_OL
════════════════════════════════════════════════════════════
   3.3V 供电，红色 LED 正向压降 1.8V，想让它流过约 3mA。

【按理想源算（错）】
        R = (3.3 − 1.8) / 0.003 = 500 Ω  → 取标称 470Ω
        预估电流 = 1.5 / 470 = 3.19 mA

【把 R_OL 算进去（对）】
        回路总电阻 = R_OL + R + r_LED
                   ≈ 50 + 470 + 20（LED 动态电阻）= 540 Ω
        实际电流 = 1.5 / 540 = 2.78 mA

   偏差 = (3.19 − 2.78) / 3.19 = 13 %

   【13% 听起来不多，但注意两件事：】
     ① 这是【系统性的】偏差，不是随机噪声 ——
        所有板子都会偏同一个方向、同一个幅度；
     ② 当你想让 LED 工作在接近上限的电流时
        （比如红外发射管要 15mA），这个偏差就直接
        决定了它是「够亮」还是「烧了」。

【一句话结论】
   以后算限流电阻，把 50Ω 这个数写进公式里。
   它是这条支路上【唯一一个不在你原理图上的电阻】。

高输出阻抗的传感器，为什么后级要加电压跟随器

这是本篇最需要你「想明白」的一节，因为它直接关系到论坛上那句被说烂了的「这里要加个电压跟随器做阻抗匹配」——这句话里有两个容易误解的地方。

先看问题本身。假设你有一个输出阻抗 Rs = 100kΩ 的传感器（pH 电极、光敏电阻分压、压电薄膜、高阻电桥都属于这一类），想直接接到 PA0 上测电压。

【直连】                                 【加电压跟随器】

 传感器                       传感器
 (Rs=100kΩ)                  (Rs=100kΩ)
    │                            │
    ├────────► PA0               ├────────► ┌─────────┐
    │                          [ C_ADC ]    │  运放    │
   GND                            │         │ 跟随器   │
                                 GND        └────┬────┘
                                                 ├──────► PA0
                                                 │
                                              [ C_ADC ]
                                                 │
                                                GND

────────────────────────────────────────────────────────
【问题一：电压被分掉了】
────────────────────────────────────────────────────────
   ADC 采样瞬间，C_ADC 通过 R_ADC 接到引脚上。
   从传感器看过去，这相当于一个「负载」——
   哪怕它只是 8pF 的电容，采样瞬间也需要电流。

   用戴维宁看：采样窗口内，引脚上出现的电压是

        u(t) = Uoc_source × (1 − e^(−t/τ))
        τ = (Rs + R_ADC) × C_ADC = (100k + 1k) × 8pF = 808 ns

   要达到 12 位精度（9τ）需要 7.3 µs 的采样窗口。
   F103 最大采样时间 239.5 周期 @14MHz = 17.1µs，
   理论上【够】—— 但这只是第一关。

【问题二：前一个通道的电荷会污染这一个通道】
────────────────────────────────────────────────────────
   多通道扫描时，C_ADC 上还留着上一个通道的电荷。
   新通道接上来，要靠【它自己的源阻抗】把电容上的
   电压冲刷到自己的值。
   Rs 越大，冲刷越慢 —— 前一个通道的电压会「漏」进来。
   这是高阻多通道采样里最典型的一种串扰。

【问题三：高阻节点是噪声和漏电流的放大器】
────────────────────────────────────────────────────────
   100kΩ 的节点上，只要 10nA 的漏电流，
   就会产生 10nA × 100kΩ = 1 mV 的误差。
   而 PCB 表面的助焊剂残留、潮湿、手指印，
   轻轻松松就能产生远大于 10nA 的漏电流。
   【这就是为什么高阻电路要用保护环、要洗板、要涂三防漆。】

【加了一级电压跟随器之后】
   · 跟随器输入阻抗极高（CMOS 输入运放可以到 10^12 Ω 量级），
     从传感器几乎不取电流 → Rs 上的压降约等于 0 → 电压不被分掉；
   · 跟随器输出阻抗极低（闭环输出阻抗远小于 1Ω），
     相当于把「源阻抗 100kΩ」这个身份，翻译成了「源阻抗 1Ω」；
   · 于是 ADC 那边的 τ 变成 (1 + 1000) × 8pF ≈ 8 ns，
     一个 1.5 周期的采样窗口（107ns = 13τ）就绰绰有余。
现在说清楚那个被说烂的词：「阻抗匹配」

论坛上有人说「加跟随器是为了阻抗匹配」，这句话不算错，但极容易让人理解反。因为「阻抗匹配」在电路理论里的标准含义是最大功率传输：让负载阻抗等于源阻抗。而电压跟随器做的事情，恰恰是反过来的：

它追求的是负载阻抗远大于源阻抗（RL ≫ Req），让后级几乎不从源取电流。

用例题 3 那张表对一下就清楚了：

  • 如果按「最大功率传输」去匹配（RL = Req），端口电压会掉一半（例题 3 中 10V 变成 5V）。对你的 ADC 来说是灾难——你要测的是传感器的电压，结果接到 ADC 上只剩一半，而且这一半还随负载变化。
  • 信号链要的是「电压不失真地传过去」，对应表格里 RL ≫ Req 那一行，效率根本不在讨论范围内（因为几乎不取电流，也就不存在功率损耗的问题）。

所以正确的说法是：加电压跟随器是为了「阻抗变换」——把高输出阻抗的源，变成低输出阻抗的源，让后级能轻松驱动。这个操作的本质是缓冲（buffer），不是匹配（match）。中文里这两个词经常被混着用，你在别人的帖子里看到「匹配」时，先判断他说的是哪一种。

选电压跟随器的三个坑（都是真实踩过的）

① 一定要选「轨到轨输出」（rail-to-rail output）的运放。这是最致命的坑：LM358 在 3.3V 单电源供电时，输出最高只能到约 1.8V（它会比正电源低 1.5V 左右），根本够不到 3.3V 的 ADC 量程上限。你测 3V 的输入，输出卡在 1.8V 不动。推荐 MCP6001 / MCP6002（轨到轨输入输出、单电源 1.8~6V、增益带宽积 1MHz、输入偏置电流只有 1pA 量级），这类器件才是给 3.3V 系统用的。

② 输入偏置电流要小。跟随器的输入偏置电流会流过传感器的 Rs，产生误差。Rs = 100kΩ 时，如果运放的输入偏置电流是 100nA（普通双极型运放的量级），误差就是 100nA × 100kΩ = 10mV——比 12 位 ADC 的一个 LSB（0.8mV）大十倍以上。高阻传感器必须选 CMOS 或 JFET 输入级的运放（偏置电流 pA 级）。

③ 输出端要串一个小电阻再加滤波电容。跟随器直接驱动电容性负载容易振荡（运放的经典毛病）。做法是输出串 100Ω 电阻，再接 100nF 到地做抗混叠滤波；这个 100Ω 就是 ADC 看到的新 Req，远小于 RAIN(max) 的限制。

常见误解与坑

下面八条，每一条都见过「当场翻车」的实例。前四条是纯理论上的错，后四条是理论没错、但被用错了地方。

坑 1：用叠加定理去算功率

错误认知：「既然电流可以叠加，那功率当然也可以——把每个电源单独作用时的功率加起来就行了。」

为什么错：功率是电流的二次函数（P = I²R），而叠加定理只对线性关系成立。展开 (I1+I2)²R 会多出一个交叉项 2I1I2R。第三节的实际数字是：分开算相加得 4.08W，正确答案 6.00W，差了 32%。

正确做法：永远遵循「先叠加电流/电压，再算一次功率」的顺序。如果你需要分别知道「每个电源贡献了多少功率」，那这个问题在物理上本身就是不成立的——功率不是按源分配的。

坑 2：求 Req 时把受控源也一起置零

错误认知：「置零就是让源不起作用，独立源和受控源都是源，一视同仁全部短掉、断掉。」

为什么错：独立源是激励，置零意味着「这个激励取 0」，物理意义明确。受控源不是激励，它是由电路中某处的电压/电流决定的约束。把它置零，等于强行规定「那个控制量恒为 0」，电路结构被改了。例题 4-乙里，如果误把受控源也去掉，Req 会算成 1Ω，而正确答案是 0.8Ω，错了 25%。

正确做法：牢记八个字——独立源置零，受控源保留。保留的受控源会让 Req 变大、变小甚至变成负数，这正是「有源电路」与「无源电路」的分界线。

坑 3：以为戴维宁等效电路和原电路「完全一样」

错误认知：「等效就是相等，所以可以用等效电路算原电路里任何一个元件的功率、算整个电路的效率。」

为什么错：戴维宁定理保证的只有对外端口的伏安特性一致（u = Uoc − Req·i 这一条直线）。原电路内部可能有五个电阻在发热、有一个电源在反向吸收功率；等效电路内部只有一个 Req。例题 1 里，原电路真实效率 42.9%，等效电路算出来 60%——两个数字都对，只是回答的问题不同。

正确做法：算负载上的量（电流、电压、功率）→ 用等效电路；算内部任何元件的功率、电源的实际负担、整体效率 → 必须回原电路用节点法或回路法。

坑 4：以为「最大功率传输点」就是「最佳工作点」

错误认知：「既然是最大功率，那肯定是最优的，所有场合都应该让 RL = Req。」

为什么错：这个点上效率只有 50%，一半的功率烧在内阻上。电池供电的设备如果把负载匹配到内阻上，续航直接砍半。例题 3 的表格说明了这件事：从 RL = 4Ω 换到 36Ω，功率掉到 36%，但效率从 50% 升到 90%。

正确做法：先问「我要的是功率还是效率」。射频、天线、功放输出要功率 → 匹配；电力、电池供电要效率 → 让 RL ≫ Req；单片机信号链要电压准确度 → 也是 RL ≫ Req。三种需求，两种相反的答案。

坑 5：无条件使用「开路短路法」求 Req

错误认知：「Req = Uoc/Isc 这个公式最方便，什么电路都能套。」

为什么错：它有两个前提。① 网络里必须有独立源，否则 Uoc 和 Isc 都是 0，得到 0/0 毫无意义（例题 4-甲就是这种情况，只能用加压求流法）。② 短路电流必须是有限值，如果端口置零后 a、b 之间是一条纯导线（Req = 0），短路电流理论上无穷大，公式同样失效。

正确做法：先看一眼网络里有没有独立源、端口置零后是不是直通，再决定用哪个方法。拿不准就用加压求流法——它没有前提，永远有效，只是多写几行方程。

坑 6：把「加电压跟随器」理解成「做最大功率匹配」

错误认知：「传感器内阻 100kΩ，那我把 ADC 前面的电阻也配成 100kΩ，就匹配上了。」

为什么错：匹配之后端口电压会掉一半（例题 3 里 10V 的源接 4Ω 负载只剩 5V），而且这一半还随负载变化。你测的是电压，结果接上 ADC 就少一半——这是把射频的思路搬到了信号链上。跟随器做的事情恰恰相反：它让后级几乎不取电流，是 RL ≫ Req 的极端情况。

正确做法：把「匹配（match）」和「缓冲/阻抗变换（buffer）」分开说。信号链需要的是缓冲：输入阻抗高、输出阻抗低，把高阻源翻译成低阻源。「阻抗匹配」这个词在信号链语境下，实际指的是「让后级输入阻抗远大于前级输出阻抗」。

坑 7：认为「分压比是个常数，程序里乘一下就能换算回来」

错误认知：「R1 = 10k、R2 = 15k，分压比就是 0.6，代码里除以 0.6 就得到真实电压了，永远正确。」

为什么错：分压比 R2/(R1+R2) 只在源阻抗为 0 时成立。真实公式是 R2/(Rs+R1+R2)。源阻抗 1kΩ 时误差 3.8%；源阻抗 10kΩ 时误差 28.6%。而且 Rs 往往随温度、湿度、激励电流变化，它不是一个能提前量出来写死进代码的常数。

正确做法：① 把 Rs 显式写进代码的宏定义和换算公式（第四节那段代码就是这么做的）；② 源阻抗超过 10kΩ 时，先加一级跟随器，把 Rs 从公式里彻底消掉，再谈校准。

坑 8：以为「ADC 输入阻抗无穷大，接上去对被测电路没有影响」

错误认知：「ADC 是高阻输入，接在电路上相当于没接，测的就是原来的电压。」

为什么错：ADC 的「高阻」是采样保持期间的性质。在采样瞬间，它把一个 8pF 量级的电容通过约 1kΩ 的开关接到引脚上，这时它对外的等效阻抗并不高——它要充电，而电荷只能从你的源里来。源阻抗越大，充得越慢，读数偏低得越多；多通道扫描时，前一个通道残留在电容上的电荷还会污染当前通道。

正确做法：把 ADC 输入当成「一个需要被驱动的容性负载」，用 τ = (Req + RADC)·CADC 估算充电时间，保证采样窗口至少 9τ。同时对照数据手册的 RAIN(max) 一行，确认自己的源阻抗在允许范围内——这两道检查都过了，才谈得上「高阻输入」。

八条坑看下来，你会发现它们的共同点

前四条是「把定理的作用范围搞错了」——把只对电流电压成立的用到了功率上、把只对外部成立的用到了内部、把只对某个应用成立的「最优」当成了普遍的「最优」。

后四条是「把理想模型当成了真实器件」——以为分压比恒定、以为 ADC 输入不取电流、以为跟随器就是匹配。

这两类错误的共同解药是同一句话：每用一次公式，都问一句「这个公式成立的前提是什么，我现在的电路满足吗」。

小结与自检

要点清单

  • 叠加定理：多个独立源时，一次只留一个（电压源短路、电流源开路、受控源保留），分别求响应，再按参考方向取代数和。适用于线性电路的电流和电压，绝不能用于功率（P = I²R 是二次函数，缺一个交叉项）。
  • 替代定理：已知某支路的电压 uk 或电流 ik 时，可以用等值的理想电压源/电流源替换它，电路其余部分不变。前提是替代后有唯一解，且网络内部没有受这条支路控制的受控源。它是戴维宁定理的证明基础。
  • 戴维宁定理：任何线性含源二端网络对外等效为 Uoc 串联 Req。四步流程：① 摘负载、标端子；② 求开路电压 Uoc；③ 求等效电阻 Req；④ 接回负载用串联公式求解；⑤ 回原电路验算。
  • 等效的含义：只保证端口伏安特性 u = Uoc − Req·i 这一条直线一致。对外等效，对内不等效——内部功率分布不能用等效电路算。
  • 诺顿定理：同一个网络也可以写成 Isc 并联 Req。Uoc = Isc · Req，两边 Req 是同一个值。电压驱动型负载看戴维宁，电流驱动型负载看诺顿。
  • 含受控源求 Req：受控源不能置零。两个方法——加压求流法（外加 U，求 I，Req = U/I，永远有效）和开路短路法（Req = Uoc/Isc，要求网络里有独立源且 Isc 有限）。
  • 最大功率传输：RL = Req 时负载获得最大功率 Pmax = Uoc²/(4Req)，此时效率只有 50%。功率最大点与效率最高点方向相反：射频要功率选匹配，电力要效率选 RL ≫ Req，信号链要电压准确度也选 RL ≫ Req。
  • 在单片机上的四个具体化身：分压网络 = 一个 Req = R1∥R2 的戴维宁源（决定 ADC 采样时间和分压比误差）；IO 口 = 理想源 + 约 50Ω 输出阻抗（决定能不能驱动）；高阻传感器 = 需要一级跟随器做阻抗变换（不是功率匹配）；电源 = Us + Rs（决定带载跌落，ΔU = I × Rs）。

自检题

  1. 一个电路里有两个电压源。你用叠加定理分别求出某电阻上的电流是 30mA 和 40mA（方向相同）。这个电阻（100Ω）消耗的功率是多少？如果有人答「0.09W + 0.16W = 0.25W」，他错在哪里，正确值是多少？
  2. 用戴维宁定理求某支路电流时，第 ③ 步「求 Req」把网络里所有源都置零了。为什么独立源可以置零，而受控源不行？如果电路里只有一个受控源、没有任何独立源，应该用什么方法求 Req？
  3. 某网络的开路电压是 6V，短路电流是 3mA。它的戴维宁等效电路和诺顿等效电路分别长什么样（参数写出来）？如果把一个 2kΩ 的负载接上去，负载上的电流和电压是多少？此时效率是多少？
  4. STM32 的一个推挽输出引脚（内部等效为 3.3V 理想源串 50Ω）直接接一个直流电阻 70Ω 的继电器线圈。请分别用「理想源模型」和「戴维宁模型」算出线圈电流，说明哪个才是对的，以及为什么两个结果都不能让继电器吸合。
  5. 你把 0~5V 的传感器经 R1 = 10kΩ、R2 = 15kΩ 分压接到 PA0，CubeMX 里采样时间选了 1.5 周期，ADC 时钟 14MHz。请估算采样误差大概是多少，并给出两种解决办法。
  6. 某传感器的输出阻抗是 200kΩ，你要用 ADC 测它的电压。有人建议「在传感器和 ADC 之间串一个 200kΩ 的电阻做阻抗匹配」。这个建议对不对？为什么？正确做法是什么？
  7. 一块板子用 USB 5V 供电，USB 线和接口的等效内阻是 1.2Ω，板上有 LDO 输出 3.3V（压差约 1.2V）。平时电流 80mA，WiFi 发射瞬间 700mA。请算出发射瞬间 LDO 的输入电压和输出电压，解释「一联网就重启」的原因，并给出三种解决办法。
  8. 为什么说「戴维宁等效电路和原电路对外等效，但对内不等效」？请用一句具体的话说明：哪些量可以用等效电路算，哪些量必须回原电路算。
自检题答案
  1. 他错在把功率也叠加了。正确做法是先叠加电流：I = 30 + 40 = 70mA，再算一次功率：P = 0.07² × 100 = 0.49 W。分开算的 0.03²×100 + 0.04²×100 = 0.09 + 0.16 = 0.25W 少掉了交叉项 2×0.03×0.04×100 = 0.24W。0.25 + 0.24 = 0.49W，正好对上。
  2. 因为独立源是激励，置零表示「这个激励取 0」，物理上就是把它短掉/断掉，电路结构不变。受控源不是激励，它是由电路中某处的电压或电流决定的约束关系；把它置零等于强行规定控制量恒为 0，电路结构被改变了，算出来的就不是原来的等效电阻。如果网络里只有受控源、没有独立源，Uoc = 0 且 Isc = 0，开路短路法得到 0/0，只能用加压求流法（外加电压 U，求流入电流 I，Req = U/I）。
  3. Req = Uoc/Isc = 6V / 0.003A = 2000Ω = 2kΩ。戴维宁等效：6V 电压源串联 2kΩ。诺顿等效：3mA 电流源并联 2kΩ。接 2kΩ 负载：I = 6/(2000+2000) = 1.5 mA，UL = 1.5mA × 2kΩ = 3V。注意负载恰好等于 Req，所以这是最大功率点，效率 50%，PL = 1.5mA × 3V = 4.5mW = Uoc²/(4Req) = 36/8000 = 4.5mW ✅。如果不想只要 50% 的效率，就应该把负载取大（比如 18kΩ，效率 90%，功率降到 1.6mW 左右）。
  4. 理想源模型：I = 3.3/70 = 47mA，线圈电压 3.3V。戴维宁模型：I = 3.3/(50+70) = 27.5mA，线圈电压 27.5mA × 70Ω = 1.93V。戴维宁模型才是对的，因为 IO 引脚内部的 MOS 管有约 50Ω 的导通电阻，它和外接的线圈构成分压。两个结果都吸合不了：理想模型算出的 47mA 虽然「电压够」但电流超 20mA 上限近 2.4 倍（而且那个 3.3V 根本不存在）；真实情况是线圈只拿到 1.93V，远低于 5V 继电器需要的吸合电压（约 3.5V），同时 27.5mA 仍然超标。正确做法是加一级三极管或 MOS 管驱动，让 IO 只提供基极/栅极的微小电流。
  5. Req = 10k ∥ 15k = 6kΩ，τ = (6000+1000) × 8pF = 56ns，采样窗口 1.5/14MHz = 107ns = 1.9τ，充电到 1 − e−1.9 ≈ 85.0%，误差约 15.0%（读数系统性偏低）。两种办法：① 把 CubeMX 里的 Sampling Time 从 1.5 周期加到 13.5 周期以上（964ns ≈ 17τ，误差可忽略）；② 在传感器和分压网络之间加一级电压跟随器，把源阻抗降到 1Ω 量级，同时还能允许使用更短的采样时间、提高扫描速率。
  6. 不对，而且是把概念用反了。串 200kΩ 属于「让负载阻抗接近源阻抗」的思路，那是最大功率传输（射频）的做法。对 ADC 来说，串上去的 200kΩ 会和 ADC 采样时的等效阻抗形成分压，让读数严重偏低；而且 τ = (200k+200k+1k) × 8pF ≈ 3.2µs，需要的采样窗口比最大档位还长，多通道扫描时还会产生严重的通道串扰。正确做法是加一级电压跟随器（选轨到轨输出、CMOS 输入、偏置电流 pA 级的运放，如 MCP6001），输入侧几乎不取电流，输出侧阻抗降到 1Ω 以下，把「高阻源」翻译成「低阻源」。串联电阻可以作为跟随器输出端的隔离电阻（约 100Ω），但那是为了驱动容性负载和做抗混叠滤波，不是为了匹配。
  7. 发射瞬间电流 700mA：跌落 ΔU = 0.7A × 1.2Ω = 0.84V，LDO 输入 = 5.0 − 0.84 = 4.16V。LDO 需要 3.3 + 1.2 = 4.5V 才能稳住，4.16V < 4.5V，所以 LDO 退出稳压区，输出约 4.16 − 1.2 = 2.96V。3.3V 轨掉到 3V 以下，WiFi 模块欠压复位，同时 ADC 基准、射频锁相环都受影响 → 「一联网就重启」。而平时 80mA 时跌落只有 0.096V，输入 4.9V，一切正常，所以空载量电压查不出来。三种办法：① 减小 Rs——换粗而短的 USB 线，把 1.2Ω 降到 0.2Ω，跌落从 840mV 变成 140mV；② 减小 ΔI——在 WiFi 模块电源脚旁并 100µF 以上的电容，让瞬态电流由电容就近提供；③ 切断共用的 Rs——给 WiFi 模块单独一路 LDO 供电，两块电路只共地不共电源。
  8. 因为戴维宁定理证明的只是「端口上的电压电流关系 u = Uoc − Req·i 这条直线相同」，它没有、也不可能保证两个电路内部每一个元件的电压电流都相同。原电路内部可能有好几个电阻在发热、有电源在被反向充电，而等效电路内部只有一个 Req。可以用等效电路算的：外部负载上的电流、电压、功率，端口电压、端口电流。必须回原电路算的：原电路内部任一电阻的功率、每个电源实际发出或吸收的功率、整个电路的真实效率。

动手练习

  1. 把你的板子上的分压网络，完整算一遍戴维宁等效。找出原理图上任何一个分压采样网络，写下 R1、R2 的实际值（用万用表量，不要用标称值），算出 Uoc 和 Req，然后对照 STM32F103 数据手册的 RAIN(max) 表，检查你现在用的采样时间够不够。这一条做完，你对「ADC 精度」的理解会完全不一样。
  2. 做一个「负载效应」实验。取一个 10kΩ 电位器接成可变负载，串联一个 10kΩ 电阻接到 3.3V 上。用电位器模拟「负载电阻从 10kΩ 连续变化到 0Ω」的过程，每一步量一次输出端的电压，画出 UL 随 RL 变化的曲线。你会亲眼看到「负载越重，电压越低」这条规律——这就是戴维宁模型最直观的验证，也是所有「带不动」问题的根源。
  3. 用万用表实测一次「IO 输出阻抗」。把 PA5 配置成推挽输出高电平，先空载量电压，再分别接 10kΩ、1kΩ、100Ω 电阻到地，每次量电阻上的电压。用这些数据反推出 ROL（提示：ROL = RL × (3.3 − UL) / UL），看看是不是落在 25~50Ω 这个区间里。亲手量出来的那个数字，比任何教科书上的说法都记得牢。
  4. 给高阻传感器搭一级电压跟随器。拿任何一颗轨到轨运放（MCP6001/MCP6002/LM358 可以先试，但你会发现 LM358 输出上不去），接成单位增益缓冲器，输入端串一个 100kΩ 电阻模拟高阻传感器。用 ADC 分别测量「直接接」和「经跟随器接」两种情况下同一个输入的读数，比较误差。注意跟随器输出要串 100Ω 电阻再加 100nF 到地。
  5. 做一次「电源内阻」的量化测试。把你的板子分别用以下几种方式供电：电脑 USB 口 + 原装线、充电宝 + 劣质充电线、DC 电源适配器、外部稳压源。在每一种情况下，用万用表测 STM32 的 3.3V 引脚电压，然后让板子跑一个满负载的程序（比如全速刷 OLED + 串口满速发送），再测一次。把「空载/满载」两组数字记下来，算出每种电源的等效内阻（Rs ≈ ΔU / ΔI，电流用电流表量）。以后遇到供电问题，你会知道该换哪一根线。
