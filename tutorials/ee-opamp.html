集成运放与信号调理

你在上一篇里用三极管搭过放大器：要算静态工作点、要挑 β、要防温漂，折腾半天增益只有几十倍，输入电阻还低得可怜。而集成运放把这一整套东西封进了一个 8 脚的塑料壳里——开环增益十万倍、输入电阻上兆欧、输出电阻几十欧。听起来完美，但你偏偏不能直接用它放大：十万倍的增益意味着输入端只要差 30µV，输出就冲到电源轨上去了，它一睁眼就饱和。所以这一篇真正要讲的，是怎么用两条几乎不用算的规则（虚短、虚断）把这只「力大无穷但完全不听话」的器件驯服成你想要的任何形状：放大、求和、做差、缓冲、积分。然后再讲另一半——手册上那几行小字（Vos、Ib、GBW、SR、共模范围）是怎么在你把 0~50mV 的分流电阻电压送进 STM32 的 ADC 时，一点一点吃掉你精度的。

为什么需要它

先看三个真实的故障现场。它们看起来毫不相干，但根子都在同一件事上：你搭了一个运放电路，却没搞清它内部的规则和手册里的参数。

现场 A：明明没有电流，串口却报 0.42A

你用一个 10mΩ 的分流电阻采电机电流，满量程 5A 对应 50mV，再用一颗运放放大 60 倍送到 STM32 的 ADC，目标是 0~3.0V。上电、电机不转，串口打印出来的电流却是 0.42A。

你没接错线，也没写错代码——这是输入失调电压 Vos 干的。你用的运放手册上写着「Vos 最大 7mV」，而你的电路把输入端的任何电压都放大 60 倍：7mV × 60 = 420mV，折算回电流正好是 0.7A 量级。零点误差不是「一点点误差」，它直接把 5A 量程的 14% 送给了你。

现场 B：电机一转，ADC 读数就乱跳

你照着网上教程，用四颗 10kΩ 电阻加一颗运放搭了「差分放大器」测电机电流。奇怪的是：电机不转时读数很稳，电机一 PWM 调速，ADC 就开始满量程乱跳。

原因是两个参数你都没顾上：一是共模输入范围——高边采样的输入端上压着 12V 的电机电源，而通用的 5V 运放输入绝对最大只有 5.3V，输入端已经在硬扛一个它不该看到的电压；二是共模抑制比 CMRR——四颗 1% 电阻配出来的差分放大器，CMRR 大概只有 36dB，12V 的共模摆动会漏成上百毫伏的「假差分信号」，而你的真实信号满量程才 500mV。

现场 C：万用表量着有电压，ADC 读出来几乎是 0

你把一个 pH 电极（或者一只光电二极管）直接接到 STM32 的 ADC 引脚上，读数一直在 0 附近打转。你拿万用表一量，明明有 400 多毫伏。

这里有两层原因。第一层：STM32 的 ADC 采样时要把内部 8pF 的采样电容充到被测电压，而 pH 电极的输出阻抗高达 100MΩ，时间常数 100MΩ × 8pF = 0.8ms，ADC 只给它十几微秒——电容只能充到 2% 左右。第二层：你的万用表也在骗你，它的输入阻抗 10MΩ 同样在加载这个高阻源。这类信号必须先过一级电压跟随器，把源阻抗从 100MΩ 降到 1Ω 以下。

三个现场指向同一张图。单片机系统里，ADC 前面那一段几乎总是运放，它负责把物理世界五花八门的信号，翻译成 STM32 唯一认得的那种形式：0~3.3V、低阻抗、有明确零点的电压。

  • 两条规则——虚短和虚断。它们能让你在三十秒内推出反相、同相、跟随器、加法器、差分、积分这六个电路的公式，不用背，也不会记混。这是这一篇的地基。
  • 一套误差账——Vos、Ib 会变成多大的输出误差；GBW 和 SR 决定了你能放大到多快；共模范围决定这个电路能不能用在这个场合。第 3 节的四道例题就是这笔账。
  • 几个真实场景的完整做法——4~20mA 电流环进 ADC、电机电流采样、高阻传感器缓冲、单电源偏置，都在第 4 节。
先纠正一个最常见的印象

很多人以为「运放是用来放大的」。在你做的单片机项目里其实不是——放大只是它的功能之一，而且往往不是最重要的那个。你真正最常需要它做的是三件别的：

  • 阻抗变换（缓冲）：把高阻传感器「翻译」成低阻抗输出，让 ADC 能采得动。这就是电压跟随器，它一点增益都没有。
  • 电平搬移（减法 / 加偏置）：把 4~20mA 经 250Ω 得到的 1~5V 减掉 1V 基准，变成 0~4V；或者把双极性小信号抬到 VCC/2 附近，好让单电源 ADC 能看见它。
  • 差分取差（抑制共模）：只放大分流电阻两端那几十毫伏的「差」，同时无视它上面压着的 12V「共」。这几乎是你做电流采样的唯一办法。

记住这三件事，你在看别人的原理图时就会开始「读得懂」：看到运放先问一句——它在这里是做放大，还是做缓冲、搬移、取差？答案往往决定了那几个电阻为什么是那些值。

核心概念

这一节有八个部分。前两个是地基（运放是什么、虚短虚断怎么来），中间四个是「用两条规则推出四种电路」，最后两个是「真实的运放哪里不理想」和「只有单电源时怎么办」。加起来不到八页纸，但它能覆盖你做的单片机项目里九成以上的运放电路。

2.1　运放到底是什么：一只增益大得没法直接用的差分放大器

课本上的定义一句话：运算放大器是一个高开环增益、高输入电阻、低输出电阻的差分放大器。这句话里每个词都是有用的，我拆开讲：

  • 差分放大器——它只「看」两个输入端之间的差，即 Vid = V+ − V−。两个输入端同时上下摆动的部分（共模）理论上被无视。这是它能测分流电阻、能抗电机干扰的根本原因。
  • 高开环增益 Aol——「开环」指不接任何反馈、直接从输入量到输出。通用运放的 Aol 在直流下有 105（100dB）以上，好的能到 107。这是个天文数字，也是所有麻烦的来源。
  • 高输入电阻 Rid——双极型输入级的运放约 106~107Ω，CMOS / JFET 输入级可以到 1012Ω 以上。这是它能做缓冲器、能接 pH 电极的原因。
  • 低输出电阻 Ro——典型几十欧姆，加上负反馈后在低频可以低到毫欧级。这是它能驱动 ADC 采样电容的原因。

「负反馈」到底做了什么：一句话讲透

把输出的一部分反相送回反相输入端，电路就变成一个自动平衡的伺服系统：只要输出偏高一点点，送回来的电压就偏高，反相端电压上升，输出被拉低——它自己会找到那个「让两个输入端几乎相等」的工作点。

这个自动平衡的结果非常漂亮：闭环增益只由外部电阻决定，跟运放自己的 Aol 几乎没关系。数学上：

Acl = Aol / (1 + Aolβ)　，其中 β = 反馈系数（反馈回反相端的那部分比例）

当 Aolβ ≫ 1 时，Acl ≈ 1/β，即纯粹由电阻分压比决定。举个数：Aol = 105、β = 1/61（就是 60 倍放大器的反馈系数），Aolβ = 1639，Acl = 105/1640 = 60.98，理想值 61，误差只有 0.016%。

但注意 Aol 是随频率下降的（见 2.7 节的 GBW），所以这个「误差极小」只在低频成立。这也就是为什么高频时运放电路的增益会开始不准、相位会开始偏移。

为什么它叫「运算」放大器

这个名字来自模拟计算机时代：那时候没有 CPU，微分方程是用运放搭出来的。加减乘除、积分微分，都能用运放电路实现——因为反馈网络如果是电阻，它做线性运算（比例、求和、取差）；如果换成电容，它做微积分运算（积分、微分）。这两个字遗留到了今天：你在这个网站上做的「信号调理」，本质就是在用运放做运算，只不过算的不是数学题，而是「把传感器的电压翻译成 ADC 能读的电压」。

2.2　两条黄金法则：虚短、虚断（以及它们什么时候不成立）

这是全篇最重要的一段。课本上所有运放电路的公式，都能从这两条规则推出来，你不需要背任何一个公式。

两条规则

规则一 · 虚断（virtual open）：流入两个输入端的电流为零。
因为运放的输入电阻极高（106~1012Ω），流入输入端的电流小到可以当成 0。所以「两个输入端不从电路里偷电流」，你可以放心地对任何一个节点写基尔霍夫电流方程。

规则二 · 虚短（virtual short）：两个输入端的电位几乎相等，V+ ≈ V−。
因为 Vout = Aol × (V+ − V−)，反过来说 V+ − V− = Vout/Aol。输出最多 3.3V、Aol 至少 105，所以两端电位差最多 33µV——在毫伏和伏的量级上就是「相等」。注意它不是真的短路（没有导线连接，电流过不去），只是电位相等，所以叫「虚」短。

虚短成立的三个前提（少一个就全错）
  1. 必须存在负反馈——反馈必须送回反相端(−)，让净输入减小。如果是正反馈（送回同相端），运放会立刻跳到某一轨，虚短彻底失效。这也是「比较器不能用虚短虚断」的原因：比较器故意不加负反馈。
  2. 运放必须还没饱和——输出没有贴到电源轨上，仍在线性区。判断方法：先用虚短虚断算出理论输出，如果算出来的值超出了电源范围（或超出了手册的输出摆幅），就说明它已经饱和了，这时候必须改用「输出 = 电源轨」来重新分析。这是做题和调试时最常见的失败点。
  3. 开环增益 Aol 要够大，而且信号频率不能太高——Aol 随频率下降，到几十 kHz 以上时可能只剩几百倍，此时 V+ 和 V− 的差就不再是「可以忽略」的量级了。

   所以「虚断」是近似，不是真理。

【虚短的由来：把 A_ol 推到极限】

   V+ - V- = Vout / A_ol

   若 Vout 最大 3.3V：
        A_ol = 100      →  V+ - V- = 33mV   （差得远，不能当虚短）
        A_ol = 10^4     →  V+ - V- = 330uV  （勉强，适合做粗略估算）
        A_ol = 10^5     →  V+ - V- = 33uV   （可以当虚短，误差小于 0.1mV）
        A_ol = 10^7     →  V+ - V- = 0.33uV （完全可当虚短）

   你的电路里所有电压都是毫伏到伏的量级，
   所以 33uV 的相对误差在 10^-5 以下 —— 这就是虚短的合法性。

【失效判据：三看】

   一看反馈:  电阻是不是从输出接回了 (-) 端？接回 (+) 端 → 正反馈，全错。
   二看饱和:  按虚短算出的 Vout 是否超出 (VOL, VOH)？
              超出 → 运放饱和，Vout = VOH 或 VOL，V+ 不再等于 V-。
   三看共模:  两个输入端的电位是否落在手册的「共模输入范围」内？
              超出 → 运放不工作，甚至出现相位反转（输出突然跳到另一轨）。
              例：LM358 在 +5V 供电时，输入只能到 0 ~ +3.5V。
                  你想测 12V 上的电流，必须用专门的电流检测放大器。
两个「看起来像虚短」但其实不是的东西

一是「虚地」不是「接地」。反相放大器的反相端电位是 0V，但它并没有接在 GND 上——它是被运放用输出来「顶着」保持在 0V 的。如果你在这个节点上直接焊一根线到 GND，运放就失去作用了：输出会被短路成 0V，输入电流全部从你那根线流走。虚地只能用来写方程，不能真的去接。

二是单电源电路的「虚拟地」是真电路，但它是 VCC/2，不是 0V。这两个中文词只差一个字，含义完全不同，2.8 节专门讲。

解题固定四步（做题、调板、算误差都能用）
  1. 标出两端的电位：先看同相端 (+) 接在哪，它的电位是多少（可能接 GND、接 VCC/2、接某个基准、或接另一个电阻分压）。
  2. 把 (+) 的电位抄给 (−)：由虚短，V− = V+。这一步是整个推导的支点。
  3. 对 (−) 节点写 KCL：由虚断，流入运放输入端的电流为 0，所以「从各个电阻流进这个节点的电流之和 = 0」。
  4. 解出 Vout，再用「二看饱和」检查一遍结果是否落在电源范围内。

下面四种电路，我都用这四步推一遍。你会发现每次只是「(+) 接在哪」和「有几个电阻」不同而已。

2.3　反相放大器与加法器：所有推导的模板

先看这个最经典的电路。学会了它，后面三个都是它的变形。

【电路：信号从反相端进，同相端接地】

                         Rf
                  ┌────/\/\/\────┐
                  │              │
                  │              │
   Vin ──/\/\/\───┴── (-)\       │
           Rin           \      │
                          \_____┴──── Vout
                          /
                      (+)/ 
              GND ────────┘

   两个电阻的连接点记作节点 A（就是反相端那个节点）。
   注意 Rf 从节点 A 接回输出 —— 这是【负反馈】，所以虚短可以用。

【四步推导】

   第 1 步  (+) 端接 GND            →  V+ = 0V
   第 2 步  虚短                     →  V- = V+ = 0V   ← 这叫「虚地」
   第 3 步  对节点 A 写 KCL（虚断：流入运放的电流 = 0）
                从 Vin 流进 A 的电流     = (Vin - V-) / Rin = Vin / Rin
                从 A 经过 Rf 到输出的电流 = (V- - Vout) / Rf = -Vout / Rf
                两者必须相等（A 点没有别的电流出口）：
                      Vin / Rin = -Vout / Rf
   第 4 步  解出
                      Vout = -(Rf / Rin) · Vin

【三个必须记住的性质】

   ① 增益 A = -Rf / Rin
      负号 = 反相（输入上升，输出下降），不是「变负电压」的意思。
      想放大 10 倍就取 Rf/Rin = 10，比如 Rf = 100k, Rin = 10k。

   ② 输入电阻 = Rin（非常低！）
      因为节点 A 是虚地（0V），信号源看到的负载就是 Rin 对地。
      你想让输入电阻高一点？加 Rin 的阻值，但增益就掉了。这是反相放大器的天生缺陷。

   ③ 共模输入 = 0V（几乎不变）
      两个输入端都在 0V 附近，与信号无关。
      所以反相放大器【不挑运放的共模范围】，这一点常常比同相结构更好用。
      代价是它需要「虚地」这个 0V —— 单电源系统里 0V 就是 GND，
      所以单电源下反相放大器只能处理「相对 GND 为正」的信号，
      且输出会往负方向走 → 立刻撞到 0V 轨。【单电源下别用反相放大器直接放大小信号。】
      要做反相，就得先把「地」抬到 VCC/2（见 2.8 节）。
关于平衡电阻 R'：为什么要多焊一颗电阻

真实的运放两个输入端都会吸一点电流 Ib（见 2.7 节）。在反相放大器里：

  • 反相端看到的外接电阻是 Rin 与 Rf 并联（Rin 接 Vin=0V 的地，Rf 接输出，交流上都算「地」）；
  • 同相端如果直接接地，看到的外接电阻是 0Ω。

两个输入端的「源电阻」不相等，Ib 在其中一端产生的电压降就没法抵消。解决办法很简单：在同相端串一颗 R' = Rin ∥ Rf 的电阻再接地，让两端看到的电阻都一样，Ib 的影响就互相抵消了。

例：Rin = 10k、Rf = 100k，则 R' = 10k ∥ 100k ≈ 9.1k（取 E24 标称值）。这一颗电阻在 LM358（Ib = 20nA 典型值）这类电路里能把 Ib 引起的失调从 2mV 量级压到几十微伏。用 CMOS 运放（Ib 只有 pA 级）时可以省掉它，这也是为什么很多现代电路图上你没有看到这颗电阻。

代价：这颗电阻和它的热噪声、以及它带来的输入杂散电容，在某些高速电路里反而会添乱。所以它是「按需加」，不是「必须加」。

把反相放大器的输入从一路变成多路，就得到了单片机项目里非常实用的反相加法器。它的用处不是做数学加法，而是把信号「搬」到你想要的区间里。

【电路：多路输入各自经一个电阻汇到虚地节点】

                  Rf
           ┌────/\/\/\────┐
           │              │
   V1 ─/\/\/\──┐          │
        R1     │          │
               ├── (-)\   │
   V2 ─/\/\/\──┤       \  │
        R2     │        \_┴──── Vout
               │        /
               ├── (+)/ 
        GND ───┴──────┘   （同相端接地，节点仍是虚地 0V）

【推导：对虚地节点把所有流入电流加起来 = 0】

        V1/R1 + V2/R2 + V3/R3 + ... = -Vout/Rf

   →    Vout = -Rf · ( V1/R1 + V2/R2 + V3/R3 + ... )

   若 R1 = R2 = R3 = R：   Vout = -(Rf/R) · (V1 + V2 + V3)
   这就是标准的「加法器」：输出等于各路电压之和乘一个系数，再反相。

【单片机里的真实用途：把 1~5V 搬移到 0~3V 给 ADC】

   信号：4~20mA 经 150Ω 采样电阻 → 0.6V ~ 3.0V
   目标：减掉 0.6V 的零点、压缩到 ADC 量程内
   做法：一路接信号（-1 倍），一路接 0.6V 基准（+0.6V 的搬移）

        Vout = -(Rf/R1)·Vin + (Rf/R2)·0.6V

   用加法器做「减基准」，是单电源系统里最常见的搬移手法。
   但要注意：【基准电压本身的精度直接变成你的测量误差】，
   所以这里的 0.6V 必须来自稳压源或基准芯片（如 TL431、REF3030），
   不能随便用两个电阻从 VCC 分压（VCC 一抖，零点就跟着抖）。
两个实用技巧

技巧一：需要很大的增益，但不想用 10MΩ 的反馈电阻。Rf 太大会和输入杂散电容组成低通、还会捡拾噪声。可以用 T 型网络（反馈支路里再插一个对地电阻，把等效 Rf 放大几十倍），用小电阻实现大增益。代价是噪声增益变大、带宽变窄——用的时候算一下 GBW。

技巧二：加法器的输入之间会「串扰」。因为所有输入都汇在同一个虚地点上，V1 的变化会通过 R1 影响节点电流，理论上 V1 在节点上产生的电位始终是 0（虚地），所以各路之间其实是隔离的；但如果信号源本身有内阻，内阻就变成了 R1 的一部分，增益会偏。做精确加法时，前级要用低阻输出（比如先过一级电压跟随器）。

2.4　同相放大器与电压跟随器：输入阻抗高，但要小心共模范围

把信号改从同相端进，反馈照样回到反相端，电路立刻换了一副性格。

【电路：信号从同相端进，反相端靠两个电阻分压得到反馈】

                          ┌───────┐
                          │       │
                  Rf      │       │
           ┌────/\/\/\────┤       │
           │               │       │
           │               │       │
          Rg              (-)\     │
           │                   \   │
          GND              (+)/ \__┴──── Vout
           │                  │
           │                  │
   Vin ────┴──────────────────┘

   反馈支路：Vout ── Rf ── 节点 A ── Rg ── GND
   信号直接从 (+) 端进，所以 V+ = Vin（理想情况不吸电流）。

【四步推导】

   第 1 步  (+) 端接信号源      →  V+ = Vin
   第 2 步  虚短                →  V- = V+ = Vin     ← 整个推导的支点
   第 3 步  对节点 A 写 KCL（节点 A 就是反相端）
                从输出经 Rf 流进 A 的电流 = (Vout - Vin) / Rf
                从 A 经 Rg 流向地的电流   = (Vin - 0) / Rg
                两者相等：
                     (Vout - Vin) / Rf = Vin / Rg
   第 4 步  两边乘 Rf 并整理
                     Vout - Vin = Vin · (Rf/Rg)
                     Vout = Vin · ( 1 + Rf/Rg )

【三个必须记住的性质】

   ① 增益 A = 1 + Rf/Rg  ——永远 ≥ 1，而且没有负号
      想放大 10 倍：Rf/Rg = 9，比如 Rf = 90k, Rg = 10k。
      注意分母是 Rg 不是 Rin，而且有个「1+」，这是最容易记错的地方。
      （记忆法：Rg 开路时反馈系数 = 1，增益 = 1，就是跟随器。）

   ② 输入电阻极高 ≈ 运放自己的 R_id（10^6 ~ 10^12 Ω）
      信号直接进 (+) 端，不经过任何电阻。这是它相对反相放大器的最大优势，
      也是它被用来接 pH 电极、光电二极管的原因。

   ③ 共模输入 = Vin（缺点！）
      两个输入端的电位都等于 Vin，所以 Vin 必须落在手册的「共模输入范围」内。
      这一条在单电源电路里非常要命：
         - LM358 在 +5V 供电时共模范围是 0 ~ +3.5V，
           所以它不能放大「输入接近 5V」的信号，也不能放大「输入低于 0V」的信号；
         - 用 +3.3V 供电时共模上限只有 1.8V 左右 ——
           如果你要缓冲一个 3.0V 的基准电压，LM358 直接罢工（输出贴在 1.8V 附近不动）。
           必须换轨到轨输入（RRIO）的运放，如 MCP6002、TLV9002、OPA333。
         - 这一条也是「电流检测为什么不能用普通运放」的答案：
           高边采样的输入端压着十几伏，远超通用运放的共模范围。

把 Rf 短路（0Ω）、Rg 开路（不接），同相放大器就退化成了最简单也最有用的电路：电压跟随器。增益正好 1，输入输出一样大——看起来什么都没干，但它做了整个信号链里最重要的一件事：阻抗变换。

【电路：输出直接接回反相端，别无他物】

    Vin ──────┬──── (+)\
              │         \
              │          \______┬──── Vout
              │          /      │
              └──── (-)/        │
                   └────────────┘    ← 一根导线把输出接回反相端

   这就是「单位增益缓冲器」，增益 = 1 + 0/∞ = 1。

【为什么输出阻抗几乎为零：把负反馈的数学代进去】

   运放开环时的输出电阻 Ro ≈ 50 ~ 100 Ω（LM358 手册典型值约 50Ω）。
   加上负反馈后，输出电阻被「压缩」了 1 + A_ol·β 倍：

        R_out(闭环) = Ro / (1 + A_ol · β)

   跟随器的 β = 1（输出全部反馈回去），A_ol = 10^5：

        R_out = 50Ω / (1 + 100000) ≈ 0.5 毫欧

   这不是玄学，而是一个「自动稳压」的过程：
   假设负载电流让输出掉下 1mV，反馈立刻把反相端也拉低 1mV，
   运放看到 V+ - V- = +1mV，输出就往上顶 1mV × A_ol —— 瞬间补回来。
   环路把输出「钉」在 Vin 上，任何试图改变它的因素都被反向修正。

   这个数字的实际意义：
       高阻传感器（100MΩ）──────►[跟随器]──────► ADC 引脚（看到 < 1Ω）
       源阻抗被降低了 8 个数量级，ADC 的采样电容终于充得动电了。

【增益是 1，那它到底有什么用？四件事】

   ① 阻抗变换（最主要的用途）
      把「高阻、带不动负载」的信号源，变成「低阻、能驱动负载」的输出。

   ② 驱动容性负载
      ADC 的采样电容、长电缆的分布电容，都会让普通信号源「反应不过来」。

   ③ 隔离与保护
      传感器的输出先过跟随器，后级电路出问题也不会伤到传感器。

   ④ 基准电压缓冲
      用电阻分压得到的 VCC/2 基准内阻很高（分压电阻的并联值），
      直接给 ADC 用会随负载变化 → 必须过一级跟随器。

【但它有四个必须知道的限制】

   ① 输入共模范围照样卡着你
      跟随器的两个输入端电位都等于 Vin，Vin 必须落在共模范围内。
      用 LM358 在 3.3V 单电源下缓冲一个 3.0V 的基准？输出会卡在 1.8V 附近。
      ——这是新手最常踩的跟随器坑，看起来「增益 1 的电路不可能出错」。
      解法：用 RRIO（轨到轨输入输出）运放。

   ② 输出摆幅限制（即使 Rail-to-Rail 也不是真的到轨）
      输出电压不可能完全等于电源。通用运放 LM358 在 +5V 供电、2kΩ 负载下，
      高电平输出典型只有 VCC-1.5V ≈ 3.5V；
      标「轨到轨输出」的 MCP6002 在轻载下能到 VCC-25mV 左右，
      但灌/拉电流一大（比如 10mA），离轨就会拉开到 200mV 以上。
      所以缓冲 3.0V 基准时，务必给电源留余量或者选真正低离轨的型号。

   ③ 容性负载会振荡
      输出直接接大电容（或长电缆）时，运放的输出电阻和电容组成一个极点，
      吃掉相位裕度，几百 kHz 处就开始振铃。经验做法：
      在输出和电容之间串一颗 【50~100Ω】 的隔离电阻，
      或者用「隔离电阻 + 小电容」的 RC 补偿网络。
      这是示波器上看到「运放输出有高频毛刺」的最常见原因。

   ④ 高频时 R_out 会变大
      A_ol 随频率下降，所以到了几百 kHz 以上，
      R_out 会从毫欧级回升到几十欧。跟随器「像一根导线」的说法只在低频成立。

一个容易混的概念：噪声增益（noise gain）

反相放大器的信号增益是 Rf/Rin，但它对「运放自己产生的误差」的放大倍数却是 1 + Rf/Rin。这个更大的倍数叫噪声增益，之后你在算失调误差和带宽时都要用它：

  • 带宽：由噪声增益决定。Rf/Rin = 100 的反相放大器，闭环带宽 = GBW/101，不是 GBW/100（差别很小，但增益为 1 的反相放大器带宽是 GBW/2，不是 GBW，差别就大了）。
  • 失调误差：Vos 在输出端产生的误差 = Vos × (1 + Rf/Rin)。
  • 稳定性：噪声增益低的电路更容易振荡，见 2.7 节的「单位增益稳定性」。

一句话：信号增益决定输出多大，噪声增益决定电路「有多快、有多准、稳不稳」。

2.5　差分放大器与仪表放大器：只放大「差」，无视「共」

前面两个电路的输入端总有一端接地。但在单片机项目里，你最常遇到的信号是悬浮在两个电位之间的：分流电阻两端的电压、电桥的两臂、4~20mA 环路上采样电阻的两端。这类信号必须用差分放大器，因为只有它能把「两端之差」取出来，同时丢掉「两端共同」的部分。

先把「共模」这件事说清楚

差分放大器的两个输入电压可以拆成两部分：

差模 Vid = V2 − V1　（你要的信号）　　共模 Vic = (V1 + V2)/2　（你不要的）

共模抑制比 CMRR 就是「差模增益 ÷ 共模增益」，用 dB 表示：CMRR(dB) = 20 log10(Ad/Ac)。

为什么要关心它？举个具体数：电机高边采样的分流电阻上，差模信号只有 50mV，而共模是 12V 的电机电源（还在以几十 kHz 的频率上下跳）。两个电压差了 240 倍。如果电路有 60dB 的 CMRR（1000 倍），12V 的共模就会漏出 12mV 到输出——相当于给你的 50mV 信号加了 24% 的误差。CMRR 不够，电流采样就是白做。

【电路：经典的四电阻差分放大器（课本叫「减法运算电路」）】

                        R2
                 ┌────/\/\/\────┐
                 │              │
                 │              │
   V1 ──/\/\/\───┴── (-)\       │
          R1              \     │
                           \____┴──── Vout
                           /
                       (+)/
      V2 ──/\/\/\───┬──┘
            R3      │
                    │
                   R4
                    │
                   GND

   注意：这是一张「两只脚都要接信号」的图，R1/R2 支路管反相输入，
   R3/R4 支路把同相端的电位「抬」到一个由 V2 决定的值上。

【四步推导（虚短虚断 + 电阻分压，多了一步）】

   第 1 步  求 (+) 端电位：V2 经 R3、R4 分压
                V+ = V2 · R4 / (R3 + R4)
   第 2 步  虚短
                V- = V+ = V2 · R4 / (R3 + R4)
   第 3 步  对 (-) 端节点写 KCL（从 V1 流入的电流 = 经 R2 流向输出的电流）
                (V1 - V-) / R1 = (V- - Vout) / R2
   第 4 步  代入并整理，得到通式
                Vout = V2 · [R2/(R1+R2)] · [1 + R2/R1] ... 整理后：
                Vout = V2 · (R4/(R3+R4)) · (1 + R2/R1) - V1 · (R2/R1)

【当四个电阻满足 R1 = R3、R2 = R4 时（匹配条件），式子变成漂亮的形式】

                Vout = (R2 / R1) · ( V2 - V1 )

   增益 = R2/R1，只放大「差」。若 R1 = R3 = 10k, R2 = R4 = 100k → 增益 10 倍。
   这就是 ADC 前端和电流采样的原型电路。

【软肋一：输入电阻低，而且不平衡】

   差模输入电阻 = R1 + R3 = 2·R1（信号源要驱动两个电阻）
   共模输入电阻 = R1 + R2（一侧）和 R3 + R4（另一侧）
   10k + 10k = 20kΩ 的差模输入电阻，对电桥式传感器（输出阻抗几 kΩ）还算能用，
   对接 pH 电极（100MΩ）就完全不行 —— 那必须用仪表放大器。

【软肋二：共模抑制比完全由电阻匹配决定（这是最致命的）】

   课本上写着「R1 = R3、R2 = R4 时 CMRR 无穷大」，
   但它没有告诉你：现实里 1% 精度的电阻只能配到 1%，
   于是 CMRR 会掉到 30~50dB（详细计算见第 3 节例 3）。
   而电流采样通常需要 80dB 以上 —— 所以【分立电阻搭的差分放大器，
   几乎不能用于电机电流采样】，必须用集成器件。

【软肋三：共模输入范围受限】

   两个输入端都直接连在信号上，所以 V1、V2 的电位必须落在运放的共模范围内。
   高边采样时 V1、V2 都在 12V 附近，通用 5V 运放直接超出绝对最大额定值，
   不是「测不准」，而是「会坏」。
【结构：两个缓冲器 + 一个差分放大器，只用一颗电阻定增益】

                      ┌──────────────────────────────────────┐
                      │           芯片内部                    │
   V1 ──►┌────────┐   │   ┌─────────┐                        │
         │ 缓冲 A1 │───┼──►│         │                        │
         │ 增益 G1 │   │   │ 差分 A3 │──────────► Vout        │
      ┌──┤(-)     │   │   │ 增益 = 1│                        │
      │  └────────┘   │   └─────────┘                        │
     Rg               │        ▲                             │
      │  ┌────────┐   │        │                             │
      └──┤ 缓冲 A2 │───┼────────┘                             │
   V2 ──►│(-)  G1 │   │                                      │
         └────────┘   │   A1、A2 之间的 Rg 同时决定两级的增益：│
                      │      总增益 = 1 + 2R/Rg              │
                      └──────────────────────────────────────┘

   三个软肋怎么被解决的：

   ① 输入电阻极高
      信号先进 A1、A2 的同相端，输入电阻就是运放自己的 R_id（10^9Ω 以上）。
      接电桥、接 pH 电极、接热电偶都不成问题。

   ② CMRR 由内部电阻决定，不再靠你配对
      芯片里的四颗电阻是同一块硅片上激光修调出来的，匹配度可以做到 0.01% 以内，
      CMRR 轻松达到 100~120dB。这是「一颗芯片换掉四颗电阻」的全部意义。

   ③ 增益只由一颗外部电阻 Rg 设定，改增益不用动匹配
      典型公式（以 INA128 数据手册为例）：   G = 1 + 50kΩ / Rg
      想要 G = 100 → Rg = 50kΩ/99 ≈ 505Ω（E96 标称 511Ω）。
      AD620 的公式是 G = 1 + 49.4kΩ / Rg，各家芯片的常数不同，
      【一定要照对应型号的手册算，不要把 50k 当成通用常数。】

【代价：为什么不是所有场合都用仪表放大器】

   · 贵：一颗 INA128 的价格能买十几颗 LM358；
   · 慢：内部三级串联，GBW 通常只有几百 kHz ~ 1MHz，压摆率也低；
   · 需要双电源或专门设计：传统仪表放大器（INA128）在单电源下输入范围很窄，
     现代的单电源仪表放大器（INA322、AD8236）才好用；
   · 多一颗电阻要算：Rg 的精度和温漂会直接变成增益误差（增益误差 ≈ Rg 误差，
     而 Rg 通常是几百欧姆的小电阻，走线电阻和焊接热电势都要考虑）。
为什么说差分放大器是 ADC 前端与电流采样的核心

三个原因，一个比一个实际：

  1. 它只放大你关心的那一段。分流电阻上真正的信息是「两端之差」，其他所有东西（电源电压、地线噪声、PWM 的共模跳变）都是垃圾。差分放大器是唯一能在模拟域就丢掉垃圾的结构——比让 ADC 去减更准，因为垃圾可能已经把 ADC 前端撑满了。
  2. 它能把信号「搬」到 ADC 量程正中间。双向电流采样需要既有正也有负的输出。差分放大器有一个 REF 引脚，把 REF 接 VCC/2，输出的零点就搬到了量程中间，正负电流都能测；接 GND，就只测单向。这个「搬零点」的功能，单端放大器给不了。
  3. 它天然配合差分输入的 ADC。很多精密 ADC（如 ADS1115 这类 16 位 ΔΣ ADC，或者 STM32 部分型号的差分模式）本身就是差分输入，直接对接就不需要再把单端信号转回差分，省掉一级电路和一级误差。

所以你在电机驱动板、电池管理板、4~20mA 采集板上看到的「ADC 前级」，十有八九是一颗差分放大器或电流检测放大器，而不是普通的同相放大器。

2.6　积分器与微分器：反馈元件换成电容之后

前面所有电路，反馈网络都是电阻，所以你得到的是「输出电压 ∝ 输入电压」。把电阻换成电容，电路就开始做微积分了——因为电容的电流和电压之间是微分关系：I = C · dV/dt。

【积分器：把反馈电阻 Rf 换成电容 C】

                          C
                  ┌───────||───────┐
                  │                │
   Vin ──/\/\/\───┴── (-)\         │
           R                \      │
                             \_____┴──── Vout
                             /
                         (+)/
               GND ────────┘

   第 1 步  (+) 接地              →  V+ = 0
   第 2 步  虚短                  →  V- = 0（又是虚地）
   第 3 步  对虚地点写 KCL：从 Vin 流进来的电流，全部流进电容
                Vin / R = -C · dVout/dt      ← 注意电容电流方向（流向输出侧）
   第 4 步  两边对时间积分
                Vout(t) = -(1/RC) · ∫ Vin dt + Vout(0)

   结论：
     · 输出与输入的「积分」成正比，比例系数 1/RC（单位 1/秒）；
     · 有一个负号（反相积分器）；
     · Vout(0) 是初始条件 —— 上电时电容上的残余电压会变成输出零点，
       所以实际电路都要想办法让它归零（并联复位开关，或者并一颗大电阻）。

【频率响应：增益与频率成反比】

        |Vout/Vin| = 1 / (2π f R C)

   f = 1kHz,  R = 10k,  C = 100nF → 1/(2π·1k·10k·100n) = 0.159 （衰减）
   f = 100Hz, 同样参数         → 1.59 （放大 1.59 倍）
   f = 10Hz                    → 15.9 倍
   f → 0（直流）               → 增益 → 无穷大    ← 危险！

   所以纯积分器在直流下增益无穷：输入失调电压会被一直积分，
   输出像爬楼梯一样一直爬到电源轨上卡死。
   【实际电路必须在电容旁边并联一颗电阻 Rf（几 MΩ），把直流增益限在 Rf/R。】
   这颗电阻同时也决定了积分器「从哪个频率开始不再像积分器」。

【微分器：把输入电阻换成电容】

   Vin ──||───┬── (-)\
        C     │       \
               \       \_____┴──── Vout
                R      /
                    (+)/

   同样四步推得：      Vout = -R C · dVin / dt

   频率响应：          |Vout/Vin| = 2π f R C    ← 随频率线性【上升】
为什么微分器对噪声敏感（而积分器不敏感）

看上面两个频率响应，答案就在式子里：

  • 积分器的增益是 1/(2πfRC)：频率越高，增益越小。它是一个低通，天然把高频噪声压下去。这就是「积分器在工程上到处都用」的原因。
  • 微分器的增益是 2πfRC：频率越高，增益越大，每十倍频程 +20dB。噪声的能量本来就集中在高频（热噪声是全频段的，开关电源毛刺、数字电路的边沿更是集中在高频），微分器等于给噪声装了一个「越吵越响」的放大器。

举例：一个 100mV 幅值、1MHz 的干扰（示波器探头上随处可见）加在微分器输入端。取 R = 10k、C = 10nF，1MHz 时的增益 = 2π×106×104×10-8 = 628 倍 → 输出想要冲到 62V。运放早就饱和了，输出被噪声「占满」，真实信号的斜率信息一丝也看不到。

还有两个附加原因：运放自身的输入噪声（nV/√Hz）在高频被放大同样的倍数；输入端的杂散电容和电阻组成额外的极点，会让微分器在高频产生尖峰甚至自激振荡。

结论：工程上几乎不用纯微分器。要做微分（比如检测信号边沿），标准做法是给输入电容串一颗小电阻 R1（限制高频增益上限为 R/R1），并在反馈电阻上并一颗小电容做低通——本质上就是「有意识地做两级滤波」，而不是直接把噪声放大到轨。

积分器在单片机项目里的三个真实用途
  1. 压电传感器的电荷放大。压电片受力时输出的是「电荷」而不是电压，用积分器（也叫电荷放大器）才能把电荷变成可用电压。敲击检测、振动传感器属于这一类。
  2. 把 PWM 变成模拟电压（模拟域滤波）。方波积分一次就得到三角波，积分两次（两级 RC 或运放积分器）就能得到接近直流的平均值。用运放积分器做 DAC 的后级平滑，比 RC 滤波更「硬」：带载能力强、纹波一致。
  3. 双斜率积分 ADC 的核心。老式数字万用表里的 ICL7106/ICL7107 就是靠一个积分器把输入电压积分固定时间，再反向积分回去计时——积分过程自带低通，所以这类表在工频干扰下特别安稳。这正是「积分器对噪声不敏感」的一个大工程实例。

2.7　实际运放的非理想参数：手册上那几行小字，才是成败所在

前面六个小节全是理想运放。理想运放是不会有误差的，而现实里的运放有六个参数会轮流给你添麻烦。这一节按「你会在什么时候被它咬到」的顺序讲：先是直流精度（Vos、Ib），再是交流速度（GBW、SR），最后是电压边界（输出摆幅、共模范围）和稳定性。

（1）输入失调电压 Vos：直流精度的头号杀手

理想运放在两个输入都是 0V 时，输出也应该是 0V。真实的运放不是——它的输入级由两只（或更多）三极管组成，这两只管子不可能完全一样，于是它们之间有一个几毫伏的「内置电池」。这个等效电池就串在输入端，叫输入失调电压 Vos。

关键点是：这个误差电压会跟着你的信号一起被放大。公式很简单：

输出端的失调误差 = Vos × (1 + Rf/Rg)　（噪声增益，两种结构都一样）

  • 极性是随机的。同型号的两颗芯片，Vos 可能一个 +3mV、一个 −5mV。所以你不能「焊一个固定电阻补偿掉它」，只能靠软件标定（上电时测一次零点存进 flash）或者选低失调的芯片。
  • 标定能消掉「此时此温」的 Vos，消不掉温漂。你标定时的温度和工作时的温度不一样，Vos 就变了。所以真正决定长期精度的是下一项：温漂。
  • 它还是个「隐藏的饱和源」。开环时 Vos 会把输出顶到电源轨（这就是 2.1 节说的「一睁眼就饱和」）；即使闭环，Vos 也会占掉一部分输出摆幅。
  • 数值直觉：LM358 在 25°C 下 Vos 典型 2mV、最大 7mV（按 TI LM358 数据手册）；60 倍增益时最大会造成 420mV 的输出误差。而 OPA333 这类自稳零（斩波）运放，Vos 最大只有 10µV（按 TI OPA333 数据手册），60 倍下只有 0.6mV——差了 700 倍。这就是同一张电路图换一颗芯片、零点误差从「0.7A」变成「1mA」的原因。
温漂：标定救不了的那部分

手册写 dVos/dT，单位是 µV/°C。它是 Vos 随温度的变化率，而且是非单调、非线性的——你不能用「测两个温度点然后线性插值」的办法完全修正它。

对比一下两种芯片（都是「按典型值估算」）：

  • LM358：约 7µV/°C。60 倍增益下 = 0.42mV/°C。车间温度从 25°C 变到 60°C（35°C 温差）→ 输出漂 14.7mV，折算到 5A 量程上是 24.5mA 的零点漂移。
  • OPA333：0.05µV/°C。60 倍增益下 = 3µV/°C，35°C 温差总共漂 0.1mV——比 12 位 ADC 的 1 个 LSB 还小，可以不管。

所以「测量精度要求 1% 以内、还要跨温度工作」的项目，必须优先选低失调+低温漂的芯片，而不是靠软件标定硬扛。这是选型的第一条硬指标。

代价也要知道：斩波/自稳零运放（OPA333、ADA4522、LTC2050）带宽低（OPA333 的 GBW 只有 350kHz）、白噪声大、输入端有几十 kHz 的斩波尖峰电流，而且贵。它们是「精密直流」工具，不是「高速」工具。

（2）输入偏置电流 Ib：高阻源的隐形杀手

运放的输入级是晶体管，晶体管要工作就需要一点电流。这个电流从你的外部电路里「偷」，叫输入偏置电流 Ib。它对电路的影响是：流过外接电阻就变成电压。

Ib 造成的输出误差 ≈ Ib × Rf　（反相放大器，反相端看到 Rin∥Rf 但同相端看 0Ω 时）

输入级类型Ib 典型值代表型号配 100kΩ 反馈时配 100MΩ 高阻源时

这张表解释了现场 C 那件事的一半：pH 电极内阻 100MΩ，用 LM358 的 20nA 偏置电流就是 2V 的误差——比信号本身大几十倍。所以接高阻传感器时，第一个要查的参数不是 Vos，而是 Ib，必须选 pA 级甚至 fA 级的运放。

  • Ib 随温度急剧增长。BJT 输入级大约每升 10°C 翻一倍：25°C 时 20nA，85°C 时就可能是 1µA 以上（按指数规律估算）。所以高温工作的电路要按最高温度重新算一遍。
  • 两个输入端的 Ib 不相等，它们的差叫输入失调电流 Ios。平衡电阻（R′ = Rin∥Rf）能抵消「相等的那部分」，剩下的 Ios 消不掉。这就是为什么精密电路里平衡电阻是「减少误差」而不是「消除误差」。
  • 怎么判断你的电路是被 Ib 还是 Vos 坑了？做个实验：在信号源和输入端之间串一颗大电阻（比如 1MΩ）。如果输出误差明显变大，说明是 Ib 主导；如果几乎不变，说明是 Vos 主导。这个「串电阻试验」在实测中非常好用。
  • CMOS 输入有个附加陷阱：输入电压超过电源轨时，输入保护二极管会导通，输入电流可能瞬间涨到毫安级。单电源电路里如果信号有可能超过 VCC（比如 5V 传感器接到 3.3V 系统），必须串限流电阻或加钳位。

（3）GBW 增益带宽积：小信号能放多大频率

为了稳定，几乎所有运放内部都做了「主极点补偿」：从很低频开始，开环增益以 −20dB/十倍频程 的固定斜率下降，直到单位增益（0dB）为止。这条斜线意味着一个非常有用的结论——增益和带宽的乘积是常数：

闭环带宽 f−3dB = GBW / 噪声增益　　噪声增益 = 1 + Rf/Rg

   增益(dB)

     100 ┤  ●                    ← A_ol = 10^5（通用运放直流值）
      80 ┤    ●

                              GBW = 1MHz（增益降到 1 的频率）

   在这条斜线上「增益 × 频率 = 常数 = GBW」。所以：

       需要闭环增益 60 倍  →  带宽 = 1MHz / 61 ≈ 16.4kHz
       需要闭环增益 10 倍  →  带宽 = 1MHz / 11 ≈ 91kHz
       需要闭环增益  1 倍  →  带宽 = 1MHz / 2  ≈ 500kHz
                            （注意：跟随器的噪声增益是 2，因为反馈系数 β = 1/2
                             是针对「反相端分压」而言的？不对——跟随器 β = 1，
                             但通用运放的相位裕度是按最坏情况设计的，
                             工程上跟随器带宽≈GBW 是常见近似。见下文说明。）

   实际取值建议：算出来的带宽要留 5~10 倍余量，
   因为 GBW 是典型值，量产分散、温度变化都会让它变小；
   而且「带宽」是 -3dB 点，在它附近增益误差和相移都已经很大了。

【增益不够时会怎样】

   如果信号频率接近 f_-3dB，你看到的不是「突然没输出」，而是：
     · 增益比理论值小（幅度误差）
     · 输出相对输入有相移（几十度）
     · 方波边沿变圆、正弦出现幅度衰减
   这些都是「A_ol 在这个频率上已经不够大」的表现，
   因为负反馈的修正能力正比于 A_ol·β，A_ol 掉下来，闭环精度就掉下来。

【GBW 不是万能的：它只管小信号】

   小信号带宽由 GBW 决定，大信号带宽由 SR 决定（下一小节）。
   两个都要算，取小的那个。
想放宽带宽，有三条路（按推荐顺序）
  1. 换高 GBW 的运放。最直接。3.3V 系统里常见的选择：TLV9002（约 1MHz）、MCP6002（1MHz）、OPA2350（38MHz）、AD8065（145MHz，但要 5V 以上）。选的时候还要看它在你需要的增益下是否稳定。
  2. 把总增益分两级。要放大 100 倍，用两级各 10 倍，每级带宽都是 GBW/11，而不是 GBW/101——总带宽提高了近 10 倍。这是模拟电路里的标准做法，代价是多一颗运放和一点噪声。
  3. 降低噪声增益。反相放大器的噪声增益比信号增益大 1，高增益时影响很小；但在低增益（< 3）场合，选择同相结构或调整电阻比例会有明显区别。

不要做的事：用一级 1000 倍放大。既没有带宽（GBW/1001）、又放大了失调、还容易受寄生电容影响而振荡。任何超过 100 倍的单级放大都值得怀疑。

（4）压摆率 SR：大信号能有多快

GBW 管的是「小信号」，它假设运放内部一直在正常线性工作。但如果输出要快速变化很大幅度，运放内部的补偿电容来不及充放电，输出就跟不上了——这个极限就是压摆率 SR，单位 V/µs。

满幅正弦的极限频率　fmax = SR / (2πA)　　A 是输出正弦的峰值幅度（V）

道理的来源很简单：正弦 V(t) = A·sin(2πft) 的最大变化率出现在过零点，等于 2πfA。输出要跟上它，就必须有 SR ≥ 2πfA。

  • 正弦波顶部变平、边沿变斜，看起来像三角波——这是最典型的症状。
  • 方波上升沿有明显斜坡：上升时间 tr ≈ ΔV / SR。3.3V 跳变用 LM358（0.6V/µs）需要约 5.5µs。你要传 100kHz 的方波？一个周期才 10µs，边沿就占掉一半。

顺便解释一个常见现象：为什么「换个运放声音就通了」？很多音频电路的问题不是增益不够，而是 SR 不够导致高频大信号被压成三角波。

（5）输出摆幅与「轨到轨」：3.3V 系统里最容易踩的坑

理想运放的输出能到电源轨。真实的运放输出级是两只晶体管串联，它们总要有一定的饱和压降，所以输出到不了电源轨——这个「离轨差多少」直接砍掉你的可用量程。

     RRI  = Rail-to-Rail Input      只有输入共模范围能到电源轨

     轻载（几 uA）  离轨约 25mV

     拉 10mA        离轨可能到 300~500mV

   所以设计时永远留余量：
     3.3V 系统的 ADC 满量程 → 运放输出设计到 3.0V 就停，不要设计到 3.3V。
     这个 0.3V 的余量同时还能容纳：基准误差、电源波动、温漂、以及过载识别。

   LM358 的短路输出电流约 20~40mA（按数据手册），
   输出级的保护电路会在过流时限制电流。
   驱动 LED、驱动 75Ω 视频负载、驱动喇叭，都需要外部三极管或专用驱动，
   不要指望运放直接带大电流负载 —— 那会让输出摆幅急剧变小。

（6）单位增益稳定性：有些运放天生不能做跟随器

负反馈不是无条件稳定的。反馈越深（β 越大、噪声增益越小），环路越容易在某个频率上变成正反馈——因为运放内部有多个极点，每个极点贡献 90° 的相位滞后，总滞后到 180° 且增益仍大于 1 时，就自激振荡了。

  • 通用运放做了「完全补偿」：内部主极点被故意放在很低频，保证在最恶劣的情况（噪声增益 = 1，也就是跟随器）下相位裕度仍然足够（通常 45°~60°）。所以 LM358、TL072、MCP6002 这类芯片在任何增益下都稳定，你可以放心做跟随器。
  • 有些运放故意不做完全补偿，用稳定性换带宽和压摆率。它们的手册会明确写：「stable for gain ≥ 5」（或 ≥ 10）。典型代表：OP37、LM318、OPA637、AD829。用这类芯片做跟随器或低增益放大，必然振荡——输出会出现几 MHz 到几十 MHz 的等幅正弦或锯齿，示波器上一看就知道。
  • 怎么查？翻手册的「Gain Stability」或「Stable Gain」一栏，或者看开环相位曲线在 0dB 处的相位裕度。看不到这些信息，就默认它单位增益稳定（通用运放基本都是）。
  • 噪声增益不等于信号增益。反相放大器的噪声增益是 1 + Rf/Rin，所以在「增益 = −1」的反相电路里，噪声增益其实等于 2，比跟随器更容易稳定一点。评估稳定性永远用噪声增益。
容性负载：另一个让跟随器振荡的原因（和芯片型号无关）

即使芯片单位增益稳定，输出直接接一根长电缆或一个大电容，也可能振荡。原因是输出电阻 Ro 和负载电容 CL 组成了一个新的极点，把相位裕度吃掉了。标准解法（按经验值）：

  • 在输出和电容/电缆之间串一颗 50~100Ω 的隔离电阻（最常用、最省事）；
  • 或者用「隔离电阻 + 直接从输出端引反馈」的接法，把隔离电阻包在环路内（更精确，但反馈点要接在电阻的负载侧）；
  • 或者在反馈电阻上并一颗小电容（几 pF ~ 几十 pF）做相位补偿。

注意：ADC 输入引脚本身就带几 pF 的采样电容和开关，所以「运放直连 ADC」在某些高速场合也会看到振铃。串一颗几十欧姆的电阻（放在 ADC 前面）是常见且安全的小技巧。

（7）还有几个参数，选型时顺手看一眼

  • 共模输入范围（CMRR 之外的一个独立参数）。前面反复提到，这是单电源电路的第一约束。LM358 在 +3.3V 下只有 0~1.8V，MCP6002 是轨到轨输入（可以到 0V 和 VCC）。注意「轨到轨输入」的运放通常是双差分对结构，在共模接近中间电平时会有一处「交接」，产生轻微的失真（crossover 失真）；做精密测量时，最好让共模电压避开 VCC/2 附近那一段。
  • 电源抑制比 PSRR。电源电压的变化有多少会漏到输出。LM358 的 PSRR 典型值约 100dB（按数据手册），也就是电源波动 100mV 只漏出 1µV。但 PSRR 随频率下降很快，开关电源的几百 kHz 纹波要靠 LDO + 去耦电容解决，不能指望 PSRR。
  • 噪声密度 en（nV/√Hz）。LM358 约 40nV/√Hz，TL072 约 18nV/√Hz，精密运放可以到 1nV/√Hz 量级。粗算总噪声：Vn,rms ≈ en × √BW × 噪声增益。例：用 LM358（40nV/√Hz）做 60 倍、带宽 16kHz 的放大，输入端白噪声约 40nV × √16400 ≈ 5.1µVrms，输出端 312µVrms——相对 3V 满量程约 0.01%，对 12 位 ADC（LSB = 0.8mV）来说可以忽略（「按典型值估算」，未计入 1/f 噪声和电阻热噪声，实际会更大一些）。结论：在你这种「低速、中增益」的场合，噪声通常不是瓶颈；失调和共模才是。
  • 静态电流与电源范围。LM358 单电源 3~32V、每通道约 0.3mA；MCP6002 是 1.8~6V、每通道 100µA；OPA333 是 1.8~5.5V、17µA。电池供电的项目里，静态电流往往比精度更重要。
  • 封装与通道数。单运放（SOT-23-5）、双运放（SOP-8）、四运放（SOP-14）。做设计时多留一个通道有好处：可以用来做基准缓冲、也可以用来做「虚拟地」的缓冲。

2.8　单电源供电与虚拟地：单片机系统里的必答题

运放其实不知道「地」是什么。它只看到两个电源脚之间的电压——真正决定电路行为的是输入和输出相对电源脚的位置。所以「单电源」带来的三个具体麻烦是：

  1. 输入共模范围碰不到负轨。双电源（±5V）时输入可以在 −4V~+4V 自由摆动；单电源（0~3.3V）时输入只能在 0~1.8V（LM358）或 0~3.3V（RRIO）之间。
  2. 输出不能往负方向走。一个以 0V 为中心的交流信号，负半周会被输出级直接削掉。你不能在 0~3.3V 的单电源下放大 ±100mV 的交流小信号。
  3. 信号必须被「搬」到电源区间的中间。要让 ±100mV 的交流信号完整摆开，得先给它加一个 1.65V 的直流偏置，让它在 1.55V~1.75V 之间摆动。这个偏置电压就叫虚拟地（virtual ground / mid-rail bias）。
【虚拟地：用两个等值电阻把 VCC 分成一半】

   +3.3V ──┬───/\/\/\───┬───/\/\/\───┬── GND
           │    R1 10k  │   R2 10k   │
           │            │            │
           │           === C1        │
           │          10uF ~ 100uF   │
           │            │            │
           │           GND           │
           │                         │
           └──────────► V_bias = VCC/2 = 1.65V
                    （内阻 = R1∥R2 = 5kΩ）

   三点必须注意：
     ① C1 不能省！没有它，VCC 上的纹波和数字电路的开关噪声会直接
        出现在偏置电压上，然后被同相放大器原封不动地「抄」到输出。
        这就是「单电源运放电路读数随数码管刷新跳动」的经典原因。
     ② 5kΩ 的内阻不算低。如果后级要吸一点电流（比如偏置点接了几个
        电阻网络），1.65V 会偏移。稳妥做法是再拿一个运放通道做跟随器缓冲。
     ③ R1、R2 越小，抗干扰越好、耗电越大。10k+10k（0.165mA @3.3V）是
        常见折中；电池供电可以放大到 100k+100k，但那时 C1 要更大、更要注意漏电。

   │                    \    │
  GND               (+)/ \___┴──── Vout
   （Rg 的另一端接 GND，          （输出以 V_bias 为中心摆动）
     不是接 V_bias！）     ▲
                           │
                     V_bias（虚拟地）

   推导（还是四步）：
     V+ = V_bias
     V- = V_bias                        （虚短）
     (Vout - V_bias)/Rf = (V_bias - 0V)/Rg   （对反相端节点写 KCL）
     Vout = V_bias · (1 + Rf/Rg)

   这个式子告诉我们一件重要的事：【输入为 0 时，输出不是 0，而是
   V_bias × (1 + Rf/Rg)】。也就是说虚拟地本身被放大了同样的倍数！
   所以：
     · V_bias 的误差 = 你的零点误差（1.65V 偏 10mV，60 倍就是 0.6V！）
     · 这就是为什么虚拟地必须做得又准又稳，而且最好用真基准或跟随器缓冲。

【接法二：反相放大器 + 虚拟地（信号必须交流耦合进来）】

                       Rf
                ┌────/\/\/\────┐
                │              │
                │              │
   Vin ──||──/\/\/\──┬── (-)\  │
         C1   Rin    │       \ │
      （隔直）       │        \┴──── Vout
                     │        /
            V_bias ──┴── (+)/

   输入电容 C1 隔掉直流，Rin 的另一端接虚地点（= V_bias）。
   于是 Vout = V_bias - (Rf/Rin)·Vin（以 V_bias 为「新零点」的反相放大）。
   注意：C1 和 Rin 组成高通，截止频率 f = 1/(2π·Rin·C1)。
   想放 1Hz 以上的信号，C1 就要足够大：Rin = 10k 时，1Hz 需要 16uF 以上。

【顺带提醒：虚拟地 ≠ 真地，不要拿它当参考】

   虚拟地的电压精度取决于 R1/R2 的匹配、VCC 的稳定性、C1 的质量，
   通常是「百分之几」的水平，而真地是「零」。
   所以：
     · 可以用虚拟地把信号「搬」到量程中间；
     · 不要用虚拟地去做「减法运算」的基准（那需要真基准，如 TL431）；
     · 不要用虚拟地给 ADC 的参考电压脚供电（除非它是精密基准）。
单电源设计的检查清单（漏一条就要返工）
  1. 运放是 RRIO 吗？输入共模要覆盖信号的最低电位（常常是 0V），输出要能到你要的最大值。
  2. 输出电压设计值留了 0.3V 余量吗？（3.3V 系统里最大设计到 3.0V）
  3. 需要双极性的信号，虚拟地做了吗？有去耦电容吗？被放大后的偏置误差算过吗？
  4. 虚拟地的内阻会不会被后级拉动？要不要跟随器缓冲？
  5. 交流耦合的高通截止频率算过吗（1/(2πRC)）？
  6. ADC 读数里那个固定的偏置偏移（2048 左右）在软件里减掉了吗？
  7. 信号有可能超过电源轨吗？超了要限流或钳位（CMOS 输入的 ESD 二极管会导通）。
一个很少被讲、但会直接毁掉精度的点：VCC 就是你的 ADC 参考

STM32 的 ADC 通常用 VDDA（也就是 3.3V 电源）当参考电压。这意味着：运放的偏置、运放的满量程、ADC 的满量程，全都挂在同一根 3.3V 上。

好处是「比例式测量」会自动抵消一部分电源漂移：如果信号和参考同时按比例变化，读数不变（比如用电位器分压、用电桥）。坏处是：如果运放电路把 VCC 的变化放大进输出（通过虚拟地或通过电阻分压基准），而 ADC 的参考也跟着变，误差会叠加或抵消，取决于电路的参考方式——这就是为什么用真基准芯片（如 REF3030，输出 3.000V）给运放偏置、而用 VDDA 做 ADC 参考时，会出现「电源一波动读数就飘」的问题。

工程结论：要么全部比例式（信号、偏置、ADC 参考都来自同一个 VCC，靠比例抵消），要么全部绝对式（信号和偏置都用真基准，ADC 也用真基准）。最怕「半比例式」——偏置来自 VCC、参考来自基准芯片，VCC 一动零点就动。

动手算一遍

这一节四道题，都是从「选电阻」算到「这颗芯片到底够不够用」。每道题我都按同一个格式走：已知 → 求 → 计算 → 判断 → 结论。你只要跟着算一遍，以后再遇到运放电路就知道该动哪几个数字了。

算之前先记住一张「误差账」表

所有直流误差都按同一个套路折算到输出端，你背这一张表就够了：

  • Vos 的贡献 = Vos × 噪声增益（1 + Rf/Rg）
  • Ib 的贡献 = Ib × 该输入端看到的等效外接电阻（加平衡电阻后残余 Ios × Rf）
  • 温漂的贡献 = dVos/dT × 噪声增益 × 温差
  • 电阻公差的贡献 = 增益误差 × 输出值（增益误差 ≈ 各电阻公差之和）
  • 共模的贡献 = Vic / 10(CMRR/20)（只在差分/同相结构里出现）

然后把所有误差按最坏情况直接相加。工程上不做平方和（RSS）也可以，最坏相加更保守，而且算起来不用计算器。

例 1　反相放大器：增益、带宽、失调误差，判断 GBW 够不够

题目

用 LM358（双电源 ±12V 供电）搭一个反相放大器：Rin = 2kΩ、Rf = 100kΩ，输入是 50mV 的直流信号。手册参数（按 TI LM358 数据手册）：Vos 最大 7mV、Ib 典型 20nA、Ios 典型 2nA、GBW 典型 1.1MHz、温漂典型 7µV/°C。

求：① 增益与输出；② 闭环带宽；③ 输出端的直流误差；④ 如果要做 1% 精度，这颗芯片够不够；⑤ 如果信号频率升到 10kHz，还需要换什么芯片。

【① 增益与输出】

    A = -Rf / Rin = -100k / 2k = -50

    Vout = A · Vin = -50 × 50mV = -2.5V

    检查饱和：±12V 供电，-2.5V 远在范围内 → 线性区，虚短成立，计算有效。✓

【② 闭环带宽：注意用「噪声增益」而不是「信号增益」】

    噪声增益 = 1 + Rf/Rin = 1 + 50 = 51

    f_-3dB = GBW / 噪声增益 = 1.1MHz / 51 ≈ 21.6kHz

    含义：输入 1kHz 时增益基本就是 50；输入 21.6kHz 时增益降到 35（-3dB）；
          输入 100kHz 时增益只剩 10 左右 —— 不是「没输出」，是「增益变小了」。

【③ 输出端的直流误差（三项相加）】

    项 1：输入失调电压
        Vout_err(Vos) = Vos × 噪声增益 = 7mV × 51 = 357mV
        ← 这一项就是全部误差的主因，占了 88%

    项 2：输入偏置电流（不加平衡电阻时）
        反相端看到的等效电阻 = Rin ∥ Rf = 2k ∥ 100k = 1.96kΩ
        Vout_err(Ib) ≈ Ib × Rf   （虚地点的电流全部由 Rf 提供）
                    = 20nA × 100kΩ = 2mV
        加一颗 R' = 1.96kΩ（取标称 2kΩ）到同相端后：
        残余误差 = Ios × Rf = 2nA × 100kΩ = 0.2mV

    项 3：电阻公差（假设用 1% 电阻）
        增益误差 ≈ 1% + 1% = 2% → 2.5V × 2% = 50mV

    总误差（最坏相加）= 357mV + 0.2mV + 50mV ≈ 407mV
    相对输出 -2.5V 的比例 = 407mV / 2.5V ≈ 16%
    ← 这个电路「增益是对的，但直流精度一塌糊涂」。

    换个说法更直观：Vos 折算到输入端就是 7mV，
    而你的信号只有 50mV —— 【误差是信号的 14%】。

【④ 判断：1% 精度够不够】

    目标：总误差 ≤ 输出的 1% = 25mV
    允许的 Vos = 25mV / 51 ≈ 0.49mV = 490uV

    对比：
        LM358   Vos 最大 7mV    → 需要 490uV，差 14 倍  ✗
        OP07C   Vos 最大 75uV   → 75uV × 51 = 3.8mV（0.15%）  ✓
        OPA333  Vos 最大 10uV   → 10uV × 51 = 0.51mV（0.02%） ✓

    注意 OP07 是双电源经典精密运放（GBW 只有 0.6MHz，更慢），
    在 ±12V 实验箱里很合适；OPA333 是单电源斩波运放，3.3V 系统里更合适。

【⑤ 判断：信号频率 10kHz 时 GBW 够不够】

    要在 10kHz 上保持增益 50（误差 1% 以内），经验上闭环带宽要
    留 5~10 倍余量，即需要带宽 ≥ 50 ~ 100kHz：

    需要的 GBW = 需要的带宽 × 噪声增益 = 100kHz × 51 = 5.1MHz

    对比：
        LM358   1.1MHz → 1.1M/51 = 21.6kHz   ✗（10kHz 时增益已明显衰减）
        TL072   3MHz   → 3M/51   = 58.8kHz   ✗（勉强，10kHz 时相移已有影响）
        OPA2350 38MHz  → 38M/51  = 745kHz    ✓（余量充足）

    另一条路：分两级放大，每级 7.5 倍（总 56 倍，用电阻配平到 50 倍）
        每级噪声增益 = 8.5 → 每级带宽 = 3MHz/8.5 = 353kHz（用 TL072）
        两级级联总带宽 ≈ 353kHz × 0.64 ≈ 226kHz
        ← 用两颗便宜的 TL072 达到了 226kHz，比单级 TL072（58.8kHz）好 4 倍。
        （0.64 是两级同带宽一阶系统级联的系数，来自 √(√2 - 1)）
结果数值说明
信号增益−50反相，输出 −2.5V
噪声增益51算带宽、算失调都用它
闭环带宽21.6kHz= 1.1MHz / 51
Vos 误差357mV占总误差的 88%
Ib 误差（加平衡电阻后）0.2mV加了 R′ = 2kΩ 之后可以忽略

这道题真正想让你记住的事

直流精度和带宽是两个独立的账，要分别算。LM358 的问题不在「增益算错了」，而在于：Vos 被噪声增益放大了 51 倍。增益越高，失调误差越大——这就是为什么「高增益小信号放大」是最考验运放选型的场合，也是为什么第 4 节里放大 60 倍的分流电阻电压必须用零漂移运放。

例 2　把 0~50mV 的分流电阻电压放大到 0~3.0V：零点误差与温漂有多大

题目

电机电流采样：分流电阻 Rshunt = 10mΩ，电流范围 0~5A，所以分流电阻上的电压是 0~50mV。用单电源 +3.3V 供电的同相放大器把它放大到 0~3.0V，送进 STM32 的 12 位 ADC（参考电压就是 VDDA = 3.3V）。

求：① 增益和电阻取值；② 为什么输出设计到 3.0V 而不是 3.3V；③ 分别用 LM358 和 OPA333 时的零点误差（折算成电流）；④ 温漂带来的漂移；⑤ 软件标定能救回多少。

【① 增益与电阻取值】

    需要的增益 A = 3.0V / 50mV = 60

    同相放大器：A = 1 + Rf/Rg = 60  →  Rf/Rg = 59

    取 Rg = 1.00kΩ（0.1% 精度）→ Rf = 59.0kΩ（E96 标称值里正好有 59.0k）
    实际增益 = 1 + 59.0/1.00 = 60.0
    满量程输出 = 50mV × 60.0 = 3.000V  ✓

    若手头只有 E24 标称值：Rf = 5.1k × 11.5? 不行，E24 里 59 附近的只有 56k 和 62k。
    用 62k / 1.05k? 也不方便。稳妥做法：
      Rf = 30k + 29k 串联，或者直接用 59k（E96 有），
      或者接受 Rf = 56k + Rg = 1k 时的增益 57（输出 2.85V，软件里按实测增益换算）。
    【关键点：增益误差 1% → 满量程误差 1%（5A 时差 50mA），所以这里的电阻至少要 0.1%。】

【② 为什么设计到 3.0V 而不是 3.3V（留 0.3V 余量 = 9%）】

    四个理由，每一个都能单独毁掉你的量程：
     1. 运放输出摆幅：即使标「轨到轨输出」的 RRO 运放，拉 1mA 时也离轨约 100mV
        （按 MCP6002 数据手册典型值），轻载 25mV。要输出 3.3V 是不可能的。
     2. 电源容差：3.3V 电源通常有 ±3% 容差（±100mV）。
        如果 VDDA 低到 3.2V，你的 3.3V 目标就已经超了。
     3. 基准/整机误差：ADC 用 VDDA 做参考，VDDA 本身也在动。
     4. 过载识别：留出 3.0~3.3V 这段，就能识别「电流超过 5A」；
        如果满量程顶到 3.3V，5A 和 6A 的读数都是 4095，你分不出来。

    反过来说：【如果你用了 LM358 而且设计输出 3.0V，那这个电路根本不工作】
    （LM358 在 3.3V 供电下 VOH 只有约 1.8V，输出会被削在 1.8V）。

【③ 零点误差（把输入失调电压折算成电流）】

    折算公式：误差电流 = (Vos × 增益) / 增益 / Rshunt = Vos / Rshunt

    【这是个非常漂亮的结论：折算到输入端的电流误差只跟 Vos 和 Rshunt 有关，
    跟你设了多大的增益无关！】（因为失调被放大多少倍，信号也被放大多少倍。）

        LM358： Vos 最大 7mV  →  7mV / 10mΩ = 0.70A
                → 满量程 5A 的 14%（零点一开就是 0.7A！）

        OPA333：Vos 最大 10uV →  10uV / 10mΩ = 0.001A = 1mA
                → 满量程的 0.02%

    两者相差 700 倍 —— 因为 Vos 相差 700 倍（7mV vs 10µV）。

    和 ADC 分辨率比一下：
        12 位 ADC，参考 3.3V → 1 LSB = 3.3V / 4096 = 0.806mV
        折算成电流（在输入端）= 0.806mV / 60 / 10mΩ = 1.34mA
    OPA333 的 1mA 零点误差 < 1.34mA 的 1 个 LSB
    → 【用 OPA333 时，零点误差已经小到「被 ADC 分辨率淹没」，不需要软件标定。】

【④ 温漂（标定救不了的那部分）】

    公式：漂移电流 = (dVos/dT × 温差) / Rshunt

    LM358： 7uV/°C × 60 = 0.42mV/°C（输出端）
            35°C 温差（25°C → 60°C）→ 输出漂 14.7mV
            折算电流 = 0.42mV/°C × 35 / 60 / 10mΩ = 24.5mA

    OPA333：0.05uV/°C × 60 = 3uV/°C
            35°C 温差 → 输出漂 0.105mV → 折算电流 0.175mA

    还有一笔账容易被忘掉：【分流电阻自己的温漂】。
    10mΩ 的合金电阻温度系数约 50ppm/°C（按常见精密分流电阻规格），
    温升 50°C → 阻值变化 0.25% → 5A 时的读数偏 12.5mA。
    这一项和 OPA333 的漂移是同一量级，所以【再好的运放也救不了烂分流电阻】。
    另外分流电阻一定要用【四线（开尔文）接法】：电压取样点必须在电阻本体上，
    不能和电流走线共用一段铜箔，否则走线电阻会被算进测量结果。

【⑤ 软件标定能救回多少】

    能救：【当前的固定失调】（上电时电机不转，采 100 次平均得到 offset）。
          对 LM358 来说，这一下就把 0.70A 的零点误差压到接近 0。
    救不了：
        · 温漂（板上温度一变，offset 就变了）；
        · 单颗芯片的失调随时间/温度的非线性变化；
        · 老化漂移（datasheet 里叫 long-term drift）。
    所以正确姿势是：
        · 用低 V_os + 低温漂的运放（这是根本解决办法）；
        · 同时做「上电标定」+ 必要时「停机标定」（电机停转瞬间再采一次）；
        · 对温度敏感的场合，把标定结果按温度分段存表，或者用零漂移运放直接省掉这件事。

顺手记住的选型直觉

做大增益小信号放大时，先问三个问题：① 这颗运放的 Vos 折算到输入是多少？② 它的温漂折算到输入是多少？③ 它的 Vos/温漂 和我的传感器满量程比，占几个百分点？例 2 的答案分别是 7mV / 0.42mV&per;°C / 14%——第三个数字直接判了 LM358 的死刑。

例 3　四电阻差分放大器：1% 失配让 CMRR 掉到多少 dB

题目

用四颗 1% 精度的电阻搭差分放大器测电机电流：R1 = R3 = 10kΩ、R2 = R4 = 100kΩ（理想增益 G = 10）。分流电阻上的差模信号满量程 50mV，共模电压是 12V 的电机电源（还在以 20kHz 上下跳）。

求：① 最坏情况下 CMRR 是多少 dB；② 12V 共模会漏出多少到输出；③ 这个误差相对满量程占多少；④ 为什么必须用集成差分放大器或 0.1% 电阻。

【① 先用通式看看「失配」是怎么进来的】

    四电阻差分放大器的输出通式（上一节推过）：

        Vout = V2 · [R4/(R3+R4)] · (1 + R2/R1)  -  V1 · (R2/R1)

    记  a = R2/R1                （反相支路的增益）
        k = R4/(R3+R4)           （同相支路的分压比）
        Acm = k · (1 + a) - a    （共模增益：把 V1 = V2 = Vcm 代进去的系数）

    理想情况下 k(1+a) = a，所以 Acm = 0，CMRR 无穷大。
    但电阻有 1% 公差，k(1+a) 和 a 就对不上了 —— 差值就是共模增益。

        CMRR = Ad / Acm     （Ad ≈ a，差模增益）

【② 最坏组合：四颗电阻同时往「错」的方向偏】

    让 R1 偏大、R2 偏小、R3 偏小、R4 偏大（这是让 Acm 最大的组合）：

        R1 = 10k × 1.01 = 10.1kΩ
        R2 = 100k × 0.99 = 99kΩ
        R3 = 10k × 0.99 = 9.9kΩ
        R4 = 100k × 1.01 = 101kΩ

        a = R2/R1 = 99 / 10.1 = 9.80198
        k = R4/(R3+R4) = 101 / (9.9 + 101) = 101/110.9 = 0.91073
        1 + a = 10.80198

        k · (1+a) = 0.91073 × 10.80198 = 9.83772
        Acm = 9.83772 - 9.80198 = 0.035738
        Ad  ≈ (a + k(1+a))/2 ≈ 9.82

        CMRR = 9.82 / 0.035738 ≈ 274.8 倍

        换算成 dB： 20 · log10(274.8) = 48.8 dB ≈ 【49 dB】

    用经验公式验算一下（结论一致，说明算对了）：
        CMRR ≈ (1 + G) / (4t)     G = 10, t = 0.01
             = 11 / 0.04 = 275 倍  →  48.8 dB  ✓ 完全吻合

    顺便看看增益为 1 的情况（四颗都用 10k）：
        CMRR ≈ (1 + 1)/(4 × 0.01) = 50 倍 = 【34 dB】
    ← 这就是「四颗 10k 电阻搭差分放大器」的真实水平：34dB。很差。

    每个数量级的电阻精度带来 +20dB：
        1%     → G=1 时 34dB，G=10 时 49dB
        0.1%   → G=1 时 54dB，G=10 时 69dB
        0.01%  → G=1 时 74dB，G=10 时 89dB   （这类配对电阻网络比一颗 INA240 还贵）

【③ 12V 共模漏出多少】

    共模增益 Acm = 1/CMRR = 1/274.8 = 0.00364

    输出端的共模误差 = 12V × 0.00364 = 43.7mV

    理想差模输出 = 50mV × 10 = 500mV

    【误差占比 = 43.7mV / 500mV = 8.7%】

    注意这只是「静态 12V」的情况。电机 PWM 时共模还有 12V 幅度、
    20kHz 的跳变，那个 dV/dt 会通过同样的 Acm 路径漏过来，
    再叠加电阻自身的寄生电感和 PCB 走线不对称 ——
    这就是现场 B 里「电机一转读数就乱跳」的完整机制。

【④ 要多少 CMRR 才够，以及为什么必须换方案】

    目标：共模误差 ≤ 满量程的 0.5% = 500mV × 0.5% = 2.5mV
    需要的 CMRR = 12V / 2.5mV = 4800 倍 = 【73.6 dB】

    用 G = 10 的四电阻结构达到 73.6dB 需要：
        (1+G)/(4t) = 4800  →  t = 11 / (4 × 4800) = 0.000573 = 【0.057%】
    这个精度等级的分立电阻：要么买不到，要么用昂贵的配对电阻网络。

    对比集成方案（按 INA240 数据手册典型值 CMRR = 132dB）：
        12V / 10^(132/20) = 12V / 3.98×10^6 = 3.0uV
        相对 500mV 满量程是 0.0006% —— 【完全可以忽略】。

    而且集成器件的优势不只是 CMRR：
        · 内部电阻同片同温，失配随温度的变化也被抵消（分立电阻做不到）；
        · 共模输入范围可以做到 -4V ~ 80V，直接挂在高边分流电阻上；
        · 增益在出厂时就修调好（20/50/100/200 V/V 可选），不用你配电阻；
        · 很多型号带增强的 PWM 抑制（对共模跳变有专门处理）。

【⑤ 结论】

    · 4 颗 1% 电阻 → CMRR 只有 34~49dB → 12V 共模漏出几十毫伏，
      而你的信号满量程才 500mV → 误差 8.7%，不可接受；
    · 想靠分立电阻达到 73dB，需要 0.057% 的电阻，成本超过专用芯片；
    · 【凡是「共模电压远大于差模信号」的场合（电流采样就是典型），
      一律用集成差分放大器 / 电流检测放大器，不要用四颗电阻硬凑。】
    · 分立四电阻结构仍然有用：共模很小（几伏以内）、精度要求一般、
      或者只需要「做减法搬电平」的场合，它便宜好用。

例 4　GBW 和 SR 谁先卡住你：两个频率都要算，取小的那个

题目

还是那颗 LM358（GBW 典型 1.1MHz、SR 典型 0.6V/µs，按 TI 数据手册）。这次要放大一个 3Vpp（峰值 1.5V）的正弦信号。

求：① 增益 60 倍时，信号频率最高能到多少；② 增益 1（跟随器）时能到多少；③ 为什么同一颗芯片两个答案差这么多；④ 如果要放 100kHz 的 3Vpp 信号，需要换什么芯片；⑤ 如果必须用便宜的芯片，能不能用两级放大的办法解决。

【① 增益 60 倍时：两个限制分别算一遍】

    限制 A（小信号，由 GBW 决定）：
        噪声增益 = 1 + Rf/Rg = 61
        f_GBW = GBW / 噪声增益 = 1.1MHz / 61 = 【18.0 kHz】

    限制 B（大信号，由 SR 决定）：
        正弦最大变化率 = 2π·f·A，要求 ≤ SR
        f_SR = SR / (2π·A) = 0.6×10^6 V/s / (2π × 1.5V) = 【63.7 kHz】

    取小的那个：【f_max = 18.0 kHz】   （GBW 先卡住）

【② 增益 1（跟随器）时】

    限制 A：跟随器的反馈系数 β = 1，闭环带宽 ≈ GBW = 1.1MHz
            （严格说噪声增益为 1，理论带宽就是 GBW）
    限制 B：SR 限制与增益无关，还是 63.7kHz

    取小的那个：【f_max = 63.7 kHz】   （这次是 SR 先卡住）

【③ 为什么同一颗芯片两个答案差 3.5 倍】

    因为两个限制「长得不一样」：
        · GBW 限制的带宽 = GBW / 噪声增益  ← 【增益越高，越容易卡】
        · SR 限制的带宽 = SR / (2π·A)      ← 【幅度越大，越容易卡】，与增益无关

    谁先卡，取决于「输出幅度」和「增益」的相对大小。算一下交叉点：
        令 GBW/噪声增益 = SR/(2π·A)
        A = SR × 噪声增益 / (2π × GBW)
          = 0.6×10^6 × 61 / (2π × 1.1×10^6) = 5.3V

    含义：增益 60 倍时，只有输出幅度超过 5.3V，SR 才会先卡住。
          而 3.3V 系统里输出最多 1.5V 峰值 —— 【永远轮不到 SR 说话，GBW 才是瓶颈。】
    反过来，跟随器里输出幅度可以接近电源（1.5V 峰值），
          此时 SR 的 63.7kHz 远小于 GBW 的 1.1MHz —— 【SR 才是瓶颈。】

    实用口诀：
        小信号 / 高增益  → 盯 GBW
        大信号 / 低增益  → 盯 SR
        不确定 → 两个都算，取小的

【④ 要放 100kHz、3Vpp 的信号，需要什么】

    需要的 GBW ≥ f × 噪声增益 = 100kHz × 61 = 【6.1 MHz】
    需要的 SR  ≥ 2π·f·A = 2π × 100k × 1.5 = 【0.94 V/us】

    对照（都是典型值）：
        LM358   1.1MHz / 0.6Vus → GBW 差 5.5 倍   ✗
        TL072   3MHz   / 13Vus  → GBW 3M/61 = 49kHz < 100kHz  ✗（SR 反而很宽裕）
        OPA2350 38MHz  / 22Vus  → 38M/61 = 623kHz ✓，SR 也够  ✓

    ← 注意 TL072：它的 SR 高达 13V/µs（是 LM358 的 20 倍），
      但 GBW 只有 3MHz，在 60 倍增益下仍然不够。
      【「SR 大的运放就是快运放」是错的，两个指标要分开看。】

【⑤ 便宜芯片能不能靠「两级放大」搞定】

    目标：总增益 60，每级增益 = √60 ≈ 7.75，取每级 8 倍（两级共 64 倍，
          在电阻上微调到 60：比如第一级 8 倍、第二级 7.5 倍）。

    用 TL072（GBW 3MHz）：
        每级噪声增益 = 1 + 7 = 8
        每级带宽 = 3MHz / 8 = 375 kHz
        两级级联的总带宽 ≈ 375kHz × 0.64 = 【240 kHz】

        （0.64 = √(√2 - 1)，两个相同的一阶系统级联后的带宽收缩系数）

    240kHz > 需要的 100kHz  ✓  用两颗便宜的 TL072 就解决了。

    SR 检查：第二级输出 3Vpp，需要 SR = 0.94V/µs，
             TL072 的 13V/µs 远远够用  ✓

    ← 这就是「分级放大」的价值：同样的 GBW 预算，分成两级后总带宽提高近 10 倍
      （单级 TL072 只有 49kHz，分两级后 240kHz）。
      代价是多一颗芯片、多一点噪声、多两个电阻，以及要注意两级的直流失调会叠加。

  2. 温度：温漂 × 噪声增益 × 工作温差，能不能接受？（例 2）

4.1　4~20mA 电流环到 ADC：工业现场最标准的一根线

压力变送器、温度变送器、液位计——工业现场的传感器几乎都用 4~20mA 通信。为什么不用 0~10V，也不用串口？三个理由：

  • 电流传输不怕线阻。几十米的双绞线上会有几欧姆的线阻，如果传电压，线阻上的压降直接变成误差；传电流则完全不受影响（只要环路电压够）。
  • 抗干扰能力强。长线上的电磁干扰主要变成感应电压，而电流环的接收端阻抗只有几百欧姆，感应电压几乎推不动电流。
  • 4mA 是「活的零点」。电流为 0mA 意味着断线或变送器没供电——你可以立刻判断出「这是故障，不是测量值」。如果零点用 0mA，你就分不清「测得 0」和「线断了」。

你的任务：把这根线上的电流变成一个 STM32 能读的电压。

4~20mA 接收的精度上限由采样电阻决定。150Ω 用 1% 精度 → 满量程误差 1%（相当于 0.16mA）；用 0.1% 精度 + 25ppm/°C 的金属膜电阻 → 0.1% 加上温漂，比 12 位 ADC（0.024%）的一点点误差都算不上。

反过来说：你用 12 位 ADC 精心算了一堆校准系数，却用了一颗 5% 的碳膜电阻当采样电阻，那整个系统的精度就只有 5%。模拟电路里，精度永远由最差的那一环决定。

4.2　电机电流采样：共模电压范围，最常被忽略的那个参数

用分流电阻（shunt）测电流，原理是欧姆定律：让电机的电流流过一颗已知的小电阻，测它两端的电压。问题是这颗电阻放在电路的哪个位置——这个位置决定了你的运放要承受多大的共模电压，也决定了你能不能做通用运放方案。

     ① 破坏了地回路：分流电阻把「电机的地」抬高了 50mV，

     ② 测不到对地短路：电机线短到 GND 时，电流不经过分流电阻，读数显示 0 ——
        而这正是你最需要保护的时刻。
     ③ H 桥 / 三相桥里，低边分流电阻的电流方向会随 PWM 变化，测到的不是负载电流。

【拓扑二：高边采样（分流电阻在电源和电机之间）——工业标配】

        +24V ────┬─────────────┐
                 │             │
            ┌────┴────┐        │
            │ R_shunt │ 10mΩ   │  ← 分流电阻在高端
            └────┬────┘        │
                 │           ┌─┴─┐
                 │           │ M │
                 │           └─┬─┘
                 │             │
                 │          ┌──┴──┐
                 │          │ 电机 │
                 │          └──┬──┘
                 │             │
                GND ───────────┘

   共模电压 ≈ 24V（整个电源电压，PWM 时还在 0~24V 之间跳）
   → 通用运放绝对不能用：输入端的绝对最大额定值通常只比电源高 0.3V，
     把 24V 接上去会损坏芯片
   → 必须用专用电流检测放大器（INA240、INA181、INA199、INA219 等）

   优点：
     ① 不破坏地回路，整机参考干净；
     ② 能检测「对地短路」这种最危险的情况；
     ③ 测到的是真正的负载电流（电机真正吃进去的电流）。

【拓扑三：专用电流检测放大器 / 数字功率监视器】

   · 模拟输出型（INA240、INA181、INA199）：
       内部激光修调电阻 + 固定增益（20/50/100/200 V/V 可选），
       共模范围 -4V ~ 80V，CMRR 120dB 以上，
       输出直接进 ADC —— 这是电机驱动板的标配做法。
       其中 INA240 还专门做了「增强 PWM 抑制」，
       对付共模在 0/24V 之间高频跳变的场合。

   · 数字输出型（INA219、INA226）：
       内部集成 12~16 位 ADC + 电流/功率计算，
       通过 I²C 直接读出「电流」和「电压」的数值。
       单片机端一行代码都不用算 —— 代价是采样速度慢（几百 Hz ~ 几 kHz），
       不适合做高频电流环控制，但做「电池电量计」「功耗监视」非常合适。
为什么「共模电压范围」比 CMRR 更常被忽略，也更致命

新手选运放时通常只查两个参数：GBW 和 Vos。但电流采样的第一道门槛是共模输入范围——它决定「这个电路能不能存在」，而 CMRR 只决定「测得准不准」。

具体对比（都是量级，具体数值看对应型号的数据手册）：

  • LM358：电源 +5V 时输入共模范围 0 ~ VCC−1.5V = 0~3.5V；输入端绝对最大额定值约为 VCC+0.3V。把 12V 接上去 = 烧芯片。
  • MCP6002（RRIO）：电源 5V 时输入范围约 0 ~ 5V，也就只能到电源轨。
  • INA240：电源 5V，但输入共模范围 −4V ~ 80V。这就是「专用」两个字的全部含义。

所以设计顺序应该是：先算共模电压 → 选拓扑 → 选满足共模范围的器件 → 最后才看 CMRR、带宽、精度。反过来做，画完 PCB 才发现器件扛不住，就只能改拓扑或加隔离，代价大得多。

【参数设计：24V / 5A 电机，双向电流（正转/反转/刹车）】

   1. 选分流电阻 R_shunt = 10mΩ（2512 封装合金电阻，2W 以上）
      满量程压降 = 5A × 10mΩ = 50mV
      功耗 = 5A² × 10mΩ = 250mW  ✓ 在 2W 电阻的安全范围内
      （压降不能太大：50mV 相对 24V 只有 0.2%，不会影响电机转矩；
        但如果选 100mΩ，250mV/2.5W 就开始影响转矩和发热了）

   2. 选增益 = 50（INA240A2 这类固定 50 V/V 的型号）
      满量程输出摆幅 = 50mV × 50 = 2.5V

   3. 双向测量：把 REF 引脚接 VCC/2（1.65V）
      · 正转 5A → 输出 1.65 + 1.25 = 2.90V
      · 电流 0   → 输出 1.65V
      · 反转 5A → 输出 1.65 - 1.25 = 0.40V
      → 全范围 0.40 ~ 2.90V，完美落在 0~3.3V 内，且两端都留了余量 ✓

   4. 分辨率检查：
      12 位 ADC，1 LSB = 3.3V/4096 = 0.806mV
      折算到电流 = 0.806mV / 50 / 10mΩ = 1.6mA
      → 5A 量程下分辨率约 0.03%，比大多数电机的电流纹波小得多 ✓

   5. 带宽检查：
      电流环控制带宽通常 1~10kHz，需要采样到 20kHz 以上；
      INA240 的 -3dB 带宽约 400kHz（按数据手册），远够 ✓
      如果用普通运放 + 四电阻方案，GBW 1MHz 在高增益下只有几十 kHz，
      而且 CMRR 在几十 kHz 上早就崩了 —— 这是又一个不能用通用运放的理由。

【开尔文（四线）接法：分流电阻必须这样接】

        ✗ 错误接法：电流走线和取样线共用一段铜箔
        ┌──────────────────────────────┐
        │  电流流入 →  ████████████  → 电流流出
        │                   │  │
        │                   └──┴──► 运放输入端（多算了铜箔电阻！）
        └──────────────────────────────┘
        铜箔电阻：1oz 铜、1mm 宽、10mm 长 ≈ 5mΩ —— 和你的分流电阻一个量级！

        ✓ 正确接法：取样点必须在电阻本体的焊盘内侧
        ┌───────────────┐        ┌───────────────┐
        │  电流流入      │        │      电流流出  │
        └───┬───────────┘        └───────────┬───┘
            │      ┌──────────────┐          │
            └──────┤   R_shunt    ├──────────┘
                   └──┬────────┬──┘
                      │        │
                      └────────┴──► 运放输入端（只测电阻本体上的压降）
        取样走线要「差分对」一样等长、并排、紧贴走，远离电感和大电流回路，
        并且从焊盘内侧引出（这就是「四线 / Kelvin 接法」）。
别忘了和 PWM 同步采样

电机电流不是直流，而是被 PWM 斩成一个个斜坡。你用软件随便找个时刻去读 ADC，读到的可能是峰值、可能是谷值、也可能是开关瞬间的尖刺——三种情况下的读数能差一倍以上。

标准做法：用定时器在 PWM 计数器的中心点触发 ADC 转换（STM32 里就是把 ADC 的外部触发源设成某个 TIM 的 TRGO），并把运放/电流检测放大器的输出做一点 RC 滤波。这样每次都在波形的同一相位采样，电流值才具有可比性。这个「定时器触发 ADC」的配置，比运放型号对控制效果的影响更大。

4.3　高阻传感器接 STM32 的 ADC：为什么必须加跟随器

这是现场 C 那件事的完整答案。先把 STM32 的 ADC 输入端「看清楚」——它不是理想电压表，而是一个每次采样都要给一只小电容充电的开关电路。

【STM32F103 ADC 输入端的等效模型（按数据手册典型值）】

   外部信号源                    芯片内部
   ┌──────────┐     R_ain     ┌─────/\/\/\──┬──────┐
   │ 传感器    ├────/\/\/\────┤   R_adc     │      │
   │ (Rs 高)  │   外部源阻抗   │   约 1kΩ    │  ┌───┴───┐
   └──────────┘               │             │  │ C_adc │ 约 8pF
                              │             │  │ 采样  │
                              │             │  └───┬───┘
                              │             │      │
                              │            === 开关 │
                              │             │      │
                             GND ───────────┴──────┘

   采样瞬间：开关闭合，C_adc 要在「采样时间」内被充到被测电压。
   要充到 12 位精度（误差 < 1/2 LSB），需要约 9 个时间常数：
       τ = (R_adc + R_ain) × C_adc       充电时间 Ts ≥ 9τ = 9 × R × 8pF

   ┌──────────────────────────────────────────┬────────────────┬────────────────────────┐
   │ 采样时间设置                             │ Ts             │ 允许的外部源阻抗上限   │
   ├──────────────────────────────────────────┼────────────────┼────────────────────────┤
   │ 1.5 周期（14MHz 最快）                   │ 107 ns         │ ≈ 0.4kΩ                │
   │ 7.5 周期                                 │ 536 ns         │ ≈ 6kΩ                  │
   │ 55.5 周期（手册给出保证值的最后一档）    │ 3.96 µs        │ ≈ 50kΩ                 │
   │ 71.5 / 239.5 周期                        │ 5.11 / 17.1 µs │ 手册未给（NA）         │
   └──────────────────────────────────────────┴────────────────┴────────────────────────┘
   （推导：R ≤ Ts/(9 × 8pF)；表格右侧的量级与 STM32F103
     数据手册给出的最大外部阻抗一致）

   【50kΩ 是手册给出的 R_AIN 绝对上限（R_AIN Max），与采样时间无关；采样时间再长也不能超过它。】

【pH 电极的数字：差了三个数量级】

   pH 电极（玻璃电极）的内阻：几十 MΩ 到上千 MΩ（典型 100MΩ）
   100MΩ / 50kΩ = 2000 倍  ← 就算采样时间拉到最长，也差 2000 倍
   算时间常数：100MΩ × 8pF = 0.8ms，而最长的一档（239.5 周期）也只有 17.1µs
   → C_adc 只能充到理论值的 0.5%（按 55.5 周期）~ 2.1%（按 239.5 周期），读数必然接近 0。

   而且你的万用表也在骗你：手持万用表的输入阻抗通常是 10MΩ，
   接上去也在加载这个 100MΩ 的源（读数偏低），
   而 pH 计专用输入端的输入阻抗是 10^12Ω 以上。
   → 【「万用表量着有 400mV」这件事本身就不能作为判据。】

【解法一：电压跟随器（最通用）】

   pH 电极 ──┬──►[ RRIO 跟随器 ]──┬──/\/\/\──┬──► ADC
   （100MΩ） │    Ib 必须 pA 级   │   1kΩ   │
             │                    │         === 10nF
            屏蔽层接地 ────────────┘         │
                                            GND

   关键参数（按 100MΩ 源阻抗折算）：
     · I_b 必须极小：
         LM358（20nA）→ 20nA × 100MΩ = 【2V 误差】，完全不能用
         TL072（5pA） → 5pA × 100MΩ = 0.5mV
         OPA333（70pA，按手册最大值）→ 70pA × 100MΩ = 7mV
         LMP7721（3fA）→ 3fA × 100MΩ = 0.3µV   ✓ 真正的 pH 级方案
     · 输入端要能处理 pH 电极的输出范围：
         pH 7 时输出 0mV，每偏离 1 个 pH 约 ±59mV（25°C）
         测 pH 0~14 → 输出约 -414mV ~ +414mV  ← 有负电压！
       → 要么用双电源（±2.5V），要么把电极「抬」到 VCC/2 虚拟地上。
     · CMRR/共模范围：单电源下输入共模 = VCC/2 附近，RRIO 运放没问题。
     · 输入保护：串 1MΩ 限流 + 钳位二极管（pH 电极带电时不要热插拔）。
     · PCB 细节：100MΩ 节点上的漏电流比运放的 I_b 还大！
         输入走线必须短、加保护环（guard ring，用同电位的缓冲输出包围输入节点）、
         焊完后用无水乙醇清洗助焊剂残留、不要用普通 FR4 上的潮湿污渍当绝缘体。

【解法二：跨阻放大器（光电二极管专用）】

   光电二极管输出的是【电流】（几 nA ~ 几 µA），不是电压，
   所以要用「跨阻放大器」（TIA）：把电流转成电压。

                     Rf (1MΩ)
              ┌─────/\/\/\─────┐
              │    ┌──||──┐    │     Cf 2~5pF（必须加！）
              │    └──────┘    │
              │                │
   光电二极管 ─┴── (-)\         │
   （反偏或零偏）     \        │
                      \_______┴──── Vout = -I_ph × Rf
                      /
                  (+)/ 接 VCC/2 或 GND

   例：光电流 1µA，Rf = 1MΩ → Vout = 1V
       Rf 越大，灵敏度越高，但带宽越低、越容易振荡。

   Cf 为什么必须加：Rf 与光电二极管的结电容 Cin 会形成极点，
   相位裕度不够就振荡。经验公式（按典型值估算）：
       Cf ≥ √( Cin / (2π · Rf · GBW) )
   代入 Cin = 10pF、Rf = 1MΩ、GBW = 1MHz：
       Cf ≥ √( 10pF / (2π × 10^6 × 10^6) ) ≈ 1.3pF  → 取 2~5pF
   此时带宽 ≈ 1/(2π·Rf·Cf) = 1/(2π×1MΩ×3pF) ≈ 53kHz
   【这就是「用一个电容换稳定」的经典例子。】

【解法三：实在不想加运放，就把采样时间拉长】

   如果信号源阻抗只有几 kΩ（比如电位器分压、NTC 分压），
   其实不需要运放：把 ADC 的采样时间设成最长的 239.5 周期（F1 上），
   并在输入端并一颗 10nF 的电容做「电荷池」，就能采得比较准。
   这颗电容的作用是：在采样瞬间提供电荷，把「对 8pF 充电」变成
   「对 10nF + 8pF 充电」，源阻抗的影响被削弱约 1000 倍。
   【但这个办法只适用于「信号变化很慢」的场合】（NTC 测温正合适），
   而且电容本身会引入建立时间，快速变化的信号会被拖慢。
信号源源阻抗量级能不能直连 ADC正确做法
电位器分压几 kΩ可以（采样时间拉长）并 10nF 电容即可
NTC 分压几 kΩ可以并 10nF 电容，软件查表
运放输出（已调理）< 1Ω（闭环）可以串 100Ω，必要时加 RC
4~20mA 采样电阻150Ω可以，但建议缓冲跟随器 + RC（4.1 节）
pH 电极 / 玻璃电极10MΩ ~ 1000MΩ绝对不行超低 Ib 跟随器（fA~pA 级）+ 保护环
光电二极管电流源（等效阻抗极高）不行跨阻放大器 + Cf
压电片 / 电荷源等效阻抗极高不行电荷放大器（积分器结构）

4.4　软件这一半：零点标定、VDDA 校准与换算

硬件做到位之后，剩下的误差主要来自两处：运放的固定失调（可以标定掉）和VDDA 不是精确的 3.3V（可以用内部基准反推）。下面这段代码就是这两件事的具体做法，可以直接拿去改。

/* ============================================================
 * 电流采样：ADC 读取 + 滑动平均 + 零点标定 + VDDA 校准
 * 硬件：10mΩ 分流电阻 + 增益 50 的电流检测放大器（双向，REF = VCC/2）
 *       STM32F103，12 位 ADC，VDDA 标称 3.3V
 * ============================================================ */
#include "stm32f1xx_hal.h"
#include <stdint.h>

#define ADC_MAX_CODE     4095.0f      /* 12 位 ADC 满码值 */
#define VREFINT_CAL_ADDR ((uint16_t *)0x1FFFF7BA)  /* F1 的 VREFINT 出厂校准值 */
#define VREFINT_CAL_VREF 3300U        /* 出厂校准时 VDDA = 3300mV */

#define AMP_GAIN         50.0f        /* 电流检测放大器的固定增益 V/V */
#define R_SHUNT          0.010f       /* 分流电阻 10mΩ */
#define ADC_VREF_NOMINAL 3.300f       /* 标称参考电压，仅作兜底 */

static float s_vdda  = ADC_VREF_NOMINAL;  /* 实测 VDDA（V），开机校准一次 */
static float s_zero  = 2048.0f;           /* 零点码值（对应 0A），标定得到 */

/* ---------- 1. 用内部基准反推 VDDA 的真实值 ----------
 * 原理：VREFINT 是一个内部 1.20V 左右的基准，出厂时在 VDDA = 3.300V
 *       条件下测过一次，结果存在 0x1FFFF7BA。
 *       现在用它测出来的码值，就能反推出当前 VDDA 到底是多少伏。
 *       这样即使你的 3.3V 实际是 3.22V，换算也不会差 2.4%。        */
float adc_calibrate_vdda(ADC_HandleTypeDef *hadc)
{
    uint32_t raw;
    uint32_t cal = *(VREFINT_CAL_ADDR);   /* 出厂校准码值 */

    /* 采样内部基准通道（F1 上是 ADC_CHANNEL_VREFINT，需要较长采样时间） */
    HAL_ADC_Start(hadc);
    HAL_ADC_PollForConversion(hadc, 10);
    raw = HAL_ADC_GetValue(hadc);
    HAL_ADC_Stop(hadc);

    if (raw == 0) {                       /* 读失败就退回标称值 */
        s_vdda = ADC_VREF_NOMINAL;
        return s_vdda;
    }
    /* VDDA = 3.300V × 校准码值 / 当前码值 */
    s_vdda = (float)VREFINT_CAL_VREF * (float)cal / (float)raw / 1000.0f;
    return s_vdda;
}

/* ---------- 2. 读一次 ADC 并做 32 次滑动平均 ----------
 * 电机 PWM 场合建议由定时器触发转换（见 4.2 节），
 * 这里用阻塞式轮询演示，实际项目里换成 DMA + 定时器触发更好。 */
float adc_read_average(ADC_HandleTypeDef *hadc, uint32_t channel)
{
    ADC_ChannelConfTypeDef cfg = {0};
    uint32_t sum = 0;

    cfg.Channel      = channel;
    cfg.Rank         = ADC_REGULAR_RANK_1;
    cfg.SamplingTime = ADC_SAMPLETIME_55CYCLES_5;  /* 源阻抗大就取最长 */
    HAL_ADC_ConfigChannel(hadc, &cfg);

    for (int i = 0; i < 32; i++) {
        HAL_ADC_Start(hadc);
        HAL_ADC_PollForConversion(hadc, 10);
        sum += HAL_ADC_GetValue(hadc);
        HAL_ADC_Stop(hadc);
    }
    return (float)sum / 32.0f;            /* 平均后噪声降 √32 ≈ 5.7 倍 */
}

/* ---------- 3. 零点标定：电机必须处于「确定不转」的状态 ----------
 *  这一步能把运放的 Vos 误差整体消掉：
 *    LM358（Vos 最大 7mV）在 10mΩ 分流电阻上等效 0.70A 的零点误差，
 *    标定之后残差只剩噪声和不随时间变化的量化误差。
 *  注意：标定消不掉温漂，温度变了要重新标。                        */
void current_calibrate_zero(ADC_HandleTypeDef *hadc, uint32_t channel)
{
    /* 建议：连续采 10 组、每组 32 次，取平均，避开刚上电的抖动 */
    float acc = 0.0f;
    for (int i = 0; i < 10; i++) {
        acc += adc_read_average(hadc, channel);
    }
    s_zero = acc / 10.0f;
}

/* ---------- 4. 把 ADC 码值换算成电流（安培）---------- */
float current_get_amps(ADC_HandleTypeDef *hadc, uint32_t channel)
{
    float code = adc_read_average(hadc, channel);

    /* 码值 → 电压 */
    float v_out = code / ADC_MAX_CODE * s_vdda;

    /* 减掉零点电压（零点电压 = 标定码值对应的电压，VCC/2 附近） */
    float v_zero = s_zero / ADC_MAX_CODE * s_vdda;
    float v_diff = v_out - v_zero;

    /* 电压 → 电流：先除以放大器增益，再除以分流电阻 */
    return v_diff / AMP_GAIN / R_SHUNT;   /* 单位：A，正负号表示方向 */
}

/* 使用示例：
 *   adc_calibrate_vdda(&hadc1);                  // 开机：校准参考电压
 *   // ……确保电机停转、电流为 0……
 *   current_calibrate_zero(&hadc1, ADC_CHANNEL_0); // 开机：标定零点
 *   float i = current_get_amps(&hadc1, ADC_CHANNEL_0);
 *   if (i > 6.0f) { motor_shutdown(); }           // 过流保护
 */
这段代码里三个容易被忽略的点
  1. VDDA 不是 3.300V。USB 供电时它可能是 3.15V，电池供电时更低。如果你在代码里写死 3.3V，那么所有测量值都会差 2~5%，而且这个误差会随供电方式变化——用内部 VREFINT 反推一次就能消掉，成本为零。这是最好赚的一笔精度。
  2. 零点标定是「必须做」而不是「可选」。例 2 算过，LM358 的失调在 10mΩ 上等效 0.70A；OPA333 只有 1mA。前者不做标定根本没法用，后者不做也没关系——但两种情况下做一次标定都不亏，因为它同时消掉了分流电阻的初始偏差和放大器的增益误差带来的零点偏移。
  3. 标定的前提是「确定电流为 0」。电机惯性滑行、H 桥下管还导通的瞬间，电流并不为零。要么在断电后延时再标定，要么用「上一次停机时的读数」做基准。如果标定时的电流不是 0，你就把那个电流当成了零点——这比不标定更糟。
把这一节的做法浓缩成一张接线流程
  1. 先问信号是什么：电压源还是电流源？源阻抗多大？共模电压多少？有没有负电压？
  2. 再定拓扑：以地为参考的小信号用同相放大；高阻源用跟随器/仪表放大器；有共模用差分/电流检测放大器；电流源用跨阻放大器。
  3. 然后算六笔账（第 3 节末的检查表）：直流精度、温漂、偏置电流、GBW、SR、电压边界。
  4. 加保护和滤波：串限流电阻、钳位二极管、RC 低通，位置尽量靠近单片机的引脚。
  5. 最后交给软件：VDDA 校准 + 零点标定 + 滑动平均 + 定时器同步采样。

这里面第 3 步是最容易被跳过、也最决定成败的一步。前两步画出来的电路图，在纸面上几乎都是对的；是第 3 步的那几个数字，决定了它在你的板子上能不能用。

常见误解与坑

下面十条，每一条我都写成「错误认知 → 为什么错 → 正确做法」的形式。它们大多不是「知识不够」造成的，而是「想当然」造成的——我自己和身边的同学都踩过。

坑 1　「运放就是用来放大的」

为什么错：在单片机项目里，放大只是运放功能的一小部分。你最常需要它做的是阻抗变换（跟随器）、电平搬移（加偏置/做减法）、差分取差（抑制共模）。这三个功能里有两个半跟「放大」没关系。

正确做法：看别人的原理图时，先问一句「这个运放在这里做什么」。跟随器看两个输入端是不是接在一起；加法器数有几个输入电阻；差分放大器看两个输入端是不是都接了信号。认出功能，参数该查哪几个就自然清楚了。

坑 2　「虚短虚断是万能公式，套上就能算」

为什么错：虚短有三个前提——有负反馈、没饱和、共模在范围内。少任何一个结论都会差得离谱：正反馈时输出贴死在某一轨；饱和时输出是电源轨不是公式值；共模超范围时运放根本不按你写的规律工作。

正确做法：算完一定要做「二看饱和」——把算出来的 Vout 和电源范围比一下。超出就说明你的电路饱和了，此时正确的结果是 VOH 或 VOL。另外单电源电路还要检查输入共模是否落在手册范围内（例如 LM358 在 +3.3V 时只有 0~1.8V）。

坑 3　「增益算对了，电路就设计对了」

为什么错：增益公式是理想运放的结论，它完全没有包含 Vos、Ib、温漂、电阻公差。例 1 里增益算得一丝不差（−50），可是输出端的直流误差有 407mV（16%）——因为 Vos 被噪声增益放大了 51 倍。

正确做法：增益算完，紧接着算一笔「误差账」：Vos × 噪声增益、温漂 × 噪声增益 × 温差、Ib × 等效电阻，再把它们和信号满量程比一下。任何一项超过信号 1%，都要换芯片或改结构。

坑 4　「同相放大器输入阻抗高，所以接什么传感器都行」

为什么错：同相结构（和跟随器）的两个输入端电位都等于 Vin，所以 Vin 必须落在运放的共模输入范围内。LM358 在 +3.3V 供电时共模上限只有约 1.8V——你想用它缓冲一个 3.0V 的基准，输出会卡在 1.8V 附近不动，看起来像「芯片坏了」。

正确做法：单电源系统里，凡是输入或输出要靠近 0V 或 VCC 的场合，一律选 RRIO（轨到轨输入输出）运放，如 MCP6002、TLV9002、OPA333。选型时把「输入共模范围」写在第一行检查。

坑 5　「换成轨到轨运放，输出就能到 3.3V」

为什么错：「轨到轨输出」不等于输出等于电源轨。轻载时离轨约 25mV，拉 1mA 时约 100mV，拉 10mA 时可能到 300~500mV（按常见 RRO 运放数据手册的典型量级）。而且灌电流和拉电流的离轨程度通常不一样。

正确做法：3.3V 系统里把输出电压设计到 3.0V 就停，留 0.3V（9%）余量。这段余量同时容纳了：运放离轨、电源容差、基准误差、温漂，还能用来识别过载（超过 3.0V 就是过流）。

坑 6　「四颗一样的电阻就是差分放大器，能测电流」

为什么错：四电阻差分放大器的 CMRR 完全由电阻匹配决定：CMRR ≈ (1+G)/(4t)。1% 电阻、G=1 时只有 34dB（50 倍），G=10 时 49dB。12V 共模会漏出 43.7mV，而信号满量程可能才 500mV——误差 8.7%。

正确做法：共模远大于差模的场合（电流采样就是典型），用集成差分放大器或专用电流检测放大器（INA240、INA181、INA199），它们的内部电阻同片同温、激光修调，CMRR 可以到 120dB 以上。分立四电阻结构只在「共模几伏以内、精度要求一般」时才用。

坑 7　「要测 12V 上的电流，用 5V 运放串两个大电阻分压一下就行」

为什么错：运放输入端的绝对最大额定值通常只比电源高 0.3V 左右。把 12V（哪怕经过分压）加到 5V 运放的输入端，很可能超过这个界线。这不是「测不准」，是「芯片会坏」——而且它可能今天不坏、明天才坏。

正确做法：先分清「共模电压」和「差模信号」。高共模场合只有两条正路：用专用电流检测放大器（共模范围 −4V~80V，如 INA240），或者用隔离方案（隔离放大器/霍尔电流传感器）。分压只能降低电压幅度，并不能让运放「浮」在 12V 上。

坑 8　「LM358 是万能的，实验室都用它」

为什么错：LM358 是 1970 年代的双电源/宽压设计，在 3.3V 单电源下三条硬伤同时出现：① 输出上不到 1.8V 以上；② 输入共模范围只有 0~1.8V；③ Vos 最大 7mV、Ib 20nA，做高增益小信号放大时误差惊人。它在 ±5V 以上、增益不高、精度要求不高的场合是很好用的廉价运放，但恰好不符合现在「3.3V 单电源 + 小信号」的主流需求。

正确做法：3.3V 单电源项目的默认选择是 MCP6002 / TLV9002（RRIO、便宜、1MHz）或需要精度时 OPA333。要双电源宽压实验时 LM358/TL072 仍然合适。选型永远跟着电源和信号走，别跟着习惯走。

坑 9　「积分器和微分器是一对，可以互相替换」

为什么错：它们的噪声特性完全相反。积分器增益 1/(2πfRC)，频率越高增益越小（低通，抗噪声）；微分器增益 2πfRC，频率越高增益越大（高通，每十倍频程 +20dB，等于给噪声装了放大器）。而且纯积分器的直流增益无穷大，失调电压会被一直积分，输出慢慢爬到电源轨卡死。

正确做法：积分器要用，但必须在电容旁并联一颗大电阻限制直流增益；微分器做边沿检测时，输入串一颗小电阻限制高频增益，并在反馈电阻上并小电容做低通。工程上「纯微分器」几乎没有人直接用。

坑 10　「运放输出直接接 ADC 就行，中间不用加东西」

为什么错：ADC 输入不是高阻电压表，它每次采样都要给内部采样电容（STM32F103 约 8pF）充放电，还会把开关电荷注入回来。运放输出直接接上去，轻则读数偏差，重则看到振铃和偶发的错误码；如果运放输出还接了长电缆或大电容，更可能直接振荡（容性负载）。

正确做法：运放输出和 ADC 引脚之间串一颗 100Ω 左右的电阻（隔离容性负载、限制注入电流），需要抗混叠时再加一级 RC（如 1kΩ + 100nF，fc ≈ 1.6kHz）；如果输出要接电缆，串 50~100Ω 做隔离。另外别忘了采样时间要和源阻抗匹配（4.3 节那张表）。

还有两条「不是坑但能救命」的补充

其一：运放不能当比较器用（反过来也一样）。运放做比较器的问题是速度慢（内部补偿让它不能快速翻转）、输出摆幅受限，而且输出端没有专门的逻辑电平驱动能力；有的运放还会在输入端差压较大时出现相位反转。比较器做放大的问题更根本：它故意不加负反馈，虚短虚断完全不成立。下一篇讲比较器时会详细说这件事。

其二：未使用的运放通道不要悬空。一颗双运放只用了一个通道时，另一个通道的输入端如果悬空，可能在电源轨之间来回振荡，干扰旁边正在工作的通道，还会多耗电。正确做法是把它的同相端接 VCC/2（或 GND）、反相端接输出，做成一个「接地跟随器」；或者干脆买一颗单运放。

小结与自检

这一篇的核心，其实就三句话：

三句话总结

一是：两条规则推一切。虚断（输入端不吸电流）+ 虚短（两端电位相等，前提是负反馈、没饱和、共模在范围内），就能推出反相、同相、跟随器、加法器、差分、积分、微分全部公式，不需要背。

二是：理想电路决定功能，非理想参数决定成败。电阻网络决定「它是放大 10 倍还是做减法」；而 Vos、温漂、Ib、GBW、SR、共模范围、输出摆幅，决定这个电路在你手里到底能不能用。

三是：单片机系统的运放，八成不是在做放大。跟随器做阻抗变换、差分放大器取差抗共模、加法器搬电平——这才是 ADC 前端真正在做的事。

要点清单

  • 运放 = 高开环增益差分放大器。Aol 有 105 以上，线性区只有几百微伏宽，所以开环必然饱和，必须加负反馈。
  • 负反馈把增益交给电阻。Acl = Aol/(1+Aolβ) ≈ 1/β，只要 Aolβ 够大，闭环增益就几乎与芯片无关。
  • 虚断：流入输入端的电流 ≈ 0，可以随便对节点写 KCL。
  • 虚短：V+ ≈ V−，因为差值 = Vout/Aol 只有几十微伏。前提：负反馈、未饱和、共模在范围内。
  • 反相放大器：A = −Rf/Rin；输入端是虚地，输入电阻 = Rin（低），共模恒为 0（不挑共模范围），单电源下不适合放大小信号。
  • 同相放大器：A = 1 + Rf/Rg；输入电阻极高，但共模跟随输入，必须落在共模范围内。
  • 电压跟随器：A = 1；输出电阻 = Ro/(1+Aolβ) 可低到毫欧，用来做阻抗变换、驱动 ADC 和容性负载。
  • 加法器：Vout = −Rf(V1/R1 + V2/R2 + …)，单片机里主要用来搬电平和加偏置。
  • 差分放大器：四电阻匹配时 Vout = (R2/R1)(V2 − V1)；缺点是输入阻抗低、CMRR 靠电阻匹配（1% → 34~49dB）。
  • 仪表放大器：两个缓冲 + 一个差分，输入阻抗极高、CMRR 靠内部匹配（100dB 以上），增益由一颗 RG 设定（INA128：G = 1 + 50kΩ/RG）。
  • 积分器：反馈电容，Vout = −(1/RC)∫Vindt，增益随频率下降（抗噪声），但直流增益无穷 → 必须并大电阻。
  • 微分器：输入电容，增益随频率上升（+20dB/decade）→ 放大高频噪声，工程上必须串电阻限制高频增益。
  • Vos 与温漂：误差 = Vos × 噪声增益；标定能消掉当前的 Vos，消不掉温漂。折算到输入端的误差与增益无关（例 2 的 7mV/10mΩ = 0.7A）。
  • Ib：BJT 输入 nA 级、CMOS pA 级、JFET pA 级；高阻源上 Ib × Rsource 是主要误差（20nA × 100MΩ = 2V）。
  • GBW：闭环带宽 = GBW / 噪声增益（小信号限制）；SR：满幅带宽 = SR/(2πA)（大信号限制）。两个都算，取小的。
  • 输出摆幅：LM358 在 5V 下 VOH ≈ 3.5V（离轨 1.5V），3.3V 下只剩约 1.8V；RRO 运放轻载离轨约 25mV、带载更差。设计留 0.3V 余量。
  • 单位增益稳定性：通用运放完全补偿（任何增益都稳定）；OP37、LM318 这类标「stable for gain ≥ 5」的芯片不能做跟随器。
  • 单电源 + 虚拟地：把「地」抬到 VCC/2 才能放大双极性信号；虚拟地必须有去耦电容，它的误差会被噪声增益放大，最好用跟随器缓冲或用真基准。
  • 电流采样三拓扑：低边（共模接近 0V，便宜，但破坏地回路、测不到短路）；高边（共模 = 电源电压，必须用专用电流检测放大器）；专用器件（INA240 −4~80V 共模、CMRR 120dB 以上、固定增益）。
  • ADC 前端的三件事：串 100Ω 隔离、RC 抗混叠、采样时间与源阻抗匹配（STM32F103 在最长采样时间下也只允许 50kΩ 量级）。

自测题（附答案）

先自己算，再对答案。这六道题覆盖了全篇的核心，能全做对说明你已经可以独立设计运放电路了。

题 1　反相放大器的基础量

用一颗 GBW = 1MHz 的运放搭反相放大器：Rin = 4.7kΩ、Rf = 47kΩ，输入 20mV。求信号增益、输出、噪声增益、闭环带宽。

答：信号增益 A = −47k/4.7k = −10；输出 Vout = −10 × 20mV = −200mV；噪声增益 = 1 + 10 = 11；闭环带宽 = GBW / 噪声增益 = 1MHz / 11 ≈ 91kHz。
注意：带宽要用噪声增益 11，不是信号增益 10。两者只差 9%，但增益为 1 时差别就是 2 倍（GBW/2 vs GBW），所以习惯上永远用噪声增益。

题 2　跟随器增益是 1，为什么还要用它

电压跟随器的增益等于 1，输入输出一样大，它到底做了什么？

答：做阻抗变换。输入电阻极高（运放自己的 Rid，106~1012Ω），而闭环输出电阻 = Ro/(1+Aolβ) 可以低到毫欧级。所以它把一个「高阻、带不动负载」的信号源，变成了「低阻、能驱动 ADC 采样电容和容性负载」的输出。
典型场景：100MΩ 的 pH 电极接 STM32 的 ADC，采样电容 8pF 只给它十几微秒充电时间，直连时读数接近 0；加一级跟随器后源阻抗降到 1Ω 以下，立刻就准了。

题 3　单电源下的共模陷阱

用 LM358、+3.3V 单电源搭一个同相放大器（增益 2），输入 2.5V。输出应该是多少？实际会是多少？为什么？

答：按公式应该输出 5.0V——但电源只有 3.3V，所以首先必然饱和（虚短失效）。而且更早一步就已经出问题了：LM358 在 +3.3V 供电时共模输入范围只有约 0~1.8V，输入 2.5V 超出共模范围，运放根本不工作在正常状态，输出可能贴在低轨附近不动，或者行为完全不可预测。
正确做法：换 RRIO 运放（MCP6002 等），并把目标输出降到 3.0V 以内。这道题的两个错误点（饱和、共模超范围）是单电源电路里最常见的死法。

题 4　四电阻差分放大器的 CMRR

用四颗 10kΩ、1% 的电阻搭差分放大器（增益 = 1）。它的 CMRR 大概是多少 dB？如果输入共模是 5V，会漏出多少到输出？

答：CMRR ≈ (1 + G)/(4t) = (1+1)/(4×0.01) = 50 倍 = 34dB。
共模增益 = 1/50 = 0.02，所以 5V 共模会漏出 5V × 0.02 = 100mV 到输出。
这就是「1% 电阻的四电阻差分放大器不可用于电流采样」的量化理由。想改善：每提高一个数量级的电阻精度（1% → 0.1%）只能多 20dB，要 70dB 就得用 0.05% 级别的电阻，成本远超一颗 INA240。

题 5　失调误差折算成电流

分流电阻 10mΩ，用 60 倍增益放大后送 ADC。运放的 Vos = 7mV。零点误差相当于多少安培？如果换成 Vos = 10µV 的运放呢？

答：折算公式：误差电流 = Vos / Rshunt（与增益无关，因为失调和信号被放大了同样的倍数）。
7mV / 10mΩ = 0.70A（满量程 5A 的 14%）；
10µV / 10mΩ = 0.001A = 1mA（满量程的 0.02%，已经小于 12 位 ADC 的 1 LSB 折算值 1.34mA）。
两者相差 700 倍，正好等于 Vos 相差的 700 倍。这就是「小信号大增益放大必须用零漂移运放」的全部算术。

题 6　GBW 还是 SR 先卡住

要放大一个 100kHz、3Vpp（峰值 1.5V）的正弦信号，增益 60 倍。需要一个至少多少 GBW、多少 SR 的运放？LM358（1.1MHz / 0.6V/µs）和 TL072（3MHz / 13V/µs）分别够不够？

答：GBW 需求 = 100kHz × 噪声增益 61 = 6.1MHz；SR 需求 = 2π × 100k × 1.5 = 0.94V/µs。
LM358：GBW 1.1MHz（差 5.5 倍）✗，SR 0.6V/µs（差 1.6 倍）✗ —— 两个都不够。
TL072：GBW 3MHz → 3MHz/61 = 49kHz < 100kHz ✗，但 SR 13V/µs 远远够 ✓。
注意这个反差：TL072 的 SR 是 LM358 的 20 倍以上，却仍然因为 GBW 不够而放不了 100kHz。“压摆率大的运放就是快运放”是错的，小信号看 GBW，大信号看 SR，两个都要算。要满足这个需求，可以选 OPA2350（38MHz）单级做，或者用两颗 TL072 分两级放大（每级 8 倍，级联后约 240kHz）。

题 7　积分器为什么比微分器受欢迎

同样是「电容型」电路，为什么工程上到处用积分器，却几乎不用纯微分器？

答：看频率响应：积分器增益 = 1/(2πfRC)，随频率下降（低通，天生抗噪声）；微分器增益 = 2πfRC，随频率上升，每十倍频程 +20dB（高通，把高频噪声放大）。
举例：取 R = 10k、C = 10nF，1MHz 的 100mV 干扰在微分器上会被放大 628 倍，理论输出 62V——运放早就饱和，输出被噪声占满。
另外纯积分器的直流增益无穷，失调电压会把它积分到电源轨，所以必须并一颗大电阻限制直流增益。微分器则必须串电阻限制高频增益。两个都要「打补丁」，但积分器的补丁不损失有用信号，微分器的补丁会。

题 8　虚拟地的误差会被放大多少

单电源 3.3V 系统，用一个 10k/10k 电阻分压产生虚拟地，实际电压是 1.60V（比理想的 1.65V 低了 50mV）。后面的同相放大器增益 60，输出会偏多少？

答：输出 = Vbias × (1 + Rf/Rg) = 1.60V × 60 = 96V——当然实际会饱和，这正说明问题有多严重：虚拟地的误差被噪声增益放大了 60 倍，50mV 的偏差理论上会变成 3V 的输出偏差（还没饱和时）。
所以虚拟地必须做得又准又稳：分压电阻用 1% 以上、并联足够的去耦电容（10~100µF）、必要时用跟随器缓冲，需要精度时用真基准芯片。这也是「单电源运放电路为什么读数老在飘」的头号答案。

动手练习

练习 1　亲眼看见失调电压（必做）

搭一个同相放大器，增益 100（Rg = 1kΩ、Rf = 99kΩ），输入端接地（0V），用万用表测输出。

  • 用 LM358：理论输出 0V，实际大概几百毫伏——按 Vos × 101 反推这颗芯片的 Vos（几百 mV / 101 = 几 mV）。
  • 换 OPA333：输出应该只有几毫伏，反推 Vos 大约是几微伏到几十微伏。
  • 把手指按在 LM358 的封装上（给芯片加热），观察输出缓慢漂移——这就是温漂在起作用。

这个实验只要五分钟，是理解「噪声增益放大失调」最快的方法。

练习 2　测出运放的真实输出摆幅

把 MCP6002（或任何 RRO 运放）接成跟随器，输入用一个电位器从 0V 缓慢调到 3.3V（分压自同一路电源），用万用表记录输出电压，画出「输入—输出」曲线。

  • 找出输出开始「跟不动」的两个点，那就是实际的 VOH 和 VOL。
  • 在输出接一颗 1kΩ 电阻到 GND（拉电流），再测一次，看 VOH 掉了多少。
  • 换成 LM358 重做一遍，你会看到输出在 1.8V 左右就上不去了——这就是 3.3V 系统里不能用 LM358 的直接证据。
练习 3　虚拟地的去耦电容到底有多重要

搭一个单电源偏置的同相放大器（虚拟地 1.65V，增益 10），输入端接地使输出停在 1.65V 附近。然后在同一块板上让一颗 LED 以 10Hz 闪烁（或者让单片机跑一段 GPIO 翻转程序）。

  • 先不接虚拟地的去耦电容，用 ADC 或示波器观察输出的波动幅度。
  • 再并上 10µF 和 100nF 各一颗，重复观察。
  • 你会看到读数波动明显变小。这个实验能让你真正理解「为什么虚拟地必须有电容」以及「偏置噪声会被噪声增益放大」。
练习 4　跨阻放大器的稳定性（进阶）

用一颗 1MΩ 反馈电阻接光电二极管做跨阻放大器（TL072 或 OPA333）。

  • 先不加 Cf，用示波器看输出——很可能看到几百 kHz 的振荡或者严重振铃。
  • 并上 3pF 电容，再看输出。按 4.3 节的公式算一下理论需要的 Cf，和实验结果对比。
  • 把 Rf 换成 10MΩ，你会发现需要的 Cf 更大、带宽更窄——这就是「灵敏度与带宽的交换」。
练习 5　亲手测一次 CMRR（最能长记性）

用四颗 10kΩ、1% 的电阻搭一个增益为 1 的差分放大器，两个输入端短接在一起，接同一个可调电压源。

  • 把共模电压分别设到 0V、2V、4V（注意不要超过运放的共模范围和电源），记录每一步的输出电压。
  • 输出电压的变化量除以共模变化量，就是共模增益；取倒数得到 CMRR，换算成 dB。
  • 和理论值 34dB（1% 电阻）对比。你测出来的可能更好或更差，取决于四颗电阻的实际匹配程度——这就是分立电阻差分放大器的真实水平：同一批电阻，不同的四颗，CMRR 能差 10dB 以上。

延伸阅读

  • 教材：童诗白、华成英《模拟电子技术基础》第 5 版第 3 章（多级放大电路与差分放大电路——运放内部的差分输入级就是从这里来的）和第 6 章（放大电路中的反馈、信号的运算与处理——虚短虚断的系统推导、加减运算、积分微分电路都在这两节）。第 6 章里「负反馈的四种组态」和「深度负反馈的估算」是这一篇的数学后台，值得精读。
  • 下一篇：《有源滤波与电压比较器》——把这一篇的运放接上电容和正反馈，就得到了滤波器、振荡器和比较器。你会看到「虚短失效」在比较器里是怎么变成一种特性的，以及为什么施密特触发器需要正反馈。
  • 动手方向一：用运放替代专用模块。把你手头某个模块（比如 LM35 温度模块、声音传感器模块）上的运放电路抄下来，逐颗电阻还原它的功能：这是同相放大还是差分？虚拟地在哪？增益多少？为什么选这个型号？能完整讲清楚一块模块，比看十篇教程有用。
  • 动手方向二：把电流采样做成闭环。用 INA240 + STM32 的 ADC + 定时器触发采样，做一个电流环的 PI 控制，让电机电流跟随给定值。这是「运放 + ADC + 定时器 + 控制算法」第一次完整串起来，也是电赛和毕设里最常见的题目类型。
  • 器件手册（最值得读的「课外书」）：TI 的 LM358、OPA333、INA240、INA128 数据手册，每份开头几页的「Application Information」几乎都是免费的教材；再配合 TI 的《Op Amps for Everyone》和「TI 精密实验室」（TI Precision Labs）系列视频，可以把这一篇的内容延伸到噪声计算、稳定性分析和 PCB 布局。
最后一句话

模拟电路和写代码最大的区别是：代码错了会报错，模拟电路错了会「看起来在工作」。一个 Vos 有 7mV 的运放，接上电就能输出，示波器上波形也像模像样，只是所有数字都偏了 14%。所以做模拟电路，永远要在画板子之前把那六笔账算完——这一篇所有的公式和例题，最终都是为了让你有这个习惯。
